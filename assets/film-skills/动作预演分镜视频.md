# 动作预演分镜视频

## Skill 描述

根据用户动作构思或已有动作分镜，生成动作分镜故事板，并结合角色三视图与场景参考生成连续动作视频，重点处理动作节拍、镜头衔接、角色一致性与多板连续性。

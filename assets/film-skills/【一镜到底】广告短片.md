# 【一镜到底】广告短片

## Skill 描述

适用于一镜到底或高连贯性故事短片。采用首帧承接技术，逐个生成镜头，通过提取前一镜头最后一帧作为当前镜头首帧来确保无缝连贯性。使用 Seedance 2.0 驱动镜头视频生成。

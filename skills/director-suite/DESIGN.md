# 专业导演分镜 Skill 设计蓝图（Director's Storyboard Skill · Architecture Blueprint）

> 一句话定位：把"20年导演的默会手感"做成一台**内部推理引擎**，让它先读懂剧本的情感与氛围，再用一套可量化的电影专业知识把感觉翻译成场面/景别/运镜/光影/色彩/表演/声音，最后按固定契约吐出可直接喂给文生图/文生视频的"哇塞提示词"——而引擎本身永远隐身。

---

## 1. 设计哲学（Why）

### 1.1 为什么"默会知识当内核引擎、不当输出"是关键

专业导演的核心竞争力不是"知道术语表"，而是 Polanyi 所说的**能力之知（knowing-how）**——一种说不全、但能在 0.5 秒内做出强选择的手感。这种手感有两个工程性质：

- **它必须在上游运行，不能出现在下游。** 一旦把"我现在在做寓居/格式塔整合"这类思考过程写进输出，提示词就被哲学话术污染，模型读到的是元认知噪声而不是画面指令。**引擎的价值在于产生决策，不在于解释决策。** 所以底盘第一条铁律就是：内部推理可见，方法论术语对外隐身。
- **它是"第一直觉的发生器"，规则是"事后自检的尺子"。** 如果让规则表去生成第一直觉，结果必然是"清单填空式"的安全平均镜头——每一项都对，整体却没有灵魂。正确的分工是：**默会内核先下注（commitment），知识库与契约再回检。** 顺序反了，skill 就退化成一个昂贵的填表机器人。

一句话：**默会知识是"为什么这么拍"的源头，专业知识库是"怎么拍得专业"的词典，输出契约是"怎么说模型才听得懂"的语法。三者地位不可互换。**

### 1.2 为什么情感/氛围是一切设计的上游因

技术维度（景别/运镜/光影/色彩…）本身**没有意义**——一个特写既可以是温柔也可以是威胁，决定它含义的是它服务的那个情绪。因此本 skill 立一条不可违反的**顺序铁律**：

> **先定"感觉"，再定"做法"。主情绪与氛围未锁定前，禁止进入任何技术决策。**

这条铁律带来三个结构性后果，贯穿整个架构：

1. **单一主锚（single anchor）**：每个分镜段只允许一个主导情绪，复杂情绪用"主+暗流"表达，绝不并列多锚——多锚=情绪被稀释=废稿。
2. **氛围是"母色"**：主情绪先翻译成可感知的氛围（冷暖/密度/稳定感/时间感），这个"母色"再统辖六维。六维不是平行清单，是同一母色的六个分声部。
3. **可回溯性（traceability）**：每一个最终的技术参数，都必须能反查到那一个主情绪。断链的决策一律删改。这是后面"自检"的根本依据。

## 2. 三层架构（Soul / Bone / Skin）

```
┌─────────────────────────────────────────────────────────────┐
│  输入：剧本片段  +（可选）参考素材  +  模型/画幅/时长约束        │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────── 第①层 · 灵魂 ───────────────────────┐
│  默会推理内核 TACIT CORE（_shared/tacit-core.md）               │
│  · 八大支柱 → 决策操作化   · 情感优先六维推理管线               │
│  · 核心张力自检清单        · 引擎隐身铁律                        │
│  产出：主情绪锚 + 氛围母色 + 每镜的"体感意图"（自然语言，内部）  │
└───────────────────────────┬─────────────────────────────────┘
                            ▼ 把"感觉"交给"词典"翻译
┌─────────────────────────── 第②层 · 骨 ────────────────────────┐
│  导演专业知识库 KNOWLEDGE BASE（_shared/*.md，多文件）           │
│  · 映射表（景别/运镜/光影… 情绪→参数 的强制映射）                │
│  · 八大专业维度词典（焦段/光圈/色温光比/帧率画幅/胶片…）         │
│  · 类型风格与名家语汇  · 连续性·质量·反向锚定                    │
│  产出：每镜的具体术语 + 数值参数（焦段/光比/色温/时长…）         │
└───────────────────────────┬─────────────────────────────────┘
                            ▼ 把"参数"装进"语法"
┌─────────────────────────── 第③层 · 皮 ────────────────────────┐
│  输出契约 + 自检 OUTPUT CONTRACT（<成员>/output-contract.md）   │
│  · 固定字段结构与顺序   · 参数优先于形容词                       │
│  · 连续性锁定字段       · 输出前内部检查 6 步 + 质量 rubric      │
│  · Seedance 2.0 适配层（_shared/seedance-2.0.md）               │
│  产出：固定格式的镜头卡（few-shot 对齐） + 通过自检的成片提示词  │
└─────────────────────────────────────────────────────────────┘
```

**三者如何串联（数据流，而非并列）：**

- **灵魂 → 骨**：内核输出的不是术语，而是"此刻该让观众感到 X、心理距离应更近、节奏应停滞"这类**体感意图 + 情绪强度等级（0–5）**。这个等级是把灵魂接进骨头的"插销"——它正好是映射表的查表键。
- **骨 → 皮**：知识库把"情绪强度 4 级、压迫升级"翻译成"近景 CU / 慢推 push-in / 光比 8:1 / 35mm / 时长 2s"，皮层负责把这些塞进固定字段，并补全连续性锚点与负面约束。
- **皮 → 灵魂（回检闭环）**：写完卡后，用内核的"情绪贯穿检/留白检/下注检"反向校验——这一步是回到灵魂层，确认骨与皮没有跑偏。**架构是单向翻译、末端闭环回检。**

设计上的关键纪律：**层与层之间只传"约定好的接口字段"**（主情绪、氛围母色、情绪强度 0–5、体感意图），不传哲学术语。这保证了引擎隐身在层间就已落实，而不是靠最后一步擦干净。

## 3. 端到端工作管线（Pipeline）

每步标注【输入 / 输出 / 调用哪张表或哪层】。

### Step 0 · 寓居读本（Indwelling Read）
- **输入**：剧本片段（+ 可选参考素材、模型/画幅/时长约束）。
- **做什么**：通读不拆镜，以人物身体感受场景，捕捉**边缘线索/潜台词**，记下第一直觉体感印象。
- **输出**：一段内部"体感印象"笔记 + 已识别的边缘线索清单。
- **调用**：第①层 · tacit-core（寓居、边缘线索、不可言说的剩余）。

### Step 1 · 主情绪与氛围标定（Anchor & Mood）
- **输入**：Step 0 体感印象。
- **做什么**：锁定**一个**主导情绪（如"压抑的期待"）；翻译成氛围母色（冷暖/密度/稳定感/时间感）。
- **输出**：`主情绪锚` + `氛围母色`（一句话各一个）。
- **调用**：第①层 · 情感优先六维推理管线（第 1–2 步）。
- **门禁**：母色未定，不许进 Step 3。

### Step 2 · 分镜组切分与节奏（Beat & Rhythm）
- **输入**：剧本片段 + 主情绪锚。
- **做什么**：按情绪节拍（beat）切分镜头组；为整段画一条**情绪曲线**（起→蓄→爆→落），给每个镜头预判一个**情绪强度 0–5 级**。
- **输出**：镜头组列表 + 每镜情绪强度等级 + 整段节奏曲线。
- **调用**：第①层（格式塔整合：保全整段情绪曲线不断裂）+ 第②层 表演与节奏（剪辑节奏）。

### Step 3 · 逐镜决策（Shot-by-shot，用映射表）
对每个镜头，按"情绪驱动而非清单填空"展开六维。每维先问一句"它如何让观众更接近主情绪？"
- **输入**：单镜情绪强度等级 + 体感意图 + 氛围母色。
- **做什么 / 调用哪张表**：
  - 景别 ← **景别-情绪映射表**（强度 0–5 → 强制/可选景别 + 时长基准）
  - 运镜 ← **运镜-情绪映射表**（手法 + 叙事功能 + 速度基准）
  - 光影 ← **主情绪×光影表**（色温 K / 对比 / 光比 / Key / 质感词）
  - 色彩 ← 光影与色彩词表（母色统辖 → palette）
  - 机位/角度/焦段 ← 镜头语言·空间 + 专业参数词表（焦段=心理距离开关）
  - 表演/声音 ← 表演与节奏词表（微表情锚点）+ 声音四轨表
- **输出**：每镜的六维术语 + 数值参数（草稿）。
- **强制约束**：映射表的强制项不可违反（如情绪 5 级禁用中景；情绪≤2 级无理由禁甩特写）；跳级须阶梯递进或显式"反差爆破镜"且有动机。

### Step 4 · 写卡（Card Authoring）
- **输入**：Step 3 六维草稿。
- **做什么**：按输出契约的固定字段结构与顺序，把草稿写成镜头卡；**参数优先于形容词**（可量化维度一律数值+单位）；补全 `连续性锁定` 字段（L1 角色/服化道零容忍，L2 光线时段锁）。
- **输出**：结构完整的镜头卡（未过检）。
- **调用**：第③层 · output-contract（字段规范 + 连续性锁定）+ Seedance 适配层。

### Step 5 · 自检与反向锚定（Self-check & Negative Anchor）
- **输入**：镜头卡草稿。
- **做什么**：跑**输出前 6 步内部检查**（情绪贯穿/六维协同/留白/下注/题材原创/引擎隐身）+ **核心张力 7 项自检**；补**反向锚定**（负面约束 negative prompt + 风格反例，把模型从"均值审美/AI 味"里拽出）。
- **输出**：修订后的镜头卡 + 负面约束块。
- **调用**：第①层张力清单 + 第③层质量 rubric + 知识库"连续性·质量·反向锚定"。

### Step 6 · 输出（Emit）
- **输入**：通过自检的镜头卡。
- **做什么**：按固定示例格式（few-shot 对齐）输出：映射表速览（可选）→ 镜头组 → 逐镜卡 → 中文为主+关键英文的成片提示词。**只剩创作语言，引擎全隐身。**
- **输出**：可直接驱动 Seedance 2.0 等文生视频的优质提示词。

**编排要点：**
- **SKILL.md（每个成员）**：① 身份设定（20年导演+提示词工程师）；② 三条铁律（情绪先行 / 单一主锚 / 引擎隐身）；③ 6 步 Pipeline 概要；④ **路由表**——"标定情绪→读 tacit-core；逐镜查表→读 mapping-tables/dimensions；写参数→读 pro-params；写卡→读 output-contract + seedance-2.0"。主文件不内联大表，只给"何时读什么"。
- **强制映射表单独成 `mapping-tables.md`**：它是每镜必查、最高频；参数词表与维度词典分开，避免一次性塞爆上下文。
- **few-shot 范例放 `storyboard/examples/`**：每个范例**完整演示链路**，且**至少一个展示"破格强选择"**（如情绪反差爆破镜），让模型学会"敢下注"而非只会安全平均。范例只用于**对齐输出格式与手感**，绝不被搬运进真实输出（题材原创检兜底）。
- **两种交付形态**：可安装的 Agent Skill 家族包（`_shared/` DRY 共享）；以及 `_megaprompts/` 里各成员的**自包含单文件版**（把所需知识内联，可直接粘贴进 Seedance/对话框，即拿即用）。
- **渐进式披露**：默认只加载 SKILL.md（轻）；进入某步时按路由表**按需 Read** 对应 reference；范例仅在格式对齐时读。

## 5. "哇塞"质量保证机制（Quality Assurance）

### 5.1 质量评分维度（Rubric，每维 0–5，总分门槛建议 ≥ 24/30）

| 维度 | 考察什么 | 满分锚点 |
|---|---|---|
| 情绪真实 | 是否对"这一刻的情感真实"负责 | 看完卡能"感到"那个情绪，而非"读懂"参数 |
| 情绪贯穿 | 每个决策可否回溯到单一主锚 | 六维全部朝同一母色用力，零断链 |
| 强选择/下注 | 有无敢负责的强选择 | 至少一处有动机的破格/极致，而非全程平均 |
| 参数硬度 | 可量化维度是否数值化 | 焦段/光比/色温/时长/声压全是数值+单位 |
| 连续性 | 跨镜能否拼成片 | L1 角色/服化道锚点显式声明，跨镜变化有交代 |
| 留白与隐身 | 是否留了"说不出"、引擎是否隐身 | 有留白；零哲学术语/支柱编号/方法论字样 |

### 5.2 自检 Rubric（输出前必跑，沿用底盘）
情绪贯穿检 → 六维协同检 → 留白检 → 下注检 → 题材原创检 → 引擎隐身检；任一不过即回炉。

### 5.3 常见劣化点与防呆（Anti-degradation）

| 劣化点 | 表现 | 防呆机制 |
|---|---|---|
| 清单填空 | 六维各自对、整体没灵魂 | 每维必须先答"它如何逼近主情绪"，答不出即删 |
| 多锚稀释 | 一段塞多个并列情绪 | 单一主锚硬约束，复杂情绪只能"主+暗流" |
| 炫技空转 | 无动机的 360 环绕/无情绪的推拉 | 运镜必带"叙事意图"，缺则废 |
| 形容词糊脸 | "唯美、高级感、电影感"无参数 | 参数优先于形容词，纯形容词不得单独成立 |
| 廉价惊悚 | 情绪≤2级甩特写 / 5级用中景 | 映射表强制项，违反即废稿 |
| AI 味/塑料感 | 均值审美、跨镜漂移 | 强制负面约束 + 风格反例 + 连续性锚点 |
| 引擎泄漏 | 输出现 Polanyi/支柱/"方法论分析" | 引擎隐身检兜底，发现即整段重写 |

## 6. 本次落地的关键取舍（已按你的决策锁定）

**设计取舍（已内置的立场）：**
- 默会内核**只在内部跑、不入输出**——牺牲"可解释性展示"，换"提示词纯净度"。
- **单一主锚** > 多情绪并列——牺牲"信息丰富"，换"情绪不被稀释"。
- **重知识下沉 `_shared/` + 按需加载**——牺牲"一次到位"，换"上下文不爆 + 手感完整"。
- **强制映射表硬约束**——牺牲部分"自由发挥"，换"专业下限有保障、可批量稳定出哇塞"。

**你已拍板的四个决策：**
1. **交付形态**：两者都要（Agent Skill 家族包 + 各成员单文件 mega-prompt）。
2. **目标模型**：Seedance 2.0 为主（设 `_shared/seedance-2.0.md` 适配层：`{语言:台词}`、`<音效>`、`(BGM)`、`【标题】`、4–15s、首尾帧、参考音色、多机位镜内切换、禁壁钟式时间切分）。
3. **输出语言**：中文为主 + 关键提示词附英文。
4. **范围**：skill 家族（分镜=核心，配套 角色设定板 / 场景色卡 / 关键帧）。

## 7. 微型 Worked Example（证明链路可行）

**输入剧本片段：**
> "她站在空荡的机场到达口，最后一拨人也走光了。手机屏幕亮着，是那条没发出去的消息。"

**① 默会判断（灵魂层 · 内部，不输出）：**
寓居进她的身体——人群散尽后的"被留下感"，边缘线索是"亮着却没发出的消息"（潜台词=不甘与犹豫）。

# 角色表（Character Roster · 制片圣经）输出字段契约 v1.0

> 制片圣经上游表 · 服务分镜表的「连续性锁定」· 时长制 v2.0 配套
> 与 `../storyboard/output-contract.md`、`./scene-roster.md`、`./props-roster.md` 同源同纪律：**参数优先于形容词**、**一致性锁定为第一性**、**反向锚定必填**、**自检不外显**。

---

## 0. 用途与定位（本表在制片圣经里站什么位置）

- **本表是「制片圣经」的最上游身份锚定表**：每个角色一次定义、全片复用。它先把"这个人是谁、长什么样、什么气质、什么声音"钉死成一份可复用的事实，再被下游各表引用——
  - **分镜表**「镜头组」`连续性锁定` 字段以本表 `asset_id` 为唯一引用键锁角色造型；分镜表「台词」的 `【音色】` 子参数引本表 §4「音色锁定」；分镜「画面内容·动作与微表情」依本表「情感主线/弧光」给戏。
  - **场景表** `交叉引用·出场角色` 引本表 `asset_id`（注意：**人物身份在本表，场景图里不画人物**——见 `scene-roster.md` 总则）。
  - **道具表** `归属 owner` 引本表 `asset_id`（谁拿着随身道具）。
  - **角色设定板**（`../character-board/`）生成的多视图/头像图像资产，回填到本表 `视觉资产绑定` 字段，作为图像事实源；本表是"文字台账"，设定板是"图像规格"，两者一对一。
- **一处定义·处处引用**：角色的面貌/造型/体型/音色在本表锁死后，下游一律 `asset_id + 当前 Look/态` 引用，**不重述外观**——重述就是漂移的入口。所有未标"可选"的字段均为强约束，缺项视为不合格。
- **本表的灵魂不是机械罗列名词**：而是默会读出每个角色的**情感主线/弧光与气质**、分清**主角/配角/群演的着墨等级**、并**锁死音色以备配音一致**。一张只填了"年龄/身高/发色"却读不出人物"此刻该让观众感到什么"的角色表，回炉。

## 1. asset_id 命名规范（每个角色条目恰有一个）+ 一致性等级 L1/L2

### 1.1 asset_id 命名

格式：`[Element_<Name>]`（与场景 `[Element_<Space>_<Tag>]`、道具 `[Prop_<语义名>_NN]` 同体系，下游分镜以同一 ID 引用、并对应 Seedance 提示词里的 `<<<image_n>>>=@asset_id`）。

| 规则 | 说明 | 正例 | 反例 |
|---|---|---|---|
| 前缀固定 `Element_` | 与场景/道具同纪律，下游可跨表对齐 | `[Element_LinChen]` | `[角色1]` / `[林辰]`（无前缀、非稳定英文ID） |
| `<Name>` | 角色英文/拼音名（PascalCase），全片唯一不重名 | `[Element_ZhaoShanhe]` | `[Element_Man01]`（语义空洞） |
| 群演群像 | 无个体身份的群像作为**一个**集合实体登记 | `[Element_Elders]`（三前辈沉默群像） | 把无名群众逐个建 ID，表臃肿 |
| **音色子 ID** | 角色音色单独登记 `[Voice_<Name>]`，与角色 `asset_id` 绑定，供配音跨镜一致复用（见 §4） | `[Voice_LinChen]` | 把音色塞进角色描述不单列，配音无法对齐 |
| **多 Look 同 ID** | 同一角色不同造型/年龄**不拆新 ID**，用 §3「外观/Look 轴」的 `Look 1 / Look 2` 区分（同道具多态思路） | `[Element_LinChen]` Look1 办公室 / Look2 赴宴 | `[Element_LinChen_Office]`+`[Element_LinChen_Banquet]` 拆两条，身份断裂 |

### 1.2 一致性等级 L1 / L2（每条锚定项逐项标注）

每个角色的每条锚定项都必须打等级标签，告诉下游"什么永不许动、什么允许动但要说一声"：

| 等级 | 名称 | 含义 | 在分镜中的待遇 | 典型项 |
|---|---|---|---|---|
| **L1** | 硬锚 · 不可变 | 跨全片所有镜头**恒定不变**的身份事实，跨镜一字不改 | 进每个出现镜头组的 `连续性锁定` 硬锚区，**任何镜头不得改写**；漂移即废稿 | 面貌（脸型/五官/特征记号）、体型头身比、音色（音域/质地/口音）、瞳色、骨相 |
| **L2** | 软锚 · 随剧情可变 | 允许随叙事改变（换装、变老、负伤、情绪态切换），**但变化只能沿预定义「外观/Look 轴」逐态发生**，且每次变化必须在分镜「连续性锁定」里**显式声明**"承上组×××／本组起×××" | 进 `连续性锁定` 时**必须显式声明当前 Look/态**；相邻镜头首尾帧须校验衔接 | 服装与配饰、发型造型（被打湿/凌乱）、妆容、可见伤口/血污、临时持有道具、随情绪推进的默认神态偏移 |

> **铁律**：**没有"默认可变"。** 未标 L2 的一律按 L1 锁死。L2 项的变化**只能在「外观/Look 轴」已登记的节点发生**；分镜里出现「未登记的突变」（上镜西装、下镜便服却无换装交代）= 连续性破口，废稿。L2 不等于"随便变"，等于"按账本变"。与分镜契约 §7-5「硬锚不漂、跨组承接显式声明」对接。

## 2. 着墨等级（主角 / 配角 / 群演 · 决定一条目要锁多细）

> 焦点 vs 从属的第一刀：**不是每个出场的人都要锁同样多字段。** 着墨等级决定本表给这个角色分配多少锚定密度、要不要单独音色 ID、要不要多视图设定板。

| 着墨等级 | 定位 | 锚定密度 | 音色 | 视觉资产 |
|---|---|---|---|---|
| **主角 Lead** | 承载主情绪主线、有完整弧光、反复被特写凝视 | §4 全字段满锁；情感主线/弧光必写、微表情谱必给 | 必建 `[Voice_<Name>]`，音色全参数 + 情绪基调随弧光的变化 | 必出多视图设定板（头像+5视图），多 Look 各锁 |
| **配角 Support** | 服务主角弧光、有明确功能与单一气质、有台词 | 面貌/造型/音色锁，弧光可简写为"功能+单一气质" | 有台词即建 `[Voice_<Name>]`，音色含性别+质地+语速基调 | 出头像+正面（必要 Look） |
| **群演 / 群像 Extra** | 无个体身份、作整体氛围或共谋符号 | 作**一个集合实体**登记，只锁"群体统一造型 + 群体气场"，不逐人锁面貌 | 一般不单建音色；若群体有统一声场（如低声议论）登记群体声场即可 | 群像参考图一张，统一造型基调 |

> 判别口诀（内部）：**会被反复凝视、会变化、会扛情绪主线的人 → 主角满锁；服务主线、有功能有台词的 → 配角中锁；只为氛围/共谋存在的 → 群像集合锁。** 一张角色表若给每个端茶倒水的人都满锁面貌音色，多半是把群演当主角了，回炉。

| **妆容造型 [L2]** | 妆感强弱+关键部位+是否素颜 | 给男角硬安浓妆；与气质打架 |
| **服装与配饰 [L2]** | 廓形+层次(由内到外)+颜色(HEX)+材质+剪裁+状况(new/used/worn+具体损耗)+配饰逐件(名+位+材) | 只写"穿西装"不写内层/材质/状况；配饰无位置 |

| **音色锁定** | 见 §4，每参数给值 | 只写"低沉好听"；不单列音色 ID |
| **微表情/表演谱** | 分解为**可观察肌肉/肢体动作**（"指节叩两下后停住""下颌微收喉结一动"），按情绪节拍给；主角必给 | 只写情绪标签（"他很紧张"）；摆拍式空动作 |
| **风格核心锁定** | 沿用全片基调（如`冷峻写实商战悬疑片`），跨角色不漂 | 每角色各自漂风格 |

| **视觉资产绑定** | 设定板图像 asset / `用户图`直绑不重生 / `TextToImage Nano Banana 2 @2K` / 多 Look 走 `ImageToImage 链参考 Look1` | 用户已有资产重复生成；多 Look 各自重画不走链 |

## 4. 音色锁定（Voice Lock · 本表的灵魂之一 · 配音跨镜一致的根）

> 音色是角色身份的一半。**台词在分镜表里写、声音的"身份"在本表里锁**——分镜「台词」的 `【音色】` 子参数只引本表 `[Voice_<Name>]`，不重述音色，保证同一角色全片配音不漂、不会"一个人前后两把嗓子"。

### 4.1 音色 ID 与字段

每个有台词的角色单独登记一条音色档案，`[Voice_<Name>]` 与角色 `[Element_<Name>]` 一对一绑定：

```
[Voice_角色名]  绑定 [Element_角色名]
├ 声音身份 identity：性别 + 年龄感 + 音域(男低/中/高·女低/中/高) + 质地(沙哑/烟嗓/清亮/胸腔厚/气声…)
├ 口音 / 语言：     普通话 / 方言 / 外语；语言代号(zh/en)；多语台词标语言
├ 语速基调 pace：   缓/中/急 + 习惯性尾音处理(拖尾/收顿/叹气句尾)
├ 情绪基调 tone：   默认情绪色（沉稳/疲惫/算计/温煦…）；随弧光变化的写"基态→变化态"
├ 标志性处理 tic：  该角色特有的口头习惯/重音习惯（某些词加重收顿、句间停顿等）
├ voice_reference： 参考音频资产(≤15s)：用户提供则直绑；中文 doubao / 英文·全球 elevenlabs
└ 生成绑定：        视频生成时哪个角色用哪段参考音频，显式声明，不混用
```

| 字段 | 填写规范 / 允许值 | 常见错误 |
|---|---|---|
| **声音身份** | 性别+年龄感+**音域档**+**质地**，质地给可听描述（烟嗓/胸腔厚/气声） | 只写"好听的男声"；无音域无质地 |
| **口音/语言** | 标语言代号(zh/en)；多语台词在分镜花括号前标语言（`*Says in Japanese:*`） | 不标语言，配音选错语种 |
| **语速基调** | `缓/中/急` + 尾音习惯 | 与情绪打架（急切戏却标"缓"） |
| **情绪基调** | 默认情绪色；随弧光变则写"基态→变化态"（如"沉稳→无温度的冷"） | 把每句的临时情绪当基调；基调多锚并列 |
| **标志性处理** | 该角色独有的重音/停顿/口头习惯，使配音可辨识 | 留空，角色声音同质化 |
| **voice_reference** | 用户音频直绑；无则按语言选 TTS（zh→doubao / en→elevenlabs）；时长 ≤15s | 不指定参考、不标时长；多角色共用一段参考 |
| **生成绑定** | 显式写"本镜哪个角色用哪段参考音频"，与分镜参考输入对齐 | 不指明对应关系，视频生成串音 |

> **音色随弧光走 [L2 情绪基调] / 音域质地恒定 [L1]**：一个角色的**音域与质地是 L1 身份锚**（赵山河永远是低沉胸腔厚的中年男声，不许变嗓），但**情绪基调可随弧光做 L2 弧光**（赵山河从"温煦和蔼"逐步抽成"笑里没有温度的冷"）——后者每次变化在分镜「台词·情感」处显式声明，与画面色温抽冷同步。

## 5. 默会要点（本表的灵魂 · 内部推理，不机械罗列名词）

> 顺序铁律同分镜与场景表：**先定"感觉"，再定"做法"**。角色不是一份"年龄发色身高"的户籍卡，是**情绪主线的载体**。以下四步只在内部跑，最终只输出角色决策本身（气质/弧光/造型/音色等创作语言与参数），**不出现任何方法论/支柱/"默会"/哲学术语**。

**① 寓居读人：先住进角色，读出情感主线与弧光**
通读剧本时不急于填字段，先以这个人**此刻的身体与处境**去感受：他怕什么、压着什么、想要什么？为每个主角锁**一条**情绪主线（单一主锚，复杂用"主线 + 一缕暗流"），再画出他从开篇到结尾的**弧光**——情绪/认知/处境的起→落（如"从'明知是局却不得不入局'的窒息，到摊牌后'浑身冰凉'的顿悟"）。弧光决定了哪些字段要走 L2（造型/神态/音色基调随弧光改写），哪些恒定 L1。**没有弧光的主角条目 = 没有灵魂的名词堆。**

**② 读气质：把"是谁"翻成可执行的母气与默认神态**
气质是角色的"母色"，统辖其造型材质/光怎么落在他脸上/默认神态。住进角色后问："他给空间带来的温度是什么？"把它落成**色温倾向 + 材质硬软 + 明暗倾向 + 松紧**，并沉淀为一句**默认神态**（"眼神下压、下颌微收"）——气质不靠甩动作外化，靠神态与造型材质渗出。一个角色**只能一个主气质**；"和蔼的笑里藏杀机"用"主气质=温煦 + 一缕暗流=笑不达眼底"表达，不并列两个气质。

**③ 分着墨：用"谁扛主线"决定锚定密度（焦点 vs 从属）**
不是每个出场的人都值得满锁。先问三问：他**扛不扛主情绪主线**？他**会不会被反复凝视/特写**？他**有没有弧光**？三个都"是"→主角满锁；服务主线、有功能有台词→配角中锁；只为氛围/共谋存在（如"三位前辈低头默默喝茶"=沉默的共谋符号）→作群像集合锁。**边缘线索常在配角身上**：一个沉默群像的"低头"可能正是该被锁住的潜台词，把它写进群体气场，而不是漏掉。

**④ 锁音色：声音是身份的一半，先定基调再定参数**
音色不是"配个好听的嗓"，是**让观众闭眼也认得出这是谁**、并随弧光让声音"变冷/变疲惫"。先住进角色读出他声音的**情绪基调**（疲惫认命 / 斩钉截铁 / 温煦藏锋），再落成可执行参数（音域/质地/语速/标志性处理）。**音域与质地恒定（L1）保证不变嗓，情绪基调随弧光走（L2）让声音参与叙事**——赵山河的"和蔼"声线一寸寸抽走温度，与画面暖金被抽冷同步，是"温柔包裹的杀机"在听觉上的可视化。

> **隐身铁律**：以上推理只在内部进行；最终角色表与成片里**不出现**任何方法论/支柱/"默会"/格式塔/寓居/哲学术语，只呈现情感主线、气质、造型参数、音色等创作语言与参数。

| 子字段 | 指向 / 规范 | 常见错误 |
|---|---|---|
| 归属剧情段 | 标 S 编号 + 起承转合功能 | 不标，无法定位角色在结构里的位置 |
| 出现场景 | → **场景表** `[Element_<Space>_<Tag>]`；身份在本表、场景图不画人物 | 把人物渲进场景图，破坏"空间图无人物"铁律 |
| 随身道具 | → **道具表** `[Prop_*]`；与道具表 `owner` 互为反查，校验"相邻镜手持物连贯" | 随身道具不登记，持有链断裂 |
| 对手戏角色 | → 本表其它 `[Element_*]`；供分镜反打不跳轴、权力关系外化 | 不标，反打镜跳轴 |
| 出现镜头组 | → **分镜表** 组号，定稿后回填，形成双向链 | 留空导致上下游脱钩 |

| 设定板资产 | → **角色设定板**（`../character-board/`）的图像 asset，作图像事实源，与本表文字台账一对一 | 文字台账与设定板图像脱节，描述与图矛盾 |

> 引用方向铁律：**角色表定义，分镜表引用**。分镜「连续性锁定」写角色时只写 `asset_id + 当前 Look/态`，「台词」只引 `[Voice_*]`，**不重述外观与音色**——外观与音色的唯一事实源在本表。

## 7. 输出前自检（内部跑 · 绝不写进成片表）

1. **ID 唯一性**：每条目恰一个 `[Element_*]`；有台词角色恰一个 `[Voice_*]` 绑定；多 Look 共享 ID、用「外观/Look 轴」区分。
2. **L1/L2 全标注**：每条锚定项均带 `[L1]`/`[L2]`；未标项按 L1 处理；L2 项均给"可变方向/Look 轴"且每态挂触发+镜组。
3. **着墨过滤**：主角满锁(弧光+表演谱+全音色)、配角中锁、群演作集合锁；表未被无名群众满锁堆臃肿。
4. **参数齐全**：身份特征有头身比+身高cm；面部有特征记号+瞳色色名/HEX；音色有音域+质地+语速；服装有层次+材质+状况。
5. **灵魂落地**：每个主角有单一情感主线 + 弧光走向 + 单一主气质（未写成内心独白/动机解说）；音色有情绪基调（随弧光变则标基态→变化态）。
6. **音色一致**：音域质地恒定[L1]、情绪基调随弧光[L2]；voice_reference 标语言(zh/en)与时长≤15s；生成绑定显式指明哪个角色用哪段参考。
7. **交叉引用闭环**：出现场景/随身道具/对手戏/出现镜头组/设定板资产 全向齐全且与场景表/道具表/分镜表/设定板 ID 对得上、双向可查。
8. **反向锚定**：质量和禁止含角色专属反向（禁换脸/跨视图换装/发型发色漂移/配饰增减/比例尺不一/音色漂移/多指脸崩）。
9. **引擎隐身**：全表零 Polanyi/默会/格式塔/寓居/方法论/支柱编号字样，只剩角色决策与参数。
10. **题材原创**：未搬运契约样例的具体角色/台词/设定到用户当前剧本。

> 与分镜契约同纪律：本 §7 检查只在内部跑，**不得**作为脚注（"自检确认✓""弧光已锁"之类）写进最终角色表——那本身就是引擎泄漏。

# 场景表（Scene Roster · 制片圣经）输出字段契约 v1.1

> 制片圣经上游表 · 服务分镜表的「连续性锁定」· 时长制 v2.0 配套
> 本契约与 `../storyboard/output-contract.md`、`../character-board/output-contract.md`、`./props-roster.md` 同源同纪律：**参数优先于形容词**（可量化项一律数值+单位）、**一致性锁定为第一性**、**反向锚定必填**、**先绑定后生成**、**自检不外显**。
> 本表是制片圣经里的**上游空间锚**：它先把每个场景"钉死"成一份可复用的视觉事实，再被分镜表「场景」字段与「连续性锁定」字段以 ID 引用。**一处定义、处处复用**——分镜跨镜不漂的物理根基在这张表，不在每个镜头各自描述。所有未标"可选"的字段均为强约束，缺项视为不合格。
>
> v1.1 相对 v1.0 的增量：补 **§0 先绑定后生成铁律**；§2 字段表新增 **asset 绑定（推荐模型@分辨率）**、**风格/作者锚点**、**主色占比量化（90% 单一主导色相）** 三处；新增 **§3.5 场景四视图参考资产规格**（2×2 宫格建立/入口/道具/反向，无人物无文字）。

---

### 0. 总则与底层约束

- **空间锚定优先**：本表第一目的不是"画得好看"，而是"把同一个空间钉死成同一个空间"。任何为了某张图好看而牺牲跨镜空间一致性的选择，视为废稿。
- **一处定义·处处引用**：每个场景定义一次、分配一个 `asset_id`，下游分镜一律用 ID 引用（如 `[Element_Office_Noir]`），**禁止**在镜头里重述场景外观——重述就是漂移的入口。
- **参数优先于形容词**：可量化维度（色温 K / 主光方向（钟点位或角度）/ 光比 / 亮度% / 焦点坐标 Focus(X,Y) / 画幅）一律写**数值+单位**；形容词仅作补充。"高级灰""有质感"等空话视为不合格。
- **空间图无人物·无文字**：场景参考资产里**不放人物**（人物身份由角色表锁定）、**不生成画面内文字/水印/Logo**，保持画面整洁、避免抢占空间信号。除非剧情要求场景内有可读屏幕文字，确切文本用引号包裹自然融入（如屏幕 reads "DANGER"）。
- **写实优先**：默认 8K 真人写实、物理正确光影，禁 CG/卡通/插画质感（除非该场景在风格核心锁定里另行声明风格化）。
- **只描述物理可见内容**：不写画外、不可见或抽象设定；与故事事实/用户已提供的场景参考资产不得矛盾。
- **先绑定后生成**：用户已提供的场景/外景参考图，直接绑定为该条目的 `asset_id`，描述必须与该资产**匹配、不矛盾**，**不重复生成**；仅当全片无任何已有资产覆盖该空间时才新建并生成（场景四视图见 §3.5）。
- **主色克制（量化）**：每场景由单一氛围母色统辖，**约 90% 画面面积只用一种主导色相**（如 deep teal-cyan shadows dominating 90%, zero warm fill）；对比/点缀色仅作 9:1 收口（或主辅缀 6:3:1）。**禁红蓝霓虹撞色**（crimson bleed / magenta×cyan），除非用户明确要求。

### 1. asset_id 命名规范 + 一致性等级 L1/L2

#### 1.1 asset_id（每个场景条目恰有一个）

格式：`[Element_<Space>_<Tag>]`

- 角色/场景用 `Element_` 前缀（角色 `[Element_<Name>]`、场景 `[Element_<Space>_<Tag>]`），道具用 `Prop_`（`[Prop_<Name>_<NN>]`）、音色用 `Voice_`；统一以 `../_shared/asset-id-convention.md` 为权威来源，下游分镜以同一 ID 引用。
- `<Space>` = 空间英文标识（PascalCase，如 `Office`、`PavilionExterior`、`PrivateRoom`）。
- `<Tag>` = 气质/语境短标（如 `Noir`、`Dusk`、`Banquet`），用来在同一物理空间的多状态间区分。
- **同一物理空间的不同时段/陈设状态**：共享 `<Space>` 根、用 `<Tag>` 或 `State N` 区分（如 `[Element_PrivateRoom_BanquetWarm]` 与 `[Element_PrivateRoom_BanquetCold]`），**并在 §2「状态/Look」字段显式声明二者关系**，不得拆成两个互不相干的实体导致空间地标对不上。
- 命名全程唯一、无同地异名；一旦分配，下游所有引用与文件名锁死不改。

| 正例 | 反例 | 错因 |
|---|---|---|
| `[Element_Office_Noir]` | `[场景1]` / `[办公室]` | 无 `Element_` 前缀、非稳定英文 ID，下游无法跨表对齐 |
| `[Element_PavilionExterior_Dusk]` | `[Element_Pavilion]`（同楼内外/日夜混用一个 ID） | 内外/时段不同却共用一个 ID，光位与空间会串 |
| `[Element_PrivateRoom_BanquetCold]`（承 Warn 同空间变冷） | 另起 `[Element_RoomDark]` | 同空间冷态被拆成新实体，红木圆桌等地标失去承接 |

#### 1.2 一致性等级 L1 / L2（每个锚定项逐项标注）

每个场景的每条锚定项都必须打等级标签，告诉下游"什么不许动、什么允许动但要说一声"：

| 等级 | 含义 | 下游行为 | 典型项 |
|---|---|---|---|
| **L1 硬锚（不可变）** | 跨全片所有引用此场景的镜头**永不改变**的物理事实 | 直接锁死，分镜「连续性锁定」逐项继承，改动即穿帮 | 空间结构/固定参照物方位、地标家具位置、内/外、画幅、空间几何朝向（窗在画面左等） |
| **L2 随剧情可变（需显式声明变化）** | 允许随叙事推进改变，**但每次变化必须在分镜「连续性锁定」里显式写"承上组×××／本组起×××"** | 不得静默漂移；变化点要留痕、可追溯 | 时段（暮→夜）、主光色温与光位走向（暖金→冷青弧光）、天气、实用光开关、可移动道具状态、临时陈设 |

> 铁律：**没有"默认可变"。** 未标 L2 的一律按 L1 锁死。L2 项若在某镜发生变化而分镜未声明，视为连续性破坏（与分镜契约 §7-5「硬锚不漂、跨组承接显式声明」对接）。

### 2. 字段表（逐字段：填写规范 / 允许值 / 常见错误）

> 固定结构与顺序。每个场景一段，字段缺一不可（标"可选"者除外）。**每条锚定项行尾标 `[L1]` 或 `[L2]`**。

```
场景条目：asset_id ｜ 场景名 ｜ 内/外 ｜ 时段
————————————————————————
氛围母色与情绪功能：<一句话定母色 + 该场景在全片情绪曲线里干什么>   ← 本表灵魂，见 §3
空间结构与几何 [L1]：<布局 + 画幅 + 镜头进入逻辑>
固定参照物（地标）[L1]：<不可移动的视觉地标 + 在画面中的方位>
焦点区 / 主表演区 [L1]：<主要动作/表演发生区 + 焦点坐标 Focus(X,Y)>
可移动道具与陈设 [L2]：<随剧情变化的物件 + 初始状态>
光位与色温基调：
  主光 [L1空间光位 / L2色温弧光]：方向(钟点位/角度) + 色温K + 亮度% + 光比 + 作用
  实用光/暖点光 [L2]：…   环境光/天光 [L1或L2]：…
材质与质感 [L1]：<墙面/地面/家具主材质 + 反光特性>
状态 / Look [L2]：<本条目相对同空间其它状态的差异 + 承接声明>
风格 / 作者锚点：<全片基调 + 具体影片/作者风格锚（非泛词）>
asset 绑定：<用户图 / TextToImage(模型@分辨率) / ImageToImage 链 ＋ 四视图规格见 §3.5>
质量和禁止：
  正向：<分辨率/质感/真实度>
  反向（禁止）：<逐类负面约束>
交叉引用：见 §4
```

| 字段 | 填写规范 / 允许值 | 常见错误 |
|---|---|---|
| **asset_id** | 见 §1.1，`[Element_<Space>_<Tag>]`，全片唯一 | 用中文序号/口语名；同空间内外混用一个 ID |
| **场景名 ｜ 内/外 ｜ 时段** | 场景名（中文可读）＋`内`/`外`/`内外过渡`＋时段（`日`/`暮`/`夜`/`晨`，过渡写`暮转夜`）。内/外必填且标 [L1]，时段标 [L2] | 缺内/外或时段；把内外当可变项 |
| **氛围母色与情绪功能** | 一句话：母色（冷暖/明暗/松紧倾向）+ 该场景在情绪曲线的功能（铺陈/反讽/转折/爆点/收束）。详见 §3 | 只写"温馨""压抑"等情绪词不落母色；罗列名词不写功能 |
| **空间结构与几何 [L1]** | 布局（开间/纵深/对称性）+ 画幅（`16:9`/`2.39:1`质感等）+ 镜头进入逻辑（从哪进、视线落点）+ 关键几何方位（如"窗在画面左") | 不写画幅；几何方位含糊导致跨镜跳轴 |
| **固定参照物（地标）[L1]** | 列 1–3 个不可移动地标 + 各自在画面中的方位（左/右/后景、画面分区）。这是空间对齐的物理钉子 | 漏地标；只说"有张桌子"不给方位 |
| **焦点区 / 主表演区 [L1]** | 主要动作/表演发生区描述 + 归一化焦点坐标 `Focus(X,Y)`，(0,0)左上、(1,1)右下，主焦点宜落三分线（X≈0.33 或 0.67） | 不标焦点区，下游机位/走位无锚；坐标乱给 |
| **可移动道具与陈设 [L2]** | 逐件：名称 + 初始状态 + 可变方向（如"烟灰缸内一支烟，初始未灭→组内摁灭"）。道具的身份若关键，单独走道具表 ID | 把可变道具当 L1 锁死；漏初始状态 |
| **主光 [L1/L2]** | 方向用**钟点位或角度**（如 `画面左/9点位`、`upper-left 60°`）[L1] + 色温K [L2弧光] + 亮度% + 光比（如 1:4）+ 作用（塑形/定空间冷调）。色温 2700K(暖钨)–7500K(冷蓝) | 只写"自然光""柔和光线"；不给方向/色温/光比；把光位当可变 |
| **实用光/暖点光 [L2]** | 实景光源（门廊灯/烛/屏光）：色温K + 亮度% + 区域 + 开关状态。常作冷暖对撞的暖斑 | 与主光打架；不标区域 |
| **环境光/天光 [L1或L2]** | 天光色温K + 强度 + 是否随时段变（变则 [L2] 标弧光） | 时段已变天光却不声明 |
| **材质与质感 [L1]** | 主表面材质（红木/玻璃/水泥/砖）+ 反光特性（哑光/镜面/做旧）。材质决定光怎么落、跨镜须一致 | 材质漂移导致同一墙忽哑忽亮 |
| **状态 / Look [L2]** | 仅当同空间有多状态时填：本状态相对基态的差异 + 承接声明（"承 Warm 暖态，本状态起暖金抽走、辅光降至 X%") | 多状态不写承接，地标对不上 |
| **风格 / 作者锚点** | 沿用全片基调（如`冷峻写实商战悬疑片`）跨场景不漂 **＋ 必带具体影片/作者风格锚**（如 `Neo-Noir style, David Fincher, inspired by Se7en`），不用"高级感""电影感"等泛词 | 每场景各自漂风格；只写泛风格词无作者锚 |
| **asset 绑定** | 已有素材→`用户图`直接绑、不重生；否则 `TextToImage Nano Banana 2 @2K` 新建；同空间多状态走 `ImageToImage 链参考基态`；四视图参考资产规格见 §3.5 | 用户已给却重画；多状态各自重画不走参考链；漏写模型/分辨率 |
| **质量和禁止** | 正向+反向两段，反向覆盖：渲染失真/风格越界/画质瑕疵/**场景专属**（人物入画/可读Logo车牌/第二空间穿帮/光位跳变/霓虹红蓝撞色） | 只写正向；反向笼统；漏"场景图禁人物/禁文字" |

### 3. 默会要点（本表的灵魂 · 内部推理，不机械罗列名词）

> 顺序铁律同分镜：**先定"感觉"，再定"做法"**。场景不是地点清单，是情绪的容器与人物关系的外化装置。以下四步只在内部跑，最终只输出场景决策本身。

**① 定氛围母色（每场景一个母色，统辖该场景全部光色）**
先"住进"这个空间：人物此刻在这里身体会感到什么（冷暖、拥挤/空旷、安稳/失衡、停滞/紧迫）？把它翻译成可执行母色——**色温倾向 + 明暗倾向 + 饱和倾向 + 材质硬软**。母色一旦定，主光/实用光/天光都服从它；偏色即偏情绪。一个场景**只能一个主母色**，复杂用"主 + 一缕暗流暖/冷"表达，不并列。

**② 定情绪功能（这个场景在全片情绪曲线里干什么）**
每个场景在"起→蓄→转→爆→落"里占一个功能位：铺陈窒息 / 伪温情反讽 / 温度抽走的转折 / 爆点 / 余韵收束。功能决定母色是否随剧情被改写——这就是 L2 色温弧光的来源（如包厢从暖金顶峰被逐步抽冷至冷青死寂，是"温柔包裹的杀机"这条主情绪在空间里的可视化）。

**③ 让空间外化人物关系与权力**
固定参照物的方位与焦点区的安排，要让"谁主谁客、谁压谁、谁被注视"在空间里被看见——主位 vs 客位、居中 vs 偏隅、被环绕 vs 孤立、高 vs 低、暖斑召唤 vs 冷场隔绝。空间布局是权力关系的无声台词；定地标方位时先问一句："它如何让观众感到此刻的权力/亲疏？"

**④ 锁光位与色温基调（情绪的明暗与温度）**
主光**方向**（钟点位/角度）属空间几何，定下即 L1 锁死，跨镜不许跳；主光**色温**是情绪温度，可随情绪功能走 L2 弧光。阴影是"未说出口"的可视化——光比越大、暗部越沉，威胁越重。实用暖点光常用来与冷场对撞，制造"过度的热情=诱饵"的反讽。

> **隐身铁律**：以上推理只在内部进行；最终场景表与成片里**不出现**任何方法论/支柱/"默会"/哲学术语，只呈现母色、情绪功能、光位色温等创作语言与参数。

### 3.5 场景四视图参考资产规格（锁定空间的可复用底图）

> 每个场景条目（除直接绑用户图外）须生成**一张** 2×2 宫格四视图作为该 `asset_id` 的权威底图，供下游每个引用此场景的镜头作 reference。四格共用同一光位/色温/陈设，**画面无人物、无文字水印Logo**。

| 宫格位 | 视角 | 作用 |
|---|---|---|
| **左上** | 建立全景（Wide establishing） | 钉死空间整体几何与画幅，确立 §2「空间结构与几何」 |
| **右上** | 主入口中景（Medium from main entry） | 钉死「镜头进入逻辑」与视线落点，跨镜机位起锚 |
| **左下** | 关键道具/地标特写（Detail of key prop/landmark） | 钉死 §2「固定参照物」的材质与方位，跨镜认得出同一地标 |
| **右下** | 反向视角（Reverse angle） | 钉死越肩反打不跳轴，锁定空间的另一半几何 |

落地规范：
- **生成**：`TextToImage Nano Banana 2 (Gemini 3.1 Flash Image) @2K`；同物理空间的不同状态（暖态/冷态）走 `ImageToImage 链参考基态四视图`，只改 L2 光色/陈设、不改 L1 地标方位。
- **一致性**：四格的主光方向、色温基态、材质、地标方位必须**互相一致**，否则该参考资产作废重生。
- **提示词骨架**（内部）：`A location reference sheet of [空间结构/材质/光源方位/色温K/标志物]…`，**末尾强制** `no people, no text, no labels, no watermark, no logo`。
- **下游引用**：分镜镜头的 reference 输入引此四视图的对应视角；视频提示词以占位符 `<<<image_场景>>>` 指代本 `asset_id`。

### 4. 交叉引用字段（与角色表 / 道具表 / 分镜表打通）

每个场景条目末尾固定附「交叉引用」块，使制片圣经各表互查：

```
交叉引用：
  归属剧情段：<S几 / 起承转合段位>
  出场角色：<角色 asset_id 列表>（仅登记会在此场景表演的角色身份 ID，人物不画进场景图）
  关联道具：<道具 asset_id 列表>
  出现镜头组：<下游分镜的镜头组号，如 G3–G4 / G5–G11>（分镜定稿后回填）
  被引用于：<分镜「场景」字段 + 「连续性锁定」中以本 asset_id 出现的位置>
```

| 子字段 | 规范 | 常见错误 |
|---|---|---|
| 归属剧情段 | 标 S 编号 + 起承转合功能 | 不标，无法定位场景在结构里的位置 |
| 出场角色 | 用角色表 asset_id；只登记身份引用，**不把人物渲进场景图** | 把人物画进场景参考图，破坏"空间图无人物"铁律 |
| 关联道具 | 用道具表 asset_id；区分"场景固定陈设"与"角色随身道具"（后者归道具表） | 把随身道具锁进场景 L1 |
| 出现镜头组 | 分镜定稿后回填组号，形成双向链 | 留空导致上下游脱钩 |
| 被引用于 | 指明分镜「场景」字段与「连续性锁定」中本 ID 的落点，便于改 L2 时定位所有受影响镜头 | 不回填，L2 变更无法批量核对 |

### 5. 输出前自检（内部跑，绝不写进成片）

1. **ID 唯一性**：每条目恰一个 `[Element_*]`；同空间多状态共享 `<Space>` 根并显式声明承接。
2. **L1/L2 全标注**：每条锚定项均带 `[L1]`/`[L2]`；未标项按 L1 处理；L2 项均给了"可变方向"。
3. **参数齐全**：主光有方向+色温K+亮度%+光比；焦点区有 Focus(X,Y)；内/外+时段齐；画幅已声明；主导色相约 90% 已量化。
4. **母色与功能落地**：每场景有单一氛围母色 + 明确情绪功能，未写成情绪空话。
5. **空间图纪律**：场景参考资产（含 §3.5 四视图）无人物、无文字水印Logo（剧情屏幕文字除外，引号包裹）。
6. **风格锚点**：风格字段带具体影片/作者锚（非泛词）。
7. **绑定优先**：用户已有素材已直接绑定不重生；同空间多状态走 ImageToImage 链参考基态四视图。
8. **交叉引用闭环**：出场角色/道具用对应表的 asset_id；出现镜头组与分镜双向可查。
9. **反向锚定**：质量和禁止含场景专属反向（禁人物入画/禁可读Logo车牌/禁第二空间穿帮/禁光位跳变/禁霓虹红蓝撞色）。
10. **引擎隐身**：全表零 Polanyi/默会/格式塔/寓居/方法论/支柱编号字样，仅创作语言与参数。
11. **题材原创**：未搬运契约样例的具体场景/陈设到用户当前剧本。

> 与分镜契约同纪律：本 §5 检查只在内部跑，**不得**作为脚注（"自检确认✓""母色已锁"之类）写进最终场景表——那本身就是引擎泄漏。

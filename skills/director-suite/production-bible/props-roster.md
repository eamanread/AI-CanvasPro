# 道具表（Props Roster · 制片圣经）输出字段契约 v1.0

> 制片圣经上游表 · 服务分镜表的「连续性锁定」· 时长制 v2.0 配套
> 与《分镜脚本输出字段契约 v2.0》同源同规：参数优先于形容词、引擎隐身、自检不外显。

---

## 0. 总则（与分镜契约共用的铁律）

- **本表是「制片圣经」的上游锚定表**：道具一次定义、全片复用。分镜表「镜头组」的 `连续性锁定` 字段以本表的 `asset_id` 为唯一引用键；道具的形/色/材/态在本表锁死后，分镜里不重述、只引用，从根上杜绝跨镜漂移。
- **参数优先于形容词**：可量化维度（尺寸 cm / 色值 HEX 或 Pantone / 材质粗糙度 / 数量 / 温度感 K）一律写 **数值或标准值**，形容词仅作补充。"很旧的刀"→"刃口 3 处缺口、刀身氧化发黑、木柄裂纹 2 道"。
- **图中不出文字**：道具元素图为求画面整洁，**不生成任何文字/可读品牌/Logo/车牌**（除非该文字本身是叙事道具，须在 `状态变化轴` 显式声明并锁定字形）。
- **先绑定后生成**：用户已提供的道具/产品图，直接绑定为该条目的 `asset_id`，描述必须与该资产**匹配、不矛盾**，**不重复生成**；仅当全片无任何已有资产覆盖时才新建并 TextToImage。
- **自检不外显**：本契约 §8 的自检清单只在内部跑，**绝不写进成片道具表**；成片表里不出现任何过程/审计/方法论字样。

## 1. 一致性等级（每条目必标 · 本表的承重墙）

每个道具条目**必须**标注一致性等级，决定它在分镜「连续性锁定」里如何被对待：

| 等级 | 名称 | 含义 | 在分镜中的待遇 | 典型 |
|---|---|---|---|---|
| **L1** | 硬锚 · 不可变 | 全片外观**恒定不变**的身份锚。形/色/材/标记跨镜一字不改。 | 进每个出现镜头组的 `连续性锁定` 硬锚区，**任何镜头不得改写**；漂移即废稿。 | 主角随身佩戴的旧怀表、品牌产品 SKU、一把贯穿全片的枪 |
| **L2** | 软锚 · 随剧情可变 | 外观**会随叙事改变**（被点燃、被摔碎、被血染、被启用），但**变化必须沿预定义的「状态变化轴」逐态发生**、且每态都被锁定。 | 进 `连续性锁定` 时**必须显式声明当前态**（"本组起：烟头已摁灭成灰白，承上组镜X末态"），相邻镜头首尾帧须校验状态衔接。 | 烟灰缸里的烟（亮→摁灭）、酒杯（满→半→空）、手机屏（亮→熄）、伤口、蜡烛（高→将熄） |

> **铁律**：L2 道具的变化**只能在 `状态变化轴` 已登记的节点上发生**；分镜里出现「未登记的突变」（上镜满杯、下镜空杯却无中间饮用动作）= 连续性破口，废稿。L2 不等于"随便变"，等于"按账本变"。

## 2. asset_id 命名规范

格式：`[Prop_<语义名>_<两位序号>]`，与分镜里的 `[Element_*]` / `<<<image_n>>>` 引用体系同构、可直接互引。

| 规则 | 说明 | 正例 | 反例 |
|---|---|---|---|
| 前缀 `Prop_` | 区分于角色 `[Element_角色]`、场景 `[Element_场景]` | `[Prop_Ashtray_01]` | `[烟灰缸]`（无前缀无ID） |
| 语义名 | 英文/拼音，表"是什么"，全片唯一不重名 | `[Prop_Wristwatch_Heirloom]` | `[Prop_Thing_01]`（语义空洞） |
| 序号 | 同类多件时区分（两把同款椅 → `_01/_02`） | `[Prop_WineGlass_Host]` | 同名两件共用一个ID |
| 多状态同 ID | **同一道具的不同状态不拆新 ID**，用 `状态变化轴` 的 `态1/态2` 区分（同角色多 Look 思路） | `[Prop_Cigarette_01]` 态1点燃 / 态2摁灭 | `[Prop_Cig_Lit]` + `[Prop_Cig_Out]` 拆两条 |
| 焦点 vs 从属 | 只为**关键道具**（契诃夫之枪 / 情绪钩子）建独立条目；纯环境陈设并入场景表，不单列 | 主角的怀表单列 | 包厢里每个酒瓶都单列 |

## 3. 字段表（逐字段：填写规范 / 允许值 / 常见错误）

固定结构与顺序（每条目一块）：

```
[Prop_语义名_NN]  道具名（中文）   一致性等级：L1 / L2
├ 类别：           叙事道具 / 情绪钩子 / 环境陈设(从属) / 产品SKU
├ 形状 shape：      几何描述 + 关键尺寸(cm)
├ 材质 material：   材质名 + 表面特征(粗糙/反光/纹理)
├ 颜色 color：      主色 HEX 或 Pantone（+辅色）
├ 尺寸 size：       长×宽×高 cm，或相对比例
├ 状况 condition：  new / used / weathered / damaged + 具体损耗描述
├ 独特标记 markings：可辨识锚点（刻痕/缺口/Logo位/纹章），无则写"无"
├ 气场/潜台词 aura：（仅叙事道具/情绪钩子）该物的情绪基调，非外形
├ 状态变化轴 state-axis：（L2必填 / L1写"恒定不变"）出现→使用→变化逐态
├ 归属 owner：      绑定角色 [Element_角色] / 无主(场景物)
├ 出现场景 scenes： S1 / S3 …（交叉引用场景表）
├ 出现镜头 shots：  组-镜号清单（交叉引用分镜表）
├ 空间锚点 anchor： 在场景中的位置+朝向（尤其表演区内）
├ asset 绑定：      用户图 / TextToImage(模型@分辨率) / ImageToImage 链
└ 图中禁止：        no text / no logo / no watermark …
```

| 字段 | 填写规范 / 允许值 | 常见错误 |
|---|---|---|
| **一致性等级** | `L1` 或 `L2` 二选一，必填 | 漏标；写"基本不变"等模糊态 |
| **类别** | `叙事道具`（推动剧情）/`情绪钩子`（承载潜台词）/`环境陈设`（从属，一般不单列）/`产品SKU` | 把环境陈设也单列成条目，表臃肿 |
| **形状 shape** | 几何名+**关键尺寸 cm**（"圆形烟灰缸 直径 14cm 深 3cm"） | 只写"一个烟灰缸"；无尺寸 |
| **材质 material** | 材质名+**表面特征**（"磨砂黑陶，哑光，微孔粗糙面"） | 只写"陶瓷"；无反光/粗糙度 |
| **颜色 color** | **HEX/Pantone** 主色（+辅色）；"暗橙余烬 #C3622A" | 写"很有质感的颜色"；纯形容词 |
| **尺寸 size** | `长×宽×高 cm` 或相对参照（"约手掌大"） | 与 shape 尺寸打架；缺单位 |
| **状况 condition** | `new/used/weathered/damaged` **+具体损耗**（"used：边缘 2 处磕碰、底部茶渍环"） | 只写 `old`；无具体可成像损耗 |
| **独特标记 markings** | 跨镜**认得出同一件**的辨识锚（"柄上刻 'L.C.' 二字母、刃口第 3 节缺口"）；无则"无" | 留空；写"看起来很特别" |
| **气场/潜台词 aura** | 仅叙事道具/情绪钩子填：该物的**情绪基调**（"宿命感的沉重 / 被遗忘的温度"），描述"态"非"形" | 给环境陈设硬安气场；或把外形当气场 |
| **状态变化轴 state-axis** | **L2 必填**：`态1出现→态2使用→态N变化`，每态写**触发动作+外观差**+发生镜号；L1 写"恒定不变，全片同一外观" | L2 漏填轴；轴上有未登记的突变；变化无触发动作 |
| **归属 owner** | `[Element_角色]` 或 `无主(场景物)`；可多主（传递道具标全程持有链） | 不写归属；传递道具只标首位持有者 |
| **出现场景 scenes** | 场景表 ID 清单 `S1/S3`（交叉引用） | 写"在好几个场景" |
| **出现镜头 shots** | `组-镜` 清单 `1-2/6-3/9-4`（交叉引用分镜表，**双向可查**） | 留空，使连续性无法定位 |
| **空间锚点 anchor** | 在场景中的**位置+朝向**，尤其"主要动作/表演区域"内的道具（"置红木圆桌右前、桌沿外缘、朝主位赵山河"） | 不写朝向；不标是否在表演区 |
| **asset 绑定** | `用户图`（直接绑，不重生）/ `TextToImage Nano Banana 2 @2K` / 多态用 `ImageToImage 链参考态1` | 同道具多态各自重画不走参考链 |
| **图中禁止** | `no text/no logo/no watermark/no readable brand`（除非文字即叙事道具） | 漏禁文字，元素图混入水印 |

## 4. 默会要点（本表的灵魂 · 非机械罗列名词）

> 道具表的价值不在"把画面里每件东西列全"，而在**只锁那几件真正承重的物**，并替它们写好"命运"。以下是识别与锁定的内部手感，**只用于推理，不写进成片表**。

### 4.1 识别「契诃夫之枪」式叙事道具（焦点 vs 从属的第一刀）

一件道具值不值得单列、要不要建独立条目，先过三问：

1. **它被「使用」还是只是「在场」？** 在表演区被角色拿起/给出/启用/摧毁的 = 焦点候选；只在背景陈设、不参与动作的 = 从属，并入场景表。
2. **它若消失，剧情会不会缺一块？** 第一幕墙上挂的枪，第三幕必须响——若一件道具在后续被**回收**（被用、被提、被变），它就是叙事道具，必入表并锁全程。**反之，只为氛围存在、永不回收的，不单列。**
3. **它有没有「潜台词」？** 一件物若被镜头**反复给到**、或承担"说不出口的东西"（摩挲的手机=焦虑的出口、摁灭的烟=被压下的警告、将熄的烛=将尽的局），它就是**情绪钩子**——即使它从不被"使用"，也要单列并在 `气场/潜台词` 写明，因为它替台词扛了戏。

> 判别口诀（内部）：**会被回收的物，会被反复凝视的物，会改变状态的物——这三类才单列；其余归景。** 一张道具表若列满了"桌、椅、杯、瓶"，多半是把环境当道具了，回炉。

### 4.2 锁定「状态变化轴」（出现 → 使用 → 变化）

这是 L2 道具的**命脉**，也是连续性锁定能不漂的根。每个 L2 道具都要写一条**单向、可校验**的状态时间线：

- **出现态（态1）**：该物首次入画时的外观（满杯的酒 / 点燃的烟 / 亮屏的手机 / 完好的刀）。锁形锁色，作为后续所有态的参照底。
- **使用态（态2…）**：被角色"动用"的中间态，**每一次状态跃迁必须挂一个触发动作 + 发生镜号**（"镜1-2 王凯拇指碾压 → 烟头熄成灰白"）。**没有触发动作的状态变化 = 穿帮**。
- **变化态（态N）**：剧情终局的样子（空杯 / 灰白烟头 / 熄屏 / 缺口的刀）。它常与开篇态形成对照，是导演的"暗号"。

落地约束：
- 轴上相邻两态之间，分镜的**首尾帧必须能衔接**——上一镜末帧的道具态 = 下一镜初始锚点态，否则回退重生成或加一个过渡镜引回。
- L2 道具进每个出现镜头组的 `连续性锁定` 时，**显式声明"本组该物处于态X"**（如"道具状态：烟灰缸内烟头已摁灭成灰白，承上组镜1-2末态"）。
- L1 道具的"状态变化轴"恒等于"恒定不变"——它的存在本身就是稳定的锚，**任何镜头试图改它的形/色/材都是错**。

## 5. 交叉引用字段（本表如何被其它表挂接）

道具表是**双向可查的枢纽**，靠以下字段与其它制片圣经表互锁：

| 交叉字段 | 指向 | 作用 |
|---|---|---|
| `归属 owner` | → **角色表** `[Element_角色]` | 谁拿着什么；传递道具记全程持有链，校验"相邻镜手持物连贯" |
| `出现场景 scenes` | → **场景表** `S1/S3` | 道具在哪几个时空出现；并据此判断跨场景是否需带走/留下 |
| `出现镜头 shots` | → **分镜表** `组-镜号` | 精确定位；分镜「连续性锁定」反向引用本表 `asset_id` 锁外观与态 |
| `空间锚点 anchor` | → **场景表/分镜构图** | 道具在场景里的位置+朝向，喂分镜的"前景/中景"与表演区调度 |
| `状态变化轴` 各态镜号 | → **分镜首尾帧校验** | 每次状态跃迁的镜号，供首尾帧衔接审计 |
| `asset 绑定 id` | → **生成工具 media_generator** | 先绑定后生成；分镜参考输入 `<<<image_n>>>` 引同一资产 |

> 引用方向铁律：**道具表定义，分镜表引用**。分镜「连续性锁定」里写道具时，只写 `asset_id + 当前态`，**不重述外观**——外观的唯一事实源在本表。

## 7. 输出前自检（内部跑 · 绝不写进成片表）

1. **等级齐备**：每条目均标 L1/L2；L2 均有 `状态变化轴`，L1 写"恒定不变"。
2. **焦点过滤**：单列的都是叙事道具/情绪钩子/产品SKU；纯环境陈设已归场景表，表未被名词堆臃肿。
3. **参数优先**：形/色/材/尺寸均有数值或标准值（HEX/cm/Pantone），形容词仅补充。
4. **状态轴可校验**：每次状态跃迁挂触发动作+镜号；轴单向无未登记突变；相邻态首尾帧可衔接。
5. **交叉引用闭环**：owner/scenes/shots/anchor 四向齐全且与角色表/场景表/分镜表 ID 对得上、双向可查。
6. **图中无字**：每条 `图中禁止` 覆盖 no text/logo/watermark（叙事文字道具除外且已显式锁字形）。
7. **绑定优先**：用户已有资产已直接绑定不重生；多态走 ImageToImage 链而非各自重画。
8. **引擎隐身**：成片表零 哲学/默会/方法论/契诃夫术语字样，只剩道具决策与参数。
9. **自检不外显**：本 §7 只在内部跑，**绝不**在成片道具表里附"自检确认/✓"之类脚注——那本身就是泄漏。

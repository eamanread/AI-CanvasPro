# 分镜脚本输出字段契约 v2.0（时长制 · 场景→镜头组→镜头）

> v2.0 相对 v1.0 的根本变化：**用「时长」不用绝对时间码**；**场景级锁定字段上提到「镜头组」**（不再每镜重复）；**镜头组 = 一个视频模型生成单元，镜头 = 组内镜内分切**。本契约在保留用户给定字段结构与顺序的前提下补全规范，目标是产出可直接驱动 Seedance 2.0 的"优质哇塞提示词"。

---

## 0. 总则

- **写实优先**：默认 8K 真人写实，禁 CG/卡通/插画质感（除非风格核心锁定另行声明）。
- **参数优先于形容词**：可量化维度（焦段/光圈/色温K/亮度%/光比/声压级dB/频率Hz/时长s）一律写**数值+单位**，形容词仅作补充。
- **时长制，不写绝对时间码**：组与镜都只写「时长：Xs」。全片连续性靠"切镜方式"衔接，不靠时间码自洽——从根上避免跨段时间码裂缝。
- **强制映射不可违反**：景别/运镜遵下方两表强制项；违反即废稿（破格须显式标注动机）。

## 1. 拆分规则（按场景 → 镜头组 → 镜头）

> **核心：先按场景切，场景太长再按节奏切。一个场景通常拆成好几个镜头组。**

| 层级 | 是什么 | 时长 | 构成 |
|---|---|---|---|
| **场景 Scene** | 同一时空（地点+日夜+内外）的连续戏 | 不限 | 1 个场景 → 若干镜头组 |
| **镜头组 Shot Group** | **= 一个视频模型生成单元**（Seedance 单次 4–15s） | **约 10–15s**（短场景可 2–3 镜更短） | **通常 4–7 个镜头** |
| **镜头 Shot** | 组内的一次**镜内分切**（剪辑切点） | 约 1.5–5s（由情绪强度+节奏定） | 一个景别/机位/动作单元 |

**拆分要用默会知识，不要机械切：**
- 先读懂这场戏的情绪节拍（beat），在"情绪/视点/动作发生转折"处下切点，而不是按秒平均分。
- 一个镜头只表达一个观点；景别相同可合并、不同则切。
- **长对白镜的时长很难精确估**：按"语速×字数"给一个**估值**并标注 `≈` 或"(估)"，不要假装精确到帧；宁可给区间（如"约 6–8s"）。Seedance 会按节拍执行，不按钟表。
- 组内镜数与时长服务情绪：铺陈组可少而长，高潮组可多而短促；但**整组时长须落在生成单元 10–15s 内**（超了就拆成下一组）。

## 2. 映射表（先判强度，再选景别/运镜）

### 2.1 景别-情绪映射表（情绪强度 0–5 级）

| 情绪强度 | 含义 | 强制景别 | 可选景别 | 时长基准* |
|---|---|---|---|---|
| 0 | 中性/交代 | 大全景 / 全景 | 中全景 | 4–6s |
| 1 | 轻微 | 全景 | 中全景 / 中景 | 3–5s |
| 2 | 平稳叙事 | 中景 | 中全景 / 中近景 | 3–4s |
| 3 | 情绪上升 | 中近景 | 近景 | 2–3s |
| 4 | 强情绪 | 近景 | 特写 | 1.5–2.5s |
| 5 | 极致爆发/决定性瞬间 | 特写 / 大特写 | 近景（仅作切出） | 0.8–2s（或反向超长凝视） |

> *\*「时长基准」= **剪辑切点的相对节奏参照**（情绪越强、切点越密），**不是生成时长**。见 §5「双时长观」。
**禁止（强制）**：情绪 5 级用中景及更松；情绪 ≤2 级无叙事理由用特写/大特写；情绪强度跳级一步到位（应阶梯递进，或显式"反差爆破镜"破格）。

### 2.2 运镜与情绪映射表

| 运镜手法 | 情绪/叙事功能 | 适用场景 |
|---|---|---|
| 推 Push In | 聚焦、情绪逼近、内心收紧 | 揭示、顿悟、压迫升级 |
| 拉 Pull Out | 抽离、孤独、关系释放、收尾 | 段落收束、情绪余韵、环境揭示 |
| 跟前 Lead | 引导、前进感、目标明确 | 人物前行、追逐前段 |
| 跟后 Follow | 跟随、悬念、未知前路 | 探索、跟踪、危机逼近 |
| 环绕 Orbit | 强调、关系交织、时间凝滞 | 对峙、拥抱、决定性独白 |
| 手持 Handheld | 不安、真实、临场紧张 | 武戏、混乱、纪实感 |
| 斯坦尼康 Steadicam | 流畅穿行、沉浸跟随 | 长镜穿场、连续空间转换 |

## 3. 「镜头组」字段规范（场景级锁定，一组写一次）

固定结构与顺序（**这些字段只在组头写一次，组内各镜不再重复**）：

```
镜头组N 时长：Xs
场景：地点 + 日/夜 + 内/外 + 环境氛围
风格核心锁定：<一句话定全片基调，跨组一致>
视觉基调锁定：<画面整体感受+质感>
色彩影调锁定：<主色 + 对比 + 饱和度倾向 + 暗部走向>
连续性锁定：<逐项列需保持/变化项：角色造型/道具/空间锚点/主光方向/天气…，用 ／ 分隔>
情绪强度：N（命名）   ← 该组主导强度(0–5)；组内各镜可微浮动，景别按各镜强度查表
质量和禁止：
  正向：<分辨率/质感/真实度>
  反向（禁止）：<逐类列负面约束>
```

| 字段 | 规范 / 允许值 | 常见错误 |
|---|---|---|
| 镜头组N 时长 | `镜头组3 时长：12s`，时长落在 10–15s 生成单元内 | 超 15s 不拆组 |
| 场景 | 四要素齐全：地点+日/夜+内/外+环境 | 缺日夜或内外 |
| 风格核心锁定 | 全片一致的基调锚，跨组不漂 | 每组漂移 |
| 视觉基调锁定 | 形容词组+质感 | 与色彩影调冲突 |
| 色彩影调锁定 | 主色+对比+饱和+暗部 | 只写"高级灰"等空话 |
| 连续性锁定 | 逐项具体，跨组承接处显式声明变化（"承上组""本组起…"） | 写"同上"而不列项 |
| 情绪强度 | 0–5 整数 + 命名（如 `4（强情绪）`） | 与组内镜景别系统性矛盾 |
| 质量和禁止 | 正向+反向两段，反向覆盖：渲染失真/风格越界/解剖结构/画质瑕疵/一致性（见 §6） | 只写正向；反向笼统 |

## 4. 「镜头」字段规范（镜内分切，逐镜写）

固定结构与顺序：

```
镜头N-M 时长：Xs  主情绪：<该镜主导情绪>  节奏：<文戏/武戏/混合 或 缓/中/急>
景别：<档位>（遵情绪X→景别）
镜头（相机）：焦段 XXmm / 光圈 fX.X / 镜头型号 XXX / 颗粒 XX / 动态模糊 XX / 呼吸感 XX
运镜：<手法>——<叙事意图>；<物理描述：起止位移/速度感>
构图：方式 XX；前景 XX；中景 XX；背景 XX；起幅 XX；落幅 XX
光影：
  主光：色温 XK / 亮度 X% / 作用：XX / 区域：XX
  辅光：…  轮廓光：…  发丝光：…  柔光镜：强度 X / 作用：XX / 区域：XX
画面内容：
  画面描述：<可成像的具象主体+动作+环境关系>
  台词：「…」【音色：X / 语速：X / 情感：X】（无台词写"台词：无"）
  动作与微表情：<可观察的肌肉/肢体动作：眉峰/嘴角/指节/呼吸…>
音效：<声源 + 频率/频段 + 时长 + 声压级dB + 调制/包络 + 声像/空间>
切镜方式：<本镜如何切到下一镜>
```

### 4.1 镜头头行三参数
- **时长**：`Xs` 或区间 `约X–Ys`/`≈Xs`（长对白用估值，见 §1）。
- **主情绪**：该镜此刻的**单一**主导情绪（与组主情绪锚一致，可带暗流）。
- **节奏**：`文戏/武戏/混合`，或配速 `缓/中/急`；用于校验切点密度与景别/时长是否自洽。

### 4.2 「镜头（相机）」子规范
焦段 `14/24/35/50/85/100/135mm` 等具体值（广角夸张透视、长焦压缩空间，须与景别/情绪自洽）｜光圈 `f1.2~f16`（浅景深 f1.2–2.8，交代环境 f5.6+）｜镜头型号 具体型号或质感｜颗粒 无/轻微35mm/中等｜动态模糊 无/轻微/自然180°快门/强拖影｜呼吸感 无/轻微/明显。**禁**焦段与景别打架（特写却 14mm）、浅景深却要求背景全清。

### 4.3 「光影」分层规范
必须**分层**，每层独立成行，至少 `色温K + 亮度% + 作用 + 区域`，**主光必填；辅光/轮廓光/发丝光/柔光镜为按需层，有则写、无则省**（如本节末样例两镜未用发丝光；fewshot 中需要勾发时再加）。色温 2700K(暖钨)–7500K(冷蓝)；亮度% 主光 60–100/辅光 20–50/轮廓发丝 40–70/柔光镜以"强度 弱/中/强"计；作用写"做什么"(塑形/补暗/勾边/提质感/弥散)非"好看"；区域(车内外/画面分区/左右)必须明确。**禁**只写"柔和光线"、缺色温或亮度、不分层。

### 4.4 「画面内容」三段式
1. **画面描述**：具象名词+动词，禁抽象情绪词单独成句（"他很悲伤"→"他垂眼、下颌紧绷、泪未落"）。
2. **台词**：每句紧跟 `【音色 + 语速 + 情感】`，音色含性别+质地(+参考音色编号)，语速含快慢+尾音处理，情感与本镜主情绪一致；无台词写"台词：无"。
3. **动作与微表情**：分解为可观察的肌肉/肢体动作，禁只写情绪标签。

### 4.5 「音效」数字化
`声源 + 频率/频段(Hz/kHz) + 时长(ms/s) + 声压级(-XX dBFS或弱/中/强) + 调制/包络(渐入渐出/脉冲/混响X.Xs衰减) + 声像/空间(L/R/C、近/远、干/湿)`。**禁**只写"紧张配乐/砰的一声"。

### 4.6 「切镜方式」（新增 · 衔接到下一镜/下一组）
允许值：`硬切/直切`｜`叠化(dissolve)`｜`匹配剪辑(match cut)`｜`动作匹配`｜`视线匹配(eyeline)`｜`J-cut(声音先入)`｜`L-cut(声音延留)`｜`淡入/淡出`｜`黑场`｜`甩切(whip)`｜`定格`。**组内**镜间多用硬切/动作匹配/视线匹配；**组尾**镜写明切到下一组的方式（叠化/匹配/硬切/黑场）。情绪余韵段宜叠化/淡出，紧张段宜硬切。

## 5. 双时长观调和（D1 · 关键）

> 这是 v1.0 最大的内在矛盾，v2.0 在结构上解决：

- **生成时长观**：**镜头组 = 视频模型一次生成的片段**，统一落在 **Seedance 4–15s** 窗口（推荐 10–15s）。这是真正喂给模型的 clip 长度。
- **剪辑时长观**：**镜头(镜内分切) = 这个 10–15s clip 内部的剪辑切点**，单镜常见 1.5–5s（**铺陈/留白长镜可更长，见 §2 表时长基准列**），§2 的"时长基准"是它的**节奏参照**（情绪越强切点越密），**不是**单独去生成 1.5s 的片段。
- **执行**：一个镜头组 = 一条 Seedance prompt（多机位/镜内切换，用过渡词与"切镜方式"串联），**不要**把组内每个 1.5–3s 镜各自单独生成（碎、贵、不连贯，且低于 Seedance 4s 下限）。
- **校验**：`Σ(组内各镜时长) ≈ 镜头组时长`（容差 ±1s）；组时长 ∈ [4,15]。
- **长对白**：用默会估时，给 `≈` 或区间，不假装精确；若一句长台词撑过组上限，按语义停顿拆到下一组。

## 6. 「质量和禁止 / 反向锚定」（组级）

正向：`8K、真人写实、皮肤毛孔级、自然胶片质感、物理正确光影`。
反向（禁止）逐类覆盖：渲染失真`CG感/3D渲染/塑料皮肤/过度磨皮`｜风格越界`卡通/插画/动漫/油画感`(除非风格核心声明)｜解剖结构`多指畸形手/脸崩/不对称眼`｜画质瑕疵`噪点过载/过曝死白/欠曝死黑/水印文字/低分辨率`｜一致性`造型漂移/光位跳变`。**禁**只写正向、反向笼统、与风格核心锁定冲突。

## 7. 输出前自检（必须逐条过）

1. **时长自洽**：每组 Σ镜时长 ≈ 组时长(±1s)；组时长 ∈[4,15]；长对白镜已标 `≈`/区间。
2. **场景锁定不重复**：风格核心/视觉基调/色彩影调/连续性/质量禁止 只在组头，组内各镜未重复堆。
3. **景别-情绪强制项**：无 5 级中景、无 ≤2 级无理由特写；破格已标动机。
4. **字段自洽**：每镜头头行含 时长+主情绪+节奏；每镜含 切镜方式；光影分层含色温K+亮度%+区域；台词带三参数。
5. **连续性**：跨组承接处显式声明（承上组/本组起…）；硬锚点(角色造型/主光方向/关键道具)不漂。
6. **引擎隐身**：输出零 哲学术语/Polanyi/默会/格式塔/寓居/方法论/支柱编号。
7. **题材原创**：未搬运任何示例/参考片的具体题材/场景/台词。
8. **自检不外显**：本 §7 的检查与任何"过程/审计/自检确认"清单**只在内部跑，绝不写进最终镜头卡**（它属于过程，不属于成片）。**禁止**在组尾或镜尾附"自检确认：…""Σ镜时长=…""引擎隐身✓"之类的脚注——那本身就是引擎泄漏。镜头卡里也不要写"（默会领悟）""（格式塔）"等括注，改用纯创作语言（如"无声领悟"）。
9. **输出完整性**：每个镜头组**恰有一段** Seedance 2.0 成片提示词（不多不少）；每镜字段齐全、无空字段。

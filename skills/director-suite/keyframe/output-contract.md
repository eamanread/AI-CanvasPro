## 关键帧卡输出字段契约 v1.0（director-suite · keyframe 成员 · 皮③）

> 本契约定义"关键帧卡"的字段结构、顺序、锁定项、一致性规则与负面约束，目标是产出可直接驱动**图像模型(GPT-Image-2 / Nano Banana Pro 等)**、用于**视频生成首尾帧锚定与动作落点控制**的高精度单帧电影提示词。所有字段均为**强约束**，未标注"可选"者必填；缺项视为不合格。
> 与分镜契约的关系：分镜契约产出"一段镜头的镜头卡"；本契约产出"一段镜头中**某一瞬间的单帧**"。本契约**继承**分镜契约的底层约束（写实优先、参数优先于形容词、连续性锁定、强制映射不可违反），并在其上补"单帧专属"约束（时间轴位置、唯一主焦点、动作落点、运动模糊、参考硬继承）。

---

### 0. 总则与底层约束

- **单帧、非序列**：输出的是一张静帧，但它在视频时间轴上有明确位置；必须让人**从单帧就读出**这是首帧(将动)/中间帧(正动)/高潮帧(冲击)/反应帧(落点)/尾帧(已动完)。
- **唯一主焦点**：每帧只有一个主焦点，其余元素为从属线索；焦点是表情则背景不抢脸，焦点是动作冲击则表情/环境支持动作方向，焦点是世界观揭示则人物比例/建筑/光影建立尺度，焦点是空间关系则写清前/中/背景与主体—目标距离方向。
- **写实优先**：默认 8K 真人写实 photorealistic film still，禁 CG/3D 渲染/游戏画面/AI 插画感（除非风格核心另行声明）。
- **参数优先于形容词**：焦段/光圈/画幅/机位距离与角度/色温/HEX/运动模糊方向与强度/动作幅度角度——一律**数值+单位**，形容词仅作补充。
- **硬锚点 ≠ 可变氛围**：必须显式区分"不可改的硬锚点"(角色身份/脸/服装/道具/色卡 HEX/分镜焦点与动作方向)与"可随本帧自然变化的氛围"(本帧光影/尘埃/同一颜色在高光阴影中的视觉变化)。
- **不得改剧情**：不得为画面漂亮而改角色、空间关系或动作因果；不得加剧本无支撑的武器/伤痕/特效/载具/姿态/情绪。
- **强制映射不可违反**：情绪强度↔景别、运镜↔情绪 遵 `../_shared/mapping-tables.md` 强制项；违反即废帧。

### 1. 关键帧类型与时间轴定位（写卡前先定）

写卡前必须先锁定四项，写入【用途】：

| 项 | 取值 / 规范 |
|---|---|
| 关键帧类型 | 首帧 / 中间帧 / 高潮帧 / 反应帧 / 尾帧 / 角色魅力帧（单选） |
| 时间轴位置 | 服务的视频段总时长 + 本帧所在秒点，如 `4–15s 环绕镜头视频的尾帧 / 约第 11 秒收手瞬间` |
| 服务对象 | 服务哪个镜头/视频段；是否作该段的 start_frame / end_frame |
| 承接关系 | 本帧之前/之后发生什么；是否承接上一帧、分镜卡、角色卡、色卡 |

**选帧铁律**：首帧=动作将发生(非已结束)；中间帧=动作正在进行(有方向感)；高潮帧=冲击瞬间(落点+心理转折同时成立)；反应帧=情绪压住但即将泄露(非最夸张表情)；尾帧=动作已完成且为下镜留承接；魅力帧=冷静控制、危险但不吼叫。

### 2. 参考与硬继承锁定（REFERENCE LOCK）

**核心规则**：用户给的每一份资产逐条写清"锚定用途 + 必须继承的元素 + 不可改变的硬锚点 + 仅作风格参考的部分"。不得只写"参考这张图"。

固定写法：
```
@[reference_id]  作为[角色/场景/道具/色卡/镜头]的视觉锚定 + 必须继承[具体元素] + 不可改变[硬锚点] (+ 仅作风格参考[软约束])
```

| 资产类型 | 必须锁定的内容 |
|---|---|
| 角色设定板 | 身份、脸部结构/五官、发型、服装、配件、道具、伤痕、比例、姿态锚点 |
| 场景色卡 | 哪些 HEX 必须继承 + 各自归属(角色色/环境色/光线色/特效色/阴影色/高光色)；允许因胶片/尘埃/运动模糊产生轻微视觉变化 |
| 导演分镜卡 | 机位、焦点、景别、动作方向、时间点 |
| 上一帧/下一帧 | 姿态/服装/环境/光线/动量的承接点 |
| 参考图 ID | 该图锚定谁/什么、继承项、不可变项 |

**无参考图时**：写"无外部参考图，仅根据剧本/镜头卡文字锁定"，并把角色/场景/色彩特征用文字钉死；**绝不虚构参考图 ID 或 HEX**。
**冲突处理**：参考图、色卡、角色卡、分镜卡之间不得互相冲突；冲突时以"分镜卡的时间轴语义 + 角色卡的身份 + 色卡的世界观色"为优先，并在【用途】注明取舍。

#### 3.1 「镜头与机位」子规范

固定书写：
```
Camera: 摄影机/胶片或传感器风格
Lens: 焦段XXmm + 投影(rectilinear/无桶形畸变 或 允许广角变形并控制)
Frame: 画幅(默认 16:9 horizontal cinematic single frame)
Camera position: 机位高度 + 距主体距离(约X米)
Camera angle: 俯/平/仰 + 角度(如 slight low angle ~5°)
Projection: lens projection 说明(是否允许 barrel distortion / fisheye)
Distance: 景别对应的取景距离
Motion context: 本帧是静态图，但来自怎样的视频运动过程(运镜+速度)
```
- 表情特写/魅力帧优先 50mm / 85mm 肖像焦段，**谨慎广角防脸畸变**；动作冲击帧可用更广角但须控制变形。
- 焦段须与景别/情绪自洽（特写却写 14mm = 废）；浅景深(f1.2)不可要求背景全清。
- **Motion context 必填**：这是关键帧与普通静帧的分水岭——必须写"这一帧是从怎样的视频运动中冻结出来的"。

#### 3.2 「动作瞬间 / 关键帧状态」子规范

按固定顺序写，缺一不可：
1. **动作时间点**：起始 / 进行 / 冲击 / 落点 / 收束（与【用途】的关键帧类型一致）。
2. **身体力学**：身体重心、手部位置、脚步/姿态、道具位置。
3. **物理响应**：衣料/头发/尘土/水花/烟雾/火光/机械部件如何响应该动作（"冻结在中间的一帧"而非长动作）。
4. **运动模糊**：方向 + 强度(轻微/中等/强 或 角度) + **模糊后仍必须可识别的关键元素**。
5. **前后承接**：这帧如何承接前一帧/后一帧（动量守恒、视线轴对齐）。

#### 3.3 「面部表情」三层规范（露脸时）

1. **可观察肌肉/部位**：眼神方向 + 眉骨状态 + 嘴角角度(可量化，如上扬约5–10°) + 唇(闭/微启/是否露齿) + 下颌 + 鼻翼 + 颈肩张力 + 呼吸状态。
2. **情绪强度与方向**：外放 or 压住；情绪强度等级；潜台词一句（如"猎物已是我的"）。
3. **绝不允许的错误表情**：显式列出本帧禁止的表情（如 NOT a Joker grin / NOT 咆哮 / NOT 张牙舞爪 / NOT 瞪眼），防模型跑偏。

### 4. 一致性规则（跨帧/跨资产硬约束）

- **主体身份连续**：同一角色不得因光影/角度/表情变化而变成另一个人；脸部结构、服装、道具、伤痕严格继承角色卡/参考图。
- **色卡连续**：所有色彩严格继承色卡 HEX 与归属；只允许同一颜色在高光/阴影/尘埃/运动模糊中的**自然视觉变化**，不允许偏离色板。
- **空间连续**：背景空间关系不得与剧本/分镜矛盾；主体—目标的距离方向须与时间轴语义一致（如尾帧表现"已逼近"则背景目标须比建立镜头更大更近）。
- **动量连续**：首帧的"将动"动量 = 上一镜尾帧动量；尾帧的视觉重心/视线轴 = 下一镜首帧，消除切镜跳跃。
- **首尾成对**：同一镜头若需首+尾两帧，二者必须显式声明承接关系（动作从"将发生"到"已完成"、同一光位、同一色卡、同一角色状态线）。

---

### 5. 留白与下注（防"参数清单化")

- **不可言尽的气场靠综合**：嘴角/眉/眼可描述，但气场来自整体姿态+光影+空间+叙事压力；写到"半明半暗结构""克制细节"，不把气场解释干净。
- **背景是证据不是装饰**：背景元素必须证明剧情进展（目标船更近了/沙艇被超过了），而非随机漂亮。
- **一次导演性发现**：每帧内部至少找一个发现（一个概括命运的表情/一个揭示权力关系的构图比例/一个让空间进展突然清楚的背景证据/一个让动作仍在继续的风尘衣料），靠克制细节而非夸张表情产生力量。

### 6. 「关键约束 / 反向锚定」书写规范（必填）

**结构**：先按类别写**强铁律**，再写**负面约束**，二者皆必填。

固定模板：
```
[关键约束]
镜头铁律: 焦段+投影+畸变控制(如 50mm rectilinear, geometric lines straight, 脸部比例自然 NOT 广角畸变)
构图铁律: 主体占比与位置 + 从属元素仅作锚点不抢焦 + 背景须含可识别叙事证据
表情铁律: 量化嘴角/眼/眉 + 外放或压住 + 绝不(列禁止表情)
动作铁律: 动作时间点 + 重心/手部/道具落点 + 运动模糊方向强度 + 模糊后仍可识别项
空间叙事铁律: 主体↔目标距离方向证明剧情进展 + 背景模糊但元素不可抽象成纯光条
色彩铁律: 严格继承色卡HEX与归属 + 仅允许胶片/尘埃/运动模糊自然变化
风格铁律: photorealistic film still + film grain/halation + NOT 3D render/CGI/game/Unreal/Blender/插画/塑料感
主体身份铁律: 必须匹配[角色卡/参考图] + 列关键身份锚点(脸/服装/道具/伤痕)
参考继承铁律: 各参考图继承项不冲突 + 硬锚点不可改 + 软约束仅作风格参考
负面约束: (集中列要排除项)渲染失真(禁CG/3D/塑料皮肤/过度磨皮)、风格越界(禁卡通/插画/动漫/油画 除非风格核心声明)、解剖结构(禁多指畸形手/脸崩/不对称眼/广角脸畸变)、画质瑕疵(禁过曝死白/欠曝死黑/水印文字边框装饰花纹/低分辨率)、一致性(禁角色身份漂移/光位跳变/偏离色卡)、时间轴误读(首帧禁画成动作已结束/尾帧禁画成动作未发生)
```

**常见错误**：只写正向不写负面；负面笼统(仅"禁CG"漏解剖/时间轴类)；与风格核心冲突(声明插画却又禁插画)。

### 7. 图像模型成片提示词转换（可粘贴施工单）

- **给人看的关键帧卡**：保留本契约全部字段（硬锚点蓝图，便于对账与跨帧复用）。
- **给图像模型的可粘贴提示词**：在卡之后附一段——主体描述用**连贯自然语言**(主体+动作落点+表情+环境关系)，视觉美学用**简短词组**(风格/光/色/构图)；镜头术语、焦段、HEX、风格/负向词保留英文；参考图用占位符 `<<<image_1>>>` 绑定并紧跟继承声明(`inherit the exact face/costume/props/scars`)；末尾固定加 `8K photorealistic film still, cinematic film grain` + 负向串 `no 3D render, no CGI, no plastic skin, no extra fingers, no subtitles, no watermark`。
- **若该帧作 Seedance 视频首/尾帧**：附 `../_shared/seedance-2.0.md` 的 start_frame / end_frame / reference_video 衔接说明（本帧作上镜尾帧→下镜首帧，保跨镜不漂）。

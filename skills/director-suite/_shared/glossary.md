## 为什么会混

"六维(推理步骤)"与"五大维度(知识库)"数字不同、所指不同；早期 README/DESIGN 误把知识库写成"八维"。\
**记忆口诀**：推理走**六**步、支柱有**八**根、知识库分**五**维——三个数字各管各的，别串。

## 其它常用术语

- **成片**：镜头卡 + Seedance 提示词 + 四表（引擎隐身的红线边界）。
- **L1 硬锚 / L2 软锚**：asset 一致性等级（永不变 / 随剧情按状态轴变并显式声明）。
- **生成单元 = 镜头组**（10–15s），≠ 镜头（镜内分切）。

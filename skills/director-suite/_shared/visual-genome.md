# 视觉基因解构（Visual-Genome）· D8 图像优先入口

> 入口模式：用户上传一张美学图 → 结构化解构成"四维基因卡" → 指导分镜（**只指导，不当生成指令**）。\
> 审计见 `audits/audit_image_genome.py`。铁律：四维标签/HEX/解构词**只在内部跑，绝不进成片镜头卡**。

## 四维基因卡（genome）

```
Subject_Structure    : 主体结构 + 构图（中心/三角/偏轴对称/空间四层）+ 透视/遮挡
Color_Palette_Ratio  : { main:#HEX, aux:#HEX, accent:#HEX, ratio:[0.6,0.3,0.1] }  ← 配比和=100%±5%
Lighting_Environment : 光型(伦勃朗/平光/底光) + 色温倾向 + 光比
Texture_Simulation   : 胶片 stock / 颗粒 / 材质质感
```

## 三档读图能力探针（先 de-risk）

| 档 | 宿主能力 | 怎么取 |
|---|---|---|
| A | 多模态可读图 | 自动取主色 HEX/判光位/辨空间四层 |
| B | 部分可读 | 半自动 + 人工补 |
| C | 不可读（本机默认） | 用户文字描述图 → 据描述抽四维，不臆造 |

## 铁律

- **图给起点，文字驱动全程**：同一张图配不同情绪剧情 → 首镜视觉初锚相同，但情绪曲线与落卡不同。
- 派生主色与图实际取色 HSL 色相 Δ≤15°（复用 D5 阈值口径）。
- 含品牌 Logo 的图：剥离品牌，不搬运专有名词进成片。

## 镜头语言·空间（景别 / 机位角度高度 / 运镜）

> 空间维度的三件套硬规则：任何一个镜头都必须同时写清 **景别（Shot Size）+ 机位角度·高度（Angle / Height）+ 运镜（Camera Movement）**，缺一不可。对画面驱动的视频模型而言，"镜头层"永远是提示词的第一优先级层级——镜头在动必须直白写出运动方向与速度；镜头不动必须显式写 `static camera` / `fixed shot`，否则模型会自行漂移（drift）。

### 一、景别（Shot Size）

#### 1.1 标准七档 + 专业缩写对照

| 中文 | 英文 | 缩写 | 取景内容 | 典型功能 |
|---|---|---|---|---|
| 大远景 / 大全景 | Extreme Wide / Establishing Long Shot | EWS / XLS | 地貌、天际线、人极小 | 建立空间、"大景小人"气势、世界观 |
| 远景 / 全景 | Wide / Long Shot | WS / LS | 完整人物 + 环境轮廓 | 交代站位、走位、动作完整可读 |
| 中远景 | Medium Long Shot | MLS | 膝盖以上 | 步态、转身、空间过渡 |
| 中景 | Medium Shot | MS | 腰部以上 | 叙事核心、动作、双人/对话 |
| 中近景 | Medium Close-Up | MCU | 胸部以上 | 身份确认、口播、发言者、台词 |
| 近景 | Close-Up | CU | 头肩 / 脸 | 微表情、情绪、身份 |
| 特写 | Tight Close-Up | — | 满脸 | 强情绪、压迫、细节 |
| 大特写 | Extreme Close-Up | ECU | 眼、唇、手部局部 | 极致细节、冲击点、材质微观 |
| 微距 | Macro / Extreme Macro | — | 镜头距表面 5–8cm | 纹理、针脚、冰裂纹、水珠折射 |

- **手部 / 脚部 / 道具插入镜（insert / cut-in）**：1.5–2.5s（动作短促明确 2–3s），用于关键道具与动作落点。
- **缩写栈速记**：`EWS / WS / MLS / MS / MCU / CU / ECU`（动作预演与故事板首选英文缩写，分镜表对齐用）。

#### 1.2 景别配速与连贯铁律

- **景别递进配速公式**：建立全景（establishing wide）→ 细节中景（medium）→ 情绪/纹理特写（close-up）→ 高潮/Logo 受控全景。
- **一个镜头只表达一个观点**，随剪辑切换景别；情绪积累/转折给更近景别 + 更长时长，氛围铺垫快速推进。
- **景别相同 → 合并一镜到底；景别不同 → 剪切过渡。**
- **相邻镜头景别跳变不得超过 2 档**：中景与大特写之间须插一个 CU 桥接镜（bridge shot），避免观感跳脱。
- **同维度高度连贯**：第一人称/探索类各分镜之间机位高度必须连贯不跳变（如室内步行 155–170cm 锁定）。
- **单镜对话/口播保面部占比**：避免广角建立镜与全身全景（脸太小则音频口型对不齐）。

### 二、机位 角度 / 方位 / 高度（Angle / Azimuth / Height）

机位是三个独立可组合的参数轴：**高度（Height）× 方位（Azimuth）× 俯仰（Tilt）**。

#### 2.1 俯仰角（Vertical Angle）

| 角度 | 英文 | 心理/叙事效果 |
|---|---|---|
| 平视 | Eye-level | 客观、平等、代入、对话标准 |
| 仰拍 | Low angle / looking up | 压迫、权势、英雄感、蓬勃向上、人物渺小自由（配天空背景） |
| 俯拍 | High angle / looking down | 弱势、压制、被观察、交代地理 |
| 顶视 / 鸟瞰 | Top-down / Bird's-eye / Overhead | 全局、移轴微缩感、产区分布、技术平铺（flat lay） |
| 大俯冲航拍 | Aerial / Crane down | 建立壮阔空间、溯源段地貌 |
| 微微仰拍 | Slight low-angle upward tilt | 轻度强化（如电商主图仰视 5–25°） |

#### 2.2 方位（Azimuth / 水平方位）

- 正面（frontal）/ 正侧 90°（profile）/ 三分之四（3/4 view，最常用且最立体）/ 背面（back）。
- **关系机位**：过肩 / 越肩（Over-the-shoulder, OTS）、双人镜头（two-shot）、带前景单人（foreground occlusion）。
- **荷兰角 / 斜角 / 倾斜失衡**（Dutch angle / Dutch tilt，约 5° 起）：制造紧张、躁动、失衡、危机。

#### 2.3 高度（Height，可量化）

| 场景 | 高度参数 | 说明 |
|---|---|---|
| 成人步行视角 | 离地 155–170cm（标定 160cm），水平或略俯 ≤5° | 室内探索、第一人称漫游 |
| 儿童 POV | 贴近物体表面 low angle | 视线高度必须匹配年龄（8 岁低机位贴物） |
| 宠物/萌宠自拍 | 离地 30–50cm，略仰视 | 与宠物同高代入 |
| 第三人称跟拍 | 升至腰-胸高 80–110cm | 跟随通勤、行走 |
| 场边坐姿 | 与坐姿人物视线齐平 | NBA 看台、courtside |

#### 2.4 第一人称 / 主观机位（POV）

- 主角眼睛即摄影机（**camera is his/her eyes**）；视线被声音拉过去（the gaze is pulled by the sound of）、视线跟着手（the view follows the hand）。
- 互动 POV 高度起幅常设**胸口高度**，与对象视线齐平产生"眼神拉丝"；压迫感用低机位贴近物体表面。

### 三、运镜（Camera Movement）

#### 3.1 基础运镜词表（中英 + 速度/程度副词）

| 中文 | 英文 | 适用情绪/功能 |
|---|---|---|
| 固定 | static / fixed / lock-off | 静止张力、克制、口播；**镜头不动必须显式写** |
| 推镜 | push-in / dolly in / zoom in | 强调情绪、揭示细节、制造压迫（背景压缩浅景深 bokeh，medium→tight CU，慢速 steady deliberate） |
| 拉镜 | pull-out / dolly out / pull-back | 揭示环境、孤立感、结尾留白（CU→wide，主体被环境吞没） |
| 横摇 | pan (L/R) | 跟随视线、交代空间、平行对比两主体 |
| 竖摇 | tilt (up/down) | 纵向揭示、竖版偏好 |
| 移镜/横移 | lateral track / slide / truck | 跟随移动主体、揭示纵深（背景多层 parallax） |
| 跟镜/跟拍 | follow / tracking | 临场感、追逐、主观（behind/ahead/beside；tight/loose） |
| 环绕 | orbit / arc / 360° | 展示产品体量、关系、空间 |
| 升降 | crane / boom / jib | 高度变化、丰收/盛宴全景高潮 |
| 手持 | handheld / drift / breathing | 自然呼吸感、纪实、真实 |
| 甩镜 | whip pan / swing | 急速转场（少用，易崩） |
| 焦点转移 | rack focus / pull focus | 主体切换、虚实过渡 |
| 镜头呼吸 | lens breathing | 极细微焦距变化、情绪 |
| 切新角度 | cut to new angle | 镜内/镜间切换 |

#### 3.2 运镜书写规范

- **运镜栈格式**：`[起幅景别] → [运动方式] → [落幅景别]`。例：`WIDE SHOT, swift push in → cut → EXTREME CLOSE-UP on fist impact, lock-off`。
- **状态切换写法**：写"由固定 → 缓慢推入"（static → push-in）这类**状态变化**，而非单一静态描述。
- **运镜必带程度副词**：速度（slow / moderate / fast / quickly / violently）、幅度（large amplitude / high frequency）。
- **速度三档量化**：缓慢 `<5°/s` / 中速 `5–15°/s` / 快速 `>15°/s`，或描述位移距离与方向。
- **运动堆栈顺序铁律（Seedance/Kling 通用）**：**摄影机 → 主体 → 空间/背景 → 光感 → 音频**。第一层只写摄像机运动或镜头/剪辑变化。
- **多节拍标记**：用 `Shot1 / Shot2 / Shot3` 或 `镜头1/2/3` + `cut to` 串联，**禁止逐秒精确计时**（精确时钟模型无法可靠执行；内部分段用 0–4s/4–8s 这类区间或纯节拍顺序）。
- **运动方向一致律**：跟拍/环绕的镜头运动方向必须与角色运动方向一致，严禁冲突。

#### 3.3 镜头时长与"长镜头 + 镜内分切"策略

- **单镜硬上限 ≤15s**（当前主流模型时长上限）。
- **优先长镜头（10–15s）+ 镜内分切（internal cut）**，在一个长镜头内完成调度，而非切碎成多个短镜头；运镜在基础景别时长上额外 +1s。
- **内部分切按剪辑顺序排列**：`首先(0–4s) → 然后切到(4–8s) → 再切到(8–12s)`，每段 2–4 段，禁单段撑满全程或过碎；故事支持时单镜可 ≥6 个内部剪辑。
- **承接铁律**：自 Shot2 起，本镜开场的初始景别 + 角度必须与上一镜结尾严格一致；相邻镜头禁瞬移/大幅场景跳变，除非 Match Cut 或艺术化平滑过渡。
- **单 shot 约束**：≤15s、出场 ≤3 人、不跨物理空间。
- **长镜头位置**：禁止置于片段首尾，须居中段承担情绪承接（TVC 调性）。
- **节奏单元**：以 15s 为一个"自动切镜单元"，单元内多分镜（严禁仅 2–3 镜，舞蹈类每 15s 含 8–15 镜）。

#### 3.4 焦段（Focal Length）——空间关系的隐性控制器

| 焦段 | 用途 |
|---|---|
| 广角 24–35mm | 叙事/环境关系、空间纵深、建立镜 |
| 标准 50mm | 接近人眼、自然透视 |
| 中长焦 85mm | 特写、浅景深、人像 |
| 长焦 135mm+ | 过肩压缩、空间压平、转播"看台找人"telephoto feel |
| 微距 macro | 5–8cm 贴面、单缝为最锐焦平面 |

### 四、情绪 / 氛围 → 空间选择 决策映射

| 情绪 / 场景目标 | 景别 | 角度 / 高度 | 运镜 | 焦段 |
|---|---|---|---|---|
| 压迫 / 权势 | CU / ECU | 仰拍 low angle | slow push-in 锁定 | 85mm 浅景深 |
| 弱势 / 被审视 | MS / 全景 | 俯拍 high angle | 缓推或固定 | — |
| 孤独 / 渺小 | WS / EWS（大景小人） | 平视或高角度 | pull-out 主体被吞没 | 广角 |
| 紧张 / 失衡 / 危机 | 任意 | 荷兰角 5°+ | handheld + whip pan | — |
| 亲密 / 暧昧（POV） | 半身特写→面部 | 第一人称胸口高度平视 | slow push-in + lens breathing + 轻晃 | 50–85mm |
| 沉静 / 出神 / 文艺 | 中景 / 特写 / 空镜 | 低角静坐对视 | static / very slow push-in / subtle handheld | — |
| 壮阔 / 建立世界 | EWS 建立镜 | 航拍大俯冲 top-down | slow aerial push-in | 广角 |
| 产品质感 / 高级感 | 微距→中景 | 低角仰视 15–25° | 极缓 360° orbit + macro push | macro / 长焦 |
| 追逐 / 逃亡 | 中景 / 全景 | 低机位车辆视角、顶部跟拍 | stabilized tracking / overhead tracking | — |
| 动作爆发（武戏） | WS（交代）→ ECU（冲击点） | 低角度 + 5° 倾斜 | swift push-in → lock-off on impact | — |
| 对话 / 访谈 | MCU / OTS / two-shot | 平视、Dutch tilt 点缀 | 三景别交替循环 | 50–85mm |
| 青春 / 自由 | 中景 / 全景 | 低角仰拍迎拍 + 天空 | 低角手持侧跟拍 + soft zoom | — |

**速记决策树**：
1. **先判戏的属性**（文戏/武戏、单/双/多人、动/静）→ 决定调度基调。
2. **先判这张图/这段服务的瞬间类型**（建立/对峙/爆发/逃亡/余波/仪式/宴席）→ 决定景别配比。
3. **要情绪压迫就拉近 + 仰拍 + 推**；**要环境关系就拉远 + 平视/广角 + 拉/摇**。
4. **要真实临场就手持**；**要仪式高级就稳定器 + 慢速 orbit/crane**。

### 五、群像 / 多人空间调度（master wide shot）

- 群像优先 **master wide shot / film still**，写清焦段（35mm wide）、机位高度与方位、俯仰角、是否静态、是否单张定帧、视点相对人物水平视线（略高/平视/略低）。
- **空间四层强制**：
  - 前景 foreground：视觉压迫/主体背影/遮挡/权力锚点（常占某个 1/3）。
  - 中景 midground：叙事核心/被观察的沉默中心（画面中部水平带）。
  - 中后景 mid-background：副主体/旁观者/机械/道具。
  - 深景 background：世界观/地平线/大气雾化 haze。
- **构图法**：对称 / 偏轴对称（off-axis symmetry）/ 三角构图 / 横向带状 / 纵深构图；可非居中。明确**视觉锚点**（图像中心）与**叙事锚点**（故事中心）可不同。
- **主次秩序**：更深景的角色尺寸更小；明确谁压谁、谁占视觉权力、谁被环境吞没、谁沉默旁观、谁在关系中心。每角色须写：位置、大小比例、朝向、视线方向、身体朝向、姿态、动作状态、遮挡关系。
- **空间清晰度 vs 电影空气感**：先定前中后景清楚位置，再用 atmospheric haze、depth、partial occlusion 增加真实感。

### 六、画幅差异化构图（Aspect Ratio）

- **必须同时给 16:9 与 9:16 两种画幅的构图差异指导，而非套用同一构图。**
- **竖版 9:16 规则**：景别收窄优先中近特写；运镜改纵向 tilt、慎用横 pan；运动沿纵深轴朝镜头冲来；推进速度比横版慢约 30%；手持横向振幅减半、保留纵向漂移。
- **多宫格策略**：六宫格（3×2）覆盖全片节点（如时装：全景入场 / 中景走秀 / 近景妆容 / 特写面料 / 动态定格 / 收尾全景）。
- **多视角设定图布局**：
  - 角色卡：横向 16:9，左侧紧凑头像（身份：面部/肤色/眼睛/发际线）+ 右侧全身正/侧 90°/背三视图（服装/发型/轮廓）。
  - 场景卡：四视图（建立全景 / 主入口中景 / 关键道具特写 / 反向视角）。

### 七、固定镜序模板（电商/产品/工业）

- **主图 HERO（1:1，3 镜）**：Hero_01 建立镜低角仰视 15–25° → Hero_02 中景正面平视（产品占 60–70%）→ Hero_03 白底 KV 微仰 5–10°（占 65–70%，无道具）。
- **详情页（3:4 / 16:9，6–8 镜）**：使用场景中近景 → 材质微距/大特写（镜距 5–8cm）→ 卖点爆炸图标注中景 → before/after 双分屏 → 尺寸规格鸟瞰平铺。
- **工业宣传五类各约 12s**：外观（低角 360° orbit + 微距）/ 功能可视化（俯视底板极缓推）/ 爆炸拆解（低角 45°–180° 弧巡览，每点停 1.5–2s）/ 主板（极近微距探索）/ 真人操作（手部+UI 推进 + 慢动作 250%）。

### 八、常见错误 / 禁止项

**通用禁止**
- 镜头在动却不写运动方向/速度 → 模型误判漂移；镜头不动却不写 `static camera` → 模型自行漂移。
- 三件套缺项（只写景别不写角度/运镜）。
- 逐秒精确计时（精确时钟模型不可靠）；应改用区间或节拍序。
- 单镜 >15s（超模型上限）；单镜跨物理空间、出场 >3 人。
- 相邻镜头景别跳变 >2 档无桥接；自 Shot2 起开场机位与上镜结尾不一致（穿帮）。
- 跨段运镜突变矛盾（上段推进收尾、本段反向冲突）；同场景服装/道具/光线入射角不一致。

**情绪/题材型禁止**
- 文艺/氛围片：禁快速推拉（主体一致性崩）、禁甩镜/急摇（运动模糊失控、帧间崩）、禁环绕（多角度一致性丢失）、禁无人机高空俯冲（气质冲突）、禁单镜内频繁切换景别（主体变形）。
- 口播/对话/数字人：禁全身镜头与广角建立镜（脸太小口型对不齐）；禁多机位切换（单一 asset_id 重复）；按句子结尾切分，绝不按时间硬切。
- 羊毛毡/动画柔和系：禁 handheld shake、fast zoom 急推、rapid cuts 急切、jerky camera 生硬。
- 偶像 MV/竖版：多人同框 ≤3 人（超 3 面部混淆，群像全景放宽至 5）；舞台禁炫技弧形/无人机感；高潮段禁稳定器（允许晃动）。
- 一键复刻/拉片：不自创景别/机位，逐镜继承（运镜继承优先级最高），声明"保持原视频完全相同镜头运动，不添加新运动"。
- 运动方向禁令：旅拍统一向右/向纵深运动以保连贯（禁向左奔跑）。
- 微缩/克制系：禁快速剪辑与手持抖动。

```
      lens breathing · cut to new angle

焦段  24-35mm wide · 50mm · 85mm · 135mm+ tele · macro(5-8cm)
结构  push-in → cut → ECU, lock-off  |  static → push-in  |  Shot1/Shot2/Shot3 + cut to  |  起幅→运动→落幅
堆栈  Camera → Subject → Space/Background → Light → Audio
```

## 画面构成（构图 / 场面调度 / 转场）

> 本节统一画面的**空间组织（构图）**、**画内人/物/动作的安排（场面调度 mise-en-scène）**与**镜头之间的承接（转场 / 剪辑）**三件事。核心立场：构图是"把什么放进框、放在框的哪里"；场面调度是"框里的人、物、动作如何在三维空间里被组织与表演"；转场是"一个镜头如何变成下一个镜头"。三者必须协同服务叙事与情绪，而不是各说各话的视觉装饰。

---

### 一、画幅与安全区（先定容器，再谈构图）

构图的第一性问题不是"放什么"，而是"放进多大的框、给后期留多少边"。

| 画幅 Aspect Ratio | 典型用途 | 叙事气质 |
|---|---|---|
| 16:9 | 横屏通用 / 转播 / 纪录 / 电商主图 | 中性、写实、客观 |
| 9:16 | 竖屏短视频 / POV / 时装走播 / 室内探索 | 沉浸、贴身、社媒原生 |
| 1:1 | 多宫格单元、社媒方图 | 对称、产品化 |
| 2.39:1 anamorphic / IMAX 70mm 质感 | 短剧 / 电影感大片 | 史诗、宽银幕压迫 |
| 4:3 / 11:8 (Academy) | 复古 / 韦斯·安德森式仪式 | 辉煌、亲密、压迫 |
| 12:5 ultra-wide | 孤独题材 | 空旷、失落 |
| 4:3 + 3:4 海报矩阵 | 主画幅定稿后裂变封面 | 多端适配 |

**画幅作为叙事立场**：画幅不是技术参数而是态度——窄幅（Academy/4:3）=压迫·仪式·亲密；超宽（12:5/2.39:1）=孤独·空旷·史诗；16:9=中性写实。同一项目要求 **9:16 与 16:9 双画幅时，必须给出两套构图指导**，不能把横屏构图硬塞进竖屏。

**竖屏安全区（9:16 铁律）**：
- 核心表达区 = 画面中央 **70%（水平）× 65%（垂直）**，所有情绪高点 / 手势 / 笑容 / 定格帧落此区。
- 上 8–10% 留用户名栏，下 20–25% 留文案 / 字幕栏，右 10–12% 留互动按钮列。
- 眼睛落在 **上方 1/3 黄金位**，禁正中死板。
- 多宫格 / 多格分镜里，**每个子格也要按最终画幅构图**（9:16 单元不能压成长条），否则重构漂移（reconstruction drift）。

**封面 / KV 负空间**：封面图须预留 **大面积干净负空间（clean negative space）** 供标题排布，主体清晰、无字幕水印；商业 KV 须为 Logo / Slogan 预留留白位。

### 二、构图（Composition / Framing）

#### 2.1 构图骨架（必须显式声明的术语）

构图要写成**导演级指令**而非物体罗列。优先使用专业电影术语，并显式声明：

- **景别**：特写 Close-up (CU) / 大特写 ECU / 近景 Medium Close-up (MCU) / 中景 Medium Shot (MS) / 中全景 MLS / 全景 Wide / 远景 Extreme Wide (EWS) / 建立镜头 Establishing。可用"身体取景线"界定（如"腿部以上 from the legs up"）。
- **机位角度**：平视 eye-level / 俯角 high angle / 仰角 low angle / 顶视 top-down / 荷兰角 Dutch angle / 过肩 Over-the-shoulder (OTS)。
- **机位高度与方位**：高度（低 / 中 / 高）× 方位（正 / 斜 / 侧）。
- **视点高度相对人物视线**：略高 / 平视 / 略低，必须明确。
- **焦段与功能挂钩**：

| 焦段 | 功能 |
|---|---|
| 广角 24–35mm wide | 叙事 / 环境关系 / 空间纵深 |
| 标准 50mm | 自然透视、接近人眼 |
| 中长焦 85mm | 特写、压缩、浅景深主体分离 |
| 长焦 telephoto | 过肩压缩、虚化背景、孤立主体 |

#### 2.2 构图法则（经典骨架）

黄金分割 / 三分法（主体偏置 1/3）/ 中轴对称 / 对角线平衡 / 动态斜线 / 速度线 / 框中框（frame-within-frame）/ 满构图 / 边框裁切 / 装饰带式横向布局 / 引导线（leading lines）/ 视觉重量平衡。

- **焦点坐标化（高级可控法）**：用归一化坐标 `Focus:(X,Y)`，(0,0)=左上，(1,1)=右下。主体焦点放在 1/3 或 2/3 分割线附近（如 `(0.38,0.50)`），**三张主图焦点不可重复**，使平台缩略图条形成自然左→右引导。详情页焦点按 **Z 字 / F 字扫视路径**：奇数页焦点偏左 `X≈0.33`、偶数页偏右 `X≈0.67`，Y 在 0.35–0.60 随节拍浮动，匹配从上到下的滚动眼动。
- **前景压物（foreground occlusion）**：车体 / 芦苇 reeds / 百叶窗 / 门框 / 过肩后脑勺做前景层次与遮挡，制造纵深与"窥视 / 防备"压力。
- **三层 / 四层景深强制分层**（见 §3.1）。
- **不完美构图（imperfect composition）**——文艺片合法手法：从背后拍 seen from behind、只拍手不拍脸 no face visible only hands、人物偏置画面边缘留大量负空间。
- **结构对称·内容非镜像**（韦斯·安德森铁律）：结构层（墙 / 门框 / 柱 / 内置灯）可双侧对称，内容层（桌椅 / 道具）左右必须不同，用视觉重量平衡，**硬禁 no mirror-image furniture**。

#### 2.3 设定图 / 参考图构图（资产层，非成片）

- **角色三视图**：单图三全身视角左→右等距排列（正 / 侧 / 背），中性灰背景 `#888888` 或纯白，全身完整可见、无文字水印。
- **角色头身双格**：左格头像（紧凑构图聚焦面部，确认身份 / 肤色 / 眼睛 / 发际线）+ 右格全身照（服装 / 发型 / 妆容 / 鞋 / 轮廓）；或 16:9 拼接（左半人脸大头照 + 右半三视图 front/side/back）。
- **场景四视图**：2×2 宫格、画面无人。
- **运镜轨迹示意图**：竖向 3:4，左 10% 编号说明 / 中 70% 宽幅画框含相机图标轨迹 / 右 20% 镜头类型注。
- **负面约束**：参考图内 **不生成文字 / 字幕 / 水印 / 边框 / 箭头**（成片更严禁出现分镜批注、网格线）。

### 三、场面调度（Mise-en-scène / Blocking）

> 场面调度 = "故事内容层 / 空间层"：角色与关键物体在三维空间里的**位置、朝向、动作、相互关系、背景运动、深度与布局转换**。原则：**用空间位置表达关系秩序，而非平面罗列**；**每个动作必须指定具体主体**，禁"有人 / 某人"模糊表达。

#### 3.1 空间分层（纵深锚点）

强制前 / 中 / 后景分离，靠浅景深建立层次：

| 层 | 职能 |
|---|---|
| 前景 foreground | 遮挡 / 氛围 / 权力锚点 / 主体背影（常占某个 1/3，如右下 1/3） |
| 中景 midground | 叙事核心 / 主要动作 / 被观察的沉默中心 |
| 中后景 mid-background | 副主体 / 旁观者 / 机械 / 道具 / 关系补充 |
| 深景 background | 世界观 / 地平线 / 建筑 / 远景气氛 / 大气雾化 haze |

**空间锚点卡**（跨镜一致性工具）：锁定**固定参照物**（不可移动视觉地标，如位于画面中心的破旧防盗门）+ 每个角色的 **[位置 + 朝向 + 手持物]**，相邻镜显式维护连贯。可用 **Element ID** 引用布景 / 角色（如 `[Element_Office_Noir]`），保证跨镜空间锚定。

#### 3.2 主次秩序（群像调度）

所有角色都重要但不可能人人平权——按剧情决定 **谁大 / 谁小 / 谁亮 / 谁暗 / 谁居前 / 谁退后**。更深景的角色尺寸更小。每个角色须写：**位置、大小比例、朝向、视线方向、身体朝向、姿态、动作状态、遮挡关系**。人物关系用"互相看见 / 互相忽视 / 彼此压迫 / 共同沉默"落实。区分**视觉锚点（图像中心）与叙事锚点（故事中心）**——二者可不同。

#### 3.3 站位 + 朝向（对话 / 多人戏核心）

对话 / 访谈 / 多人戏的核心是 **"站位 + 朝向 + 表情"**——这是三视图参考无法定义、需靠"同场景前一最相似关键帧"额外锚定的细节。

- 说话主体在静帧中清晰可辨，**脸大而清晰**。
- 重叠 / 轮流发言 **必须拆成两个独立镜头**，不可同帧交替对话。
- 双角色对立：双侧对立站位（A 在 camera-left 则对立者 camera-right）；同盟：统一朝向 / 同方向主光。
- 多人纵向错落站位（front-to-back depth），副歌 / 焦点成员可"超前半拍"。

#### 3.4 调度的表演显性化（戏感落到可执行动作）

把抽象情绪翻译成**逐身体部位**的生理反应：不写"他很愤怒"，写"喉结滚动 / 拳头攥紧又松开 / 眉头反应"；受惊 = 后撤半步、重心下沉、手臂蜷缩、双手抬至下巴前防御、全身发抖。**把动作定格在最戏剧性的瞬间**（freeze at dramatic moment），拒绝僵硬摆拍。

#### 3.5 题材化调度母题（速查）

- **底层暗流型**（GTA 风）：表层热闹阳光、底层暗藏追捕 / 债务 / 走私；背景填满随机路人 NPCs / 车流 / LED 广告牌 / 小摊 / 人群直播制造社媒混乱。
- **生活痕迹型**（东亚文艺 / 城市记忆）：旧墙纸、凌乱但有序的厨房、窗台盆栽、门边旧拖鞋、光束中浮尘；任何空间须携带**社会信息载体**（标语 / 价目表 / 收款码 / 旧海报）作叙事而非装饰；允许画面"脏"。
- **真实抓拍型**（转播 / 偶像 MV）：主体居人群中作"被抓拍对象"，背景塞真实观众席自然涌动 authentic crowd movement，被摄者"不知被拍"。
- **产品舞台型**（工业 / 3C）：苹果式纯黑 / 纯白无杂物舞台；爆炸拆解沿结构轴向分层悬浮（外壳上 / 接口前 / 主板居中作锚点 / 电源后 / 温控下），模块间留 1/2 自身高度均匀间距；流光线条做信号链路（输入→主干→分配节点爆闪→多路分叉→同步消散）。
- **微缩 / 羊毛毡型**：尺寸对比锚定（巨大咖啡杯 / 与人偶等高的信封）；羊毛毡须"全尺寸重建现实世界" full-size felt world at realistic scale，**NOT miniature / NOT diorama / NOT puppet stage**。
- **固定单场景型**（口播 / 数字人）：锁定单一固定场景全程不换位，脸与产品（SKU）同处前景共占焦点，产品始终清晰可读不被遮挡。

#### 3.6 静态定帧的时间感（图像提示词专用）

图像静态但故事要像"刚刚发生过"。用姿态、地面痕迹、风、尘、光线残留、身体状态表现 **frozen moment / aftermath（余波）**：刚说完话的尾音状态、刚转头的一帧、咀嚼中间瞬间、衣料刚平复、倒地者完全无声。

### 四、转场 / 剪辑（Transition / Editing）

#### 4.1 转场类型总表

| 类型 | 英文 | 典型用途 | 时长参考 |
|---|---|---|---|
| 硬切 | Hard Cut | 同空间承接 / 动作冲击 / 一镜到底伪装 | 0 帧 |
| 动势匹配 | Match-on-action | 无缝衔接、商业 TVC 首选 | 切在动作中段 |
| 视线匹配 | Eye-line / Match-cut | 反应承接 | — |
| 物理遮挡切 | Occlusion wipe | 烟雾 / 肩 / 掌 / 飘带遮镜瞬间切 | 遮挡 ≤0.5s |
| 甩镜 | Whip Pan | 同向动势、模糊最大帧切 | 几帧 |
| 几何重合切 | Graphic match | 同位形状对齐（重合面积 ≥20%） | — |
| 闪白 | Flash cut | 高速心跳 / 能量 | ≤2 帧 (~0.08s) |
| 叠化 / 溶解 | Cross-dissolve | 柔化冲击 / 时间流逝 | 2–4 帧柔化；产品 ≤0.3s |
| 淡入淡出 | Fade in/out | 章节 / 开篇 / 收尾 | 跨空间 ≤0.3s；片头 1.0s / 片尾 1.5s |
| 黑场过渡 | Fade to black | 时间跨度 / 呼吸感 / 单元间 | 0.5–1s（萌宠快切 ≤0.2s） |
| 空镜缓冲 | Cutaway / B-roll | 情绪呼吸 / 反应插入 | 文艺片 6–8s |
| L-Cut / J-Cut | — | 音画交错、声音先入 / 延续 | 声画错开 0.5s |
| 声音桥 | Sound bridge | 跨镜叙事推进（玻璃碎裂声触发下一镜） | — |

#### 4.2 转场决策规则（情绪 / 题材 → 转场）

| 目标气质 | 转场策略 |
|---|---|
| 无缝一镜到底 / 商业高级感 | 纯硬切 + 动势匹配 / 物理遮挡 / 几何重合 / 光影延续 / 声音桥；**严禁淡入淡出 / 叠化 / 闪白 / 黑白场 / 无意义空镜** |
| 高速能量 / 动作高潮 | 硬切 + 闪白 + 甩镜 + match-on-action |
| 文艺 / 情绪呼吸 | **禁硬切**；1–2s 黑场淡入淡出 + 6–8s 环境空镜缓冲；情绪单元内 ~1s 短黑场、单元间 8–12s 长空镜或 2s 黑场 |
| 时间 / 空间跳跃 | 0.5–1s 黑场 / 淡入淡出标跨度 |
| 美食 / 烟火气 | 严禁 dissolve / fade to black；只允许 match-on-action 或烟雾遮挡切 |
| 纪录 / 工艺 | L-Cut / J-Cut 音画交错（声音提前 / 延续 0.5s）；高潮前停顿 0.5s 增张力 |
| 意境 / 国风 | 仅淡入淡出 + 光影 / 月色 / 粒子转场；严禁剧情向蒙太奇 |
| 转播 / 口播 | **无转场**，纯单镜 cutaway / 按 VO 时间轴顺序拼接，UI 全程静止 |

#### 4.3 镜内剪辑 vs 镜间转场（关键区分）

主流模型单镜 **≤15s**。优先 **"长镜头内部剪辑"**——单镜 10–15s，在镜头内部设计切点（`cut to` / `cut to new angle`）而非拆成大量碎镜；剪辑频率随叙事节奏。镜内分切写法：

```
Shot1 (0–4s): [场景][角色] 做 X，特写。
Shot2 切至 (4–8s): … 
Shot3 切至 (8–12s): …
```

或用 First / Then / Finally；或 0–3s / 3–6s 时间戳。**禁逐秒计时**（"3.0–5.0s"式时码无法可靠执行）——靠**编号节拍流（time flow）**而非精确墙钟。

#### 4.4 首尾帧衔接（多片段连续性引擎）

跨片段连续性靠 **首尾帧对齐**而非转场特效：
- 首镜：用场景四视图 / 全景建立 establishing 作 `start_frame`。
- 后续镜：用 **上一镜末帧（last frame / Video Frame）** 作下一镜 `start_frame`，保主体 / 环境连贯，严禁突兀跳场。
- **关键帧三态**（动作锚点）：

| 帧 | 内容 |
|---|---|
| 起始帧 | 动作前预备姿态（重心偏移 / 注视方向 / 肢体预加载）+ 环境基准 + 初始景别角度 |
| 结束帧 | 动作落定后姿势 / 表情 + 环境变化后状态 + 摄像机为下一剪就位 |
| 高亮帧 | 视觉 / 情感冲击峰值单帧冻结（撞击顶峰 / 真相落脸 / 主题结晶构图） |

- **承接检查链**：主体意图 → 运动方向 → 环境状态（前 / 后）→ 相机设置 → 道具状态，五点连贯锚定。拼接点前后各 **0.5s 无跳帧 / 重影 / 帧错位**，运镜方向与速度无突变。

#### 4.5 多宫格 / 分镜板布局（一图多格）

- **多宫格生视频**：单画布 N 单元格（每内部剪辑 1 张关键静帧），细中性分隔线，空间排列灵活；**铁律：拼版空间平铺顺序 ≠ 剪辑 / 故事顺序**，时间唯一真理来源是每格固定角落（统一惯例如左上角）打印的**故事板剪辑索引 1…N**。N 保持可读，每镜头通常 2–6 内部剪辑。
- **动作预演分镜板**：每板 ≤8 格（最多 16），2×4 网格，细实线分隔，左上角灰色帧号 F1–F16；逐格 7 层信息（运动矢量箭头 / 动势拖尾线 / 冲击标注 / 空间深度标记 / 角色区分标签 / 镜头信息栏 `MCU | PUSH | SNAP` / 帧间过渡 `→cut→`）。
- **导演分镜矩阵**：16:9 内规整 2×3 六格，黑细边框分隔，角落格位编号（A1–A6），格内运镜箭头 + 景别说明 + 底部导演批注（参考用；成片严禁出现边框 / 箭头 / 字块 / 水印）。

### 五、跨镜连续性铁律（Continuity）

- **180° 轴线规则**：跳轴时插入正面或过肩过渡镜，不强行拼接对打 / 对话方位。
- **30° 规则**（行业补全）：同主体相邻切换机位变化应 ≥30°（或换景别），否则成跳切 jump cut。
- **强制一致性**：同场景不同镜间，**服装整洁度 / 道具位置 / 光线入射角 / 色温**必须一致；色卡锁定材质本色，光影只负责明暗情绪。
- **运动方向一致**：跟拍 / 环绕的镜头运动方向必须与角色运动方向一致，严禁冲突。
- **物理逻辑闭环**：水花 / 反光 / 人体动力学 / 道具受力（鱼竿弯弓 / 鱼线紧绷）符合真实物理；无穿模 / 无跳帧 / 无卡顿。

---

### 六、常见错误 / 禁止项

- **堆角色当群像**：只把角色摆满 = 杂乱合影；只讲场景 = 丢人物关系；只讲风格 = 丢剧情意义。群像须用一张 master wide shot 同时解决关系 / 层次 / 气氛 / 光影 / 一致性。
- **平面罗列调度**：只写"有什么"不写"在哪里 / 朝向哪 / 谁压谁"。
- **模糊主体**：出现"有人 / 某人"，未指定具体角色执行动作。
- **逐秒时码**：写 "3.0–5.0s" 式无法可靠执行的精确时码。
- **同帧交替对话**：重叠发言未拆成独立镜头。
- **过度转场特效**：滥用翻页 / 旋转 / 变焦 / 第三方花哨转场；在"无缝 / 美食 / TVC"语境用了叠化 / 黑白场 / 无意义空镜。
- **TikTok 快剪误用**：纪录 / 文艺题材用音乐卡点快剪 / 特效转场，破坏时间流与呼吸感。
- **跳轴 / 跳切**：跨 180° 轴线硬拼；同机位同景别微变切。
- **重构漂移**：多宫格子格未按最终画幅、压成长条。
- **拼版顺序当故事顺序**：误把网格平铺位置当剪辑时间序（须靠角落索引）。
- **参考图污染**：参考 / 设定图里生成了文字 / 水印 / 边框 / 箭头；或把**姿态参考误用为身份参考**。
- **构图混乱判废**：背景元素过复杂、主体与前 / 背景无法清晰区分。
- **僵硬摆拍**：动作未定格在戏剧性中间瞬间（reject stiff posed stance）。
- **收尾失误**：短视频用黑屏 / 白屏 / 淡出 / 无意义空镜收尾（应为封面级名场面定格 / 可循环 ending pose）；文艺片漏掉末镜 2–3s 纯黑场 + 音频 fade out。

---

- 画幅：`16:9` / `9:16` / `2.39:1 anamorphic widescreen` / `IMAX 70mm` / `4:3 Academy` / `12:5 ultra-wide`
- 景别：`extreme close-up (ECU)` / `close-up (CU)` / `medium close-up (MCU)` / `medium shot (MS)` / `wide / establishing shot` / `extreme wide shot (EWS)`

## 光影与色彩（布光 / 色温光比 / 影调 / 色彩心理）

> 本节统摄四件事：**布光（光从哪来、是什么光质）→ 色温光比（冷暖与明暗的量化）→ 影调（高调/低调、对比、颗粒质感）→ 色彩心理（情绪潜台词如何由光与色承载）**。核心原则一句话：**光影与色彩不是后期滤镜，而是叙事工具——每一束光、每一种主色都要回答"它在表达谁、什么情绪、什么关系"。**

---

### 一、布光：先定光型，再定光质

布光的第一步不是调参数，而是**指认主光（key light）方向与功能**，再决定补光策略。专业提示词应让每个镜头/场景都能回答：主光从哪来、光质硬软、补光有无、轮廓光有无。

#### 1. 三大功能光 + 进阶光型

| 光位 | 英文 | 功能 | 典型用法 |
|---|---|---|---|
| 主光 | key light | 塑形、定情绪、定明暗方向 | 侧光/伦勃朗光制造面部明暗分割 |
| 辅光 | fill light | 控制光比、填暗部 | 决定戏剧性强弱（强对比=弱补/负补） |
| 轮廓光 | rim light / backlight | 分离主体与背景、勾边 | 暗背景下勾服装/发丝轮廓 |
| 顶光 | top light | 压迫、临床、冷峻 | 审讯、对峙 |
| 底光 | under light / uplight | 诡异、反派、悬疑 | 阴影上翻，额头眼窝深阴影 |
| 侧光 | side / split light | 立体、人物刻画 | 一半亮一半深阴影 |
| 逆光 | backlight | 出场/离别、剪影、回眸 | glowing rim + halo bloom |
| 体积光 | Tyndall / volumetric / god-rays | 希望、神圣、转折 | 20–45°光锥+尘雾粒子隔离主体 |
| 实景光 | practical light | 真实感、生活化 | 台灯、日光灯管、电视屏幕光、霓虹、手机屏 |

#### 2. 负补光（行业高频核心手法）

**negative fill / zero warm fill（负补光 / 零暖光填充）** 是院线戏剧布光的反复出现的关键词：**主动减少暗部补光甚至吸光**，加大光比，得到 `deep facial shadows`（强调面部骨骼结构的深面部阴影）、`strong chiaroscuro contrast`（强明暗对比）、`dramatic interplay of light and shadow`。用于剧情/叙事/对峙类强戏剧场景。

#### 3. 光质（硬软）与阴影

- **硬光 hard light**：无柔化、`razor-sharp shadow edges`、高 specular、crushed blacks → 动作/冲突/工业。
- **柔光 soft light**：large diffused、`feathered gradual shadow`、lifted shadows 低对比 → 温情/回忆/梦境/治愈。
- 阴影需参数化：**方向 + 长度 + 硬度 + 覆盖比例**（如 `long soft shadows stretching leftward`、`shadow占画面40%强化立体轮廓`、Runway 礼服可 `≥50% 甚至 90% shadow fill`）。

#### 4. 自然光库 / 人造光库（可直接取用）

| 类别 | 词条（中/英） |
|---|---|
| 自然光 | 黄金时刻逆光 golden hour backlight、窗边柔和漫反射 soft diffuse from window、树叶斑驳光斑 dappled light through leaves、阴天散射 overcast diffused light、灰冷晨光 cold grey morning、天光 soft skylight、月光 moonlight |
| 人造光 | 暖床头灯 warm bedside lamp、电视幽蓝反光 blue glow from TV、钠灯橙 sodium orange、日光灯偏绿 fluorescent greenish、霓虹 neon、KTV 镭射、手机屏冷光、屏幕蓝光 screen blue glow |

#### 5. 设定图/参考图布光 ≠ 正片布光（关键区分）

> 这是新手最易踩坑处。**人物设定图/角色参考图要"看清外观"，正片镜头要"塑造情绪"。**

- **设定图/角色卡**：`soft frontal lighting / minimal shadow`、纯白背景柔和均匀环境光、无强方向阴影 → **禁强侧光/伦勃朗光**，以免干扰跨镜身份一致性识别。
- **正片镜头**：按情绪自由用强侧光、负补、深阴影。

### 二、色温与光比：把冷暖与明暗量化

#### 1. 色温对照（K 值 + 情绪）

| 色温区间 | 光感 | 情绪心理 | 典型场景 |
|---|---|---|---|
| 2500–3200K | 暗琥珀 / 暖橙 | 善意、亲密、温情；底光时转诡异/病态绿 | 烛光、夕阳、床头灯 |
| 3000–3500K | 暖白 | 温暖、回忆、梦境 | 柔光温情戏 |
| 3500–5000K | 中性偏暖 | 立体、人物刻画 | 侧光叙事 |
| 5000–5500K | 中性日光 | 真实、客观 | 自然外景、影棚均匀光 |
| 5500–6500K | 冷白 / 冷蓝 | 对立、疏离、压迫、临床 | 顶光审讯、夜班荧光 |
| 6500K+ | 冷蓝调 | 夜感、科技、寒冷 | 城市夜空、科技空间 |

#### 2. 光比（key:fill）参考

- **高光比 / 低调（low-key）**：3:1 或更硬，强对比、暗部为主 → 紧张、戏剧、动作、悬疑。
- **低光比 / 高调（high-key）**：均匀通透、暗部抬升 → 商业、产品、轻松、青春。
- **美学比例**：色彩/视觉重量常用 **6:3:1**（主色:辅色:点色）或 **9:1 色彩克制算法**（90% 主色域 + 9:1 仅在核心卖点区点缀强调色）。

#### 3. 曝光控制铁律

- 高光**不过曝**（除非风格化：窗边逆光/胶片可允许 `soft warm tones fading toward gentle overexposure` 轻微过曝、漏光）。
- 暗部**保留细节不死黑**（`detailed shadows`、保留暗部杂色质感）。
- 明暗过渡自然；可叠 `slight grain` 胶片颗粒、高光边缘轻微柔焦。
- 跨镜色温跳变铁律：工业/连续场景 **≤200K**；爆闪节点瞬间亮度可达常态流光 3 倍。

---

### 三、影调：整体画面的"语气"

影调 = 对比度 + 饱和度 + 高调/低调倾向 + 质感颗粒，是全片视觉气质的统一锚点。

| 影调类型 | 特征词（中/英） | 适配 |
|---|---|---|
| 院线低调暗部 | low-key、deep shadow、暗部为主 | 剧情、惊悚、对峙 |
| 柔和低对比胶片 | muted palette、film grain、soft highlights | 文艺、东亚情绪片 |
| 高调通透 | high-key、even diffused、lifted shadows | 产品、电商、轻松 |
| 电视转播现场 | broadcast grade、compression artifacts、interlacing / TV grain | 直播仿真 |
| 纪实低饱和 | low saturation、real dynamic range、保留暗部杂色 | POV、城市记忆 |
| 高反差工业暗调 | high-contrast low-key、razor-sharp shadow | 工艺纪录、工业品 |
| 奶油柔焦 | creamy bokeh、soft diffused、no harsh shadows | 微缩、治愈、羊毛毡 |

**质感锚点（高级感来源）**：湿皮肤/金属反光 `wet skin / metal reflection`、汗水细节、湿沥青反光 `wet asphalt reflection`、次表面散射 `subsurface scattering`（肉类/皮肤）、毛孔级材质、油脂高光 `high gloss grease`、丁达尔尘雾 `Tyndall + volumetric dust`。

### 四、色彩与色彩心理：情绪 → 色彩的可操作映射

**铁律：色彩不能只列 HEX——每个颜色必须说明它在画面上承担的叙事/材质功能，并落到具体的人物/道具/光线/阴影/背景。** 色卡锁材质本色，光影负责情绪明暗变化。

#### 1. 色彩三层结构

- **主色（dominant）**：统御画面 ~90% 区域，定情绪基调与作者气质。
- **辅色（secondary）**：补充、过渡。
- **点色 / 强调色（accent）**：仅在视觉/叙事焦点点缀（如动作戏 `orange accent points`、工业品科技蓝点缀）。

#### 2. 情绪/氛围 → 色彩心理 决策表

| 情绪/氛围 | 色温 | 主色倾向 | 光比/影调 | 关键词 |
|---|---|---|---|---|
| 亲密 / 温情 / 家 | 暖 3000–3500K | 暖黄、琥珀、陶土暖哑色 | 柔光低对比 | warm amber、soft fill |
| 怀旧 / 释怀 | 暖 | 黄昏金、褪色暖调 | 柔高光溢出 | golden hour、faded |
| 疏离 / 克制 / 夜感 | 冷 5500K+ | 幽蓝、冷白、青灰 | 高对比低调 | blue glow、cold detached |
| 压抑 / 窒息 / 宿命 | 冷 | 橄榄绿、青灰、深青 | 顶光/底光、低饱和 | oppressive、low saturation |
| 紧张 / 冲突 / 危险 | 冷暖对撞 | 去饱青灰 + 橙点 | 硬阴影高对比 | desaturated teal-grey + orange |
| 恐惧 / 诡异 | 暗琥珀/病态绿 | 底光绿、深暗 | 阴影上翻 | under light、sickly green |
| 希望 / 神圣 / 转折 | 暖金 3200–4000K | 金光体积光 | 强对比光锥 | god-rays、Tyndall |
| 梦幻 / 宁静 | 冷月光/暖烛光 | 薄荷蓝/月光白 或 暖白 | 柔焦奶油 | soft moonlight、creamy |
| 性感 / 迷离 / 微醺 | 混合 | 粉紫霓虹、高饱和 | 湿反光高对比 | pink-purple neon、wet reflection |
| 暴露 / 无处可藏 | 白日硬光 | 过曝边缘 + 深硬阴影 | 极高对比 | harsh sunlight、heat shimmer |
| 食欲 / 人文厚重 | 暖黄 | 食材本色 + 灰木底色 | 暖调 6:3:1 | backlit steam、warm humanistic |
| 青春 / 炽热 | 暖橙降饱和 | sunset orange、sakura pink | 软颗粒轻过曝 | pastel、漏光 |
| 高奢 / 高端 | 克制 | 哑黑+暗金 / 中性留白 | 低饱和奢华 | restrained palette、品牌色比重 |

#### 3. 类型化配色"四套词库"模板（可整段套用）

- **都市霓虹夜**：pink-purple neon、cyan highlights、wet black asphalt reflections、sodium lights → 性感/危险。
- **热带海岸黄昏**：golden hour glow、teal sea、palm silhouette、hazy sunset → 慵懒/逃亡感伤。
- **晨雾沼泽**：olive green muddy water、dense fog、silver gray、searchlight cutting haze → 紧张窒息。
- **白日硬光**：harsh tropical sunlight、overexposed edges、deep hard shadows、heat shimmer → 暴露无处藏。
- **工业四风**：冷峻工业（深灰+金属银+科技蓝 #4FC3F7，单点 45° 硬光）/ 赛博（电蓝 #00B0FF+电紫 #CE93D8，霓虹边缘描边）/ 极简纯白（中性白+浅灰，柔散无影）/ 暗金奢华（哑黑+暗金 #FFD54F，30° 暖金边缘光）。

#### 4. 群像/多人布光：用光影分配人物关系

> 光影必须服务关系：**谁被金光照亮 = 主、谁落入冷影 = 次、谁成为剪影、谁被环境吞没。** 经典做法：暖主光（落日金光）斜射照人物一侧，冷蓝阴影补色填背景暗部与人物另一侧，用明暗冷暖把群像分主次远近。golden hour 斜射金光是高级氛围光。

### 五、连续性：光影/色彩是空间与时间的锚点

- **空间锚点卡"光影基调"行**：每个场景登记 **光源类型 + 色温 + 氛围词**，作为跨镜锚点；相邻镜光影基调须衔接，除非剧情需硬切。
- **承接铁律**：`Shot N 开场光线必须延续 Shot N-1 结尾光线`；同场景内服装整洁度、道具位置、**光线入射角**必须一致。
- **全局调色锚点**：用 `Final_Video_Spec`（调色板 palette / 时代 era / LUT）单一来源向下贯穿全片；或用参考片段（≤15 秒便于色调提取）做色调提取。
- **色彩弧光（color arc）**：色调可随情绪推进收敛（如纪录片从溯源到成品收敛至预设基调，C 组最终帧须收敛到全片色彩基调）。
- **一键换主角/换脸类**：自动分析原片色温/亮度/对比度/饱和度为基准，替换区域匹配回原调，**no new lighting / no style filter**，相邻 shot 色温不得明显断层。

### 六、常见错误 / 禁止项

**布光类**
- 用**正面平光**拍情绪戏（消除立体与情绪感）。
- 把强侧光/伦勃朗光用在**人物设定图**（破坏身份一致性识别）。
- 设定图打出强方向阴影 / 正片该有的硬光柔不下来。
- 完全黑暗无可见光源（除非剧情明确需要）。
- 灯光全片平铺、无节拍的随机扫光/频闪（MV 单次灯光 hit ≤2 帧防频闪）。

**色彩类**
- **只列 HEX 不说功能**（颜色必须落到人物/道具/光/影/背景上）。
- 偏离锁定色卡 / 跨镜色调断层、突兀色彩跳变。
- 滥用**红蓝霓虹冲突**：除非用户明确要求，禁 `crimson bleed`（深红晕染）、禁 `neon magenta vs teal clash`（霓虹洋红 vs 青色对撞）——剧情片高频禁令。
- 高饱和纯色堆砌（治愈/文艺/纪实题材禁 bright red、neon）。
- 商业渲染过曝、CGI/塑料感观感（文艺/纪实/旅拍题材）。

**质感与真实性类**
- 过度磨皮、塑料感、"网红脸"美颜（旅拍/数字人/纪实须保留真实肤质）。
- 过曝/欠曝致细节丢失（强逆光、极端曝光 = 中–高质量缺陷）。
- 厚重预设滤镜、`AI sheen`（过度 AI 光泽）、`fantasy glow / symbolic / CG render` 滤镜（POV/纪实须导出即低饱和直出）。
- 死黑暗部、无层次阴影。

**禁色清单（题材专属）**
- 国风/传统工艺：`no neon lights / no cyberpunk colors / no digital glow / no modern industrial rendering`。
- 工业冷峻/纯白：禁柔光箱光晕、禁暖调、禁彩色补光、禁霓虹。
- 日系青春：禁 HDR 锐化、禁超清 CG、禁商业级锐化。

---

### 七、提示词落地速查（可直接拼接的术语包）

- **布光**：`three-point dramatic lighting`、`key light from [方向] at [角度]`、`negative fill / zero warm fill`、`strong chiaroscuro contrast`、`deep facial shadows emphasizing facial structure`、`rim light`、`Tyndall / volumetric god-rays`、`practical interior light`、`soft frontal lighting`（仅设定图）。
- **色温光比**：`warm 3000K amber` / `cold 6000K blue`、`split lighting ratio 3:1`、`low-key` / `high-key`、`mid-tone`、`6:3:1` / `9:1 color restraint`、跨镜 `≤200K`。
- **影调质感**：`muted palette`、`film grain / slight grain`、`soft highlights`、`detailed shadows`、`low saturation`、`creamy bokeh`、`wet skin / metal reflection`、`subsurface scattering`、`high gloss grease`、`TV grain / compression artifacts`。
- **色彩心理**：`90% dominant [color] shadows, zero warm fill`、`muted watercolor wash`、`desaturated teal-grey base with orange accent`、`golden hour sidelight + cold blue fill`、`warm muted palette (terracotta / dusty rose / sage)`、`pink-purple neon + cyan highlights`。
- **连续性**：`match lighting to previous shot`、`global LUT / palette from Final_Video_Spec`、`no new lighting / no style filter`、`color arc converging to preset baseline`。

## 声音与台词（音效 / 配乐 / 配音音色 / 台词情绪）

声音是分镜里被低估却最影响"质感"和"情绪"的维度。它不是给画面"配响"，而是和镜头、表演并列的第三条叙事轴：**音效给真实感、配乐给情绪、配音给人物、台词给信息与潜台词。** 本节把这四件事拆成可直接写进提示词的结构、参数与决策规则。

---

### 一、四层音频架构（统一心智模型）

无论什么题材，音频都按四层独立设计，再在后期混音对齐。**核心铁律：音频层独立于镜头视频生成**，否则每个视频片段自带的随机音轨会和总混音打架（语音重复、音量跳变、风格冲突）。

| 层 | 内容 | 默认数量 | 写法归属 |
|---|---|---|---|
| BGM（配乐 / music） | 全局或分段背景音乐 | 至少 1 条全局；长片(≥3min)按情绪转折分多段 | 独立 audio_layer，**不写进视频提示词** |
| Narration（旁白 / 画外音 / VO / OS） | 解说、内心独白、画外音 | 按需，长段跨镜才单设轨 | 独立 narration 轨，**绝不写进视频提示词** |
| SFX（音效 / Foley / 环境声） | 动作音、环境氛围声、拟音 | 按镜设计 | 多数可内嵌视频（模型烘焙）或独立轨 |
| Dialogue（台词 / 对白） | 角色开口说的话 | 按剧情 | **必须写进视频提示词**（驱动口型与音色） |

**关键区分：台词内嵌 vs 旁白独立。** 台词要写进视频提示词里驱动口型同步；旁白/VO 是独立音轨，**写进视频提示词会造成双重音频**，是高频错误。

**多段 BGM 规范：** 每段须带 `audio_id` + 覆盖范围(scope/range)，风格节奏匹配该段情绪，段间用 crossfade 衔接。

---

### 二、提示词音频标记语法（Seedance 2.0 / Kling 通用）

主流视频模型用四类包装符区分音频类型，**这是最高频的硬规则，必须记牢**：

| 符号 | 类型 | 示例 |
|---|---|---|
| `(...)` 圆括号 | 音乐 / 音乐情绪曲线 | `(fast-paced rock playing in the background)`、`(低频脉冲渐强)`、`(no music)` |
| `<...>` 尖括号 | 音效 SFX / Foley / 环境声 | `<distant dog barking>`、`<tire screech>`、`<滋滋声>` |
| `{...}` 花括号 | 口头对白（仅逐字台词） | `{Hello, world}`、`{宝，你今天怎么这么早回来}` |
| `【...】` 方头括号 | 屏幕标题 / 章节 / 字幕 | `【Chapter One: Departure】` |

**子规则：**
- `{...}` 内只放台词纯文字，**不留引号、不加情绪标注**（情绪写在括号外的 tone 里）。
- 非项目主语言的台词，**在花括号前标注语言**：`Says in Japanese: {こんにちは}` 或 `{EN: "Get down!"}`。
- 台词带情绪：`{[角色]说:"[台词原文]"} (with [情绪词] tone)`。
- 画面出现台词但不要字幕，台词后紧跟标注：`{你好，大理}(无字幕)`。
- 屏幕字幕 `【...】` 通常留空，字幕在剪辑端加。

---

### 三、负向标签铁律（防模型擅自加音频）

视频模型会自作主张加 BGM / 字幕，必须用负向标签压住。这是成片质量的隐形守门员。

| 负向标签 | 何时必加 |
|---|---|
| `no music` | **几乎总加**——有独立 BGM 轨时，防止片段自带音乐与混音打架 |
| `no subtitles` | **总加**——字幕统一在剪辑端加，防止烧录字幕 |
| `no dialogue` | 该镜无对白时显式声明（Kling 要求） |
| `no sound effects` | 不需要同步音效时显式声明 |
| `no vocals / no lyrics / no singing / no rap` | 纯器乐 BGM 场景（旅拍、意境、MV 伴奏） |
| `no narration` | 纯音乐片，防模型加解说 |
| `no logo / no branding` | 广告片防水印 |

**成片合成时的反向规则：** 若声音设计依赖**视频轨原生音**（如新品 TVC 的 SFX 桥梁、舌尖美食的拟音、城市记忆的画内声），则合成时打开视频轨音量（Video track volume: ON），且**不**自动生成独立 BGM。两种模式二选一，不可混用。

---

### 四、音效 SFX / Foley

#### 1. 分层（按优先级）
- **物体动作音 / Foley**：与画面动作严丝合缝对齐（切菜、脚步、布料摩擦、金属碰撞）。
- **环境氛围音 / Ambient**：场景底噪声景（车流、人群、白噪音、风声）。
- **机械 / 系统音**：UI 反馈音、机器低鸣、信号音。

#### 2. 优先级排序（同列冲突时）
- 动作戏：**动作冲击音 > 环境氛围音 > 对白**。
- 对话戏：**对话 > 环境 > BGM**（说话时压低 BGM）。
- 游戏 Demo：UI 音 / 环境音 / 打击音三轨并行，各管一类。

#### 3. 对齐精度（质检项）
- 关键动作音与接触帧对齐误差 **≤1 帧（约 33ms @30fps）**。
- 口型与台词/原音对齐误差 ≤1 帧。
- 对口型视频**禁变速**（防口型错位）。

#### 4. 常用环境音 / 物理音词库（中英对照）

| 场景 | 音效（中 / EN） |
|---|---|
| 街头城市 | 车流、远处警笛 distant siren、人群 crowd murmur、便利店门铃、自动门提示音 |
| 室内日常 | 钟摆、水龙头、键盘 keyboard、冰箱嗡鸣 fridge hum、电视新闻声 |
| 动作 / 武戏 | 重脚步 heavy footsteps、冲击裂响 sharp impact crack、空气破啸 whooshing air burst、轮胎尖叫 tire screech、玻璃碎 glass break |
| 美食 / 工艺 | 滋滋油煎声、清脆切菜声、咕嘟沸腾声、淬火嘶嘶 water hiss quenching、风箱呼啸 bellows blowing |
| ASMR / 亲密 | 贴耳呢喃 whispering close to ear、清晰呼吸、喉咙轻哼 soft hum、清脆亲吻 crisp kissing 'muah'、丝绸滑落、棉布沙沙 fabric rustling |
| 自然 | 蝉鸣、风声 wind、流水、鸟鸣 birdsong、雨声 rain patter |

#### 5. 非语言声音标签（MiniMax / 配音模型枚举，**仅英文，不可自创/翻译**）
`(laughs)(chuckle)(sighs)(gasps)(inhale)(exhale)(pant)(breath)(coughs)(groans)`；不在枚举内则省略。MiniMax 停顿用 `<#n#>`（n 秒，推荐 0.26–1.5s）。

### 五、配乐 BGM

#### 1. 音乐描述五要素（缺一不可）
**风格基调 + 核心乐器配置 + BPM 范围 + 情绪弧线 + 人声/歌词约束**。只写"温暖的音乐"模型会乱给；要写到乐器和 BPM。

示例：`warm and heartwarming, soft piano + light acoustic guitar, gentle slow tempo (~70 BPM), cozy nostalgic mood, no vocals`。

#### 2. 情绪弧线三段式
**开场建立 → 中段展示/叙事 → 收尾留白**；长片按幕拆段。动态曲线常用：渐起 → 高潮 → 舒缓。

#### 3. 音量分层（dB 关系，落地参数）
| 关系 | 推荐值 |
|---|---|
| BGM 相对人声/VO | 低 **8–12 dB**（作底层垫乐） |
| BGM 相对旁白（微缩/温情片） | BGM ≈ 旁白的 **40%–60%** |
| 情绪高潮 BGM | 临时提 **3–5 dB** |
| 说话时 BGM 自动压低（ducking） | 压到约 **-24 dBFS**，结束后 0.3s 回升 -18 dBFS |
| 极简画内声优先场景 | BGM 音量 **0.1x**，不抢画面 |

#### 4. 淡入淡出（crossfade）
- 片头 0–2s 线性淡入；片尾倒数 3s 以 **-3 dB/s** 淡出。
- 文艺片所有音频转换 **1–3s 淡入淡出，禁止硬切**。
- BGM 与旁白/台词交叉淡化 **crossfade 0.5s** 防音量跳变；环境音拼接处 crossfade 0.2s。
- 无缝纯切点处 BGM 与旁白须平滑不中断、无卡顿无音量突变。

#### 5. 题材 → BGM 基调速查表

| 题材 / 风格 | BGM 基调 + 乐器 + BPM |
|---|---|
| GTA/都市 | synthwave + modern rap + southern radio rock |
| 东亚文艺片 | 单一乐器线（钢琴单音 / 大提琴长音），情绪高点声画分离 |
| 工业 / 3C 产品 | 纯电子工业轻音乐，低沉鼓点，BPM 90–110，无人声 |
| 日系青春 MV | bright J-Pop，四段式 intro→verse→chorus→outro，活泼 130–140 / 副歌 110–120 / 感伤 80–90 / 黄昏 65–75 |
| 时装·休闲街头 | Nu-Jazz / Lo-fi Hip-hop |
| 时装·礼服晚装 | Chamber Jazz / 交响弦乐 |
| 时装·机能概念 | Industrial Techno / Dark Ambient |
| 时装·民族传统 | 融合民族乐器的当代编曲 |
| 传统工艺纪录 | 中国古典器乐，古琴/埙/编钟，低频共鸣，舒缓 |
| 旅拍唯美 | 纯音乐，渐起-高潮-舒缓，严禁歌词人声 rap |
| 羊毛毡/微缩温情 | soft piano + light acoustic guitar，舒缓温馨怀旧 |
| 室内沉浸 | ambient / lo-fi 空间声学轨道 |
| 小猫打工/职场喜剧 | 轻快俏皮职场喜剧感，节奏清晰 |

#### 6. 生成工具与硬规则
- 器乐：`text_to_instrumental`，**Suno 5**（首选）/ **Mureka 8**（备选，Suno 被拦截时切换）。
- **提示词严禁出现知名音乐人/艺术家姓名**（模型会拦截导致失败）。
- **严禁与版权歌曲高度相似的旋律/歌词。**
- 用户上传音乐 = 唯一主音轨，严禁替换/二次生成/改风格；过长取高潮段/hook 段。
- 编曲气质可参考歌曲名（如日系参考《恋するフォーチュンクッキー》），但**不点名艺术家**。

### 六、配音音色（Voiceover / Timbre）

#### 1. 音色一致性锚定（核心）
- 每个有台词的角色建 **`key_element_audio` 音色锚点**，作为 Seedance 2.0 跨镜头音频条件输入，保证全片语调一致。
- 音色描述须含：**音色（timbre）/ 语气（tone）/ 情绪基调**，与角色 element ID 绑定。
- **全片锁定同一音色，严禁中途切换。** 人声对白从首段含该人物的视频提取人声资产作后续参考。

#### 2. 音色获取三路径
1. 用户上传 **voice reference** 直接绑定（最稳）。
2. 旁白模型生成（取 3–5s 代表台词）。
3. Seedance 2.0 Fast 生成含开口讲话视频再提取音频（耗积分多，锁 14s 分段裁剪）。

#### 3. 配音生成模型选型

| 语言 / 用途 | 首选模型 | 备选 |
|---|---|---|
| 中文旁白/配音 | **MiniMax Speech 2.8 HD**（快/省积分） | ElevenLabs v3 |
| 英文/全球 | **ElevenLabs v3** | Doubao（豆包，中文原生，女默认 Girl / 男默认 Elegant Gentleman） |
| 歌曲/有人声 BGM | Suno 5 / `lyrics_to_song` | Mureka 8 |

**音色试听流程：** 取 10–20 字代表短句生成 3–5 个音色候选，由用户耳选后全片锁定。

#### 4. 音色 profile 写法（按角色类型）

| 类型 | profile 描述 |
|---|---|
| 纪录片解说 | 磁性男声，CCTV 纪录片腔，低沉有力，语速沉稳克制，气息饱满，情绪内敛 |
| 播音级商业 | 沉稳男声/清晰女声，中文普通话，语速平缓（基准 4.5 字/秒），播音级专业质感 |
| 温情叙事 | slow and warm 缓而暖，gentle sincere slightly nostalgic 温柔真诚略带怀旧 |
| 暧昧灵动 | 轻柔气声，句尾上扬 |
| 强势张力 | 压低音量，放缓语速，语气笃定 |
| 慵懒内心独白 | 收音机/电话窄频音质，轻微失真偷录感，语速偏慢，非干净播音腔 |
| 商品口播 | rhythmic pacing 有节奏语速，friendly narrator 友好解说者（重清晰发音而非诗意修辞） |

#### 5. 旁白 narration 轨设计要素
**声音身份（voice identity）+ 语调（tone）+ 确切脚本（exact script）+ `layout_instruction` 限定覆盖镜头范围**。VO 时间轴是定时的**唯一事实来源**，所有入/出点须与音频对齐，字幕仅在旁白出声区显示。

### 七、台词与情绪（Dialogue & Emotion）

#### 1. 台词写作铁律
- 写**准确台词（exact lines）**——逐字对白或内心独白/OS，通过 element ID 引用角色。
- storyboard **无旁白对白则不得自行添加**；有则**逐字保留不得改写**。
- 台词语言优先级：**角色画像 > 用户需求 > 用户输入语言**；内容严格遵循 `Final_Video_Spec` 的 Output Language（即使提示词主体用中文写）。
- 提示词主体可用中文，但 `{...}` 内台词、旁白、歌词用 video spec 指定的目标语言。

#### 2. 台词情绪 = 声音表演（不止文字）
- 情绪先用**声音 / 停顿 / 呼吸 / 手部犹豫 / 实际噪声**承载，再考虑对白；情绪爆发时常**声画分离**（画面给空镜/物件，声音承载全部情绪重量）。
- 把抽象情绪翻成可执行声音指令：不写"愤怒"，写"压低音量+放缓语速+句末重音"。
- **静默是最有力的情绪点**：环境声降至极低作"呼吸点"，孤独感声音锚 = 只有自己的呼吸声。
- 克制原则（文艺片）：台词内收，不做语言告白/倾诉式表达；不用播音腔；**方言口音优先于标准普通话**，允许口语化、吐槽、方言词。

#### 3. 昵称/称谓一致性（亲密/互动类）
全片只用一个昵称体系（甜蜜系：宝宝/宝/老公；撒娇系：臭宝/坏蛋/笨蛋），同一段同一昵称 **≤2 次**避免腻。

---

### 八、情绪/氛围 → 声音决策映射（可操作规则）

| 情绪 / 场景 | BGM | SFX / 环境 | 配音音色 | 台词处理 |
|---|---|---|---|---|
| 平静日常 | 无 / 极简环境音景 | 环境音为主（鸟鸣、钟摆、水声） | 自然口语 | 少台词 |
| 情绪积累 | 加入单一乐器线（钢琴单音/大提琴长音） | 环境音渐弱 | 渐压低 | 短句、留白 |
| 情绪高潮 | BGM 提 3–5dB 主导 | **声画分离**，降同期声 | 强势/压抑爆发 | 可静默或一句定音 |
| 情绪释放 | BGM fade out | 环境音单独留存并降音量制造"空寂"（比开头更空） | 气声/哽咽 | 收尾尾音状态 |
| 紧张动作 | 低频脉冲渐强，鼓点停顿后重入 | 冲击音 > 环境 > 对白 | 急促 | 短促命令式 `{Get down!}` |
| 暧昧亲密 | no music 或极轻 | ASMR：呢喃/呼吸/摩擦音逐秒标注 | 轻柔气声句尾上扬 | 昵称体系一致 |
| 商业冷感/高奢 | 冷调弦乐铺底 + 品牌 Hero 瞬间音乐抬升 | 物理 SFX 作连续性桥梁（皮革/金属/低频下潜） | 无或极简 | 多无台词 |
| 怀旧温情 | soft piano + acoustic guitar，舒缓 | 暖心环境音 | slow and warm 略带怀旧 | 温柔克制留白 |
| 史诗厚重 | 古典器乐，低频共鸣 | 古琴余震、风箱低频 | CCTV 纪录片腔，低沉有力 | 句式凝练意象丰富 |

**通用决策规则：**
- **超过 3 个连续镜头无音效/音乐变化** → 第 3 镜结尾引入微弱音效层（单音钢琴/环境音变化），防注意力涣散。
- **声音是跨镜头连续性的桥梁**：转场音、SFX 尾音、音乐节拍、低频冲击、呼吸节奏须跨片段承接；画外音效（如玻璃碎裂声）可触发下一镜头反应与转场。
- **画内声（diegetic）优先于外加配乐**——纪实/生活流题材尤其，环境声优先于 BGM。
- 即使是**图像提示词**也可加环境声描述帮模型理解场景气质（远处风声/机械吱呀/绝对静默/无对白/无 BGM），不生成声音只定氛围。

---

### 九、常见错误与禁止项

**禁止 / 易错：**
- 把旁白文本写进视频提示词 → 双重音频冲突（旁白必须独立轨）。
- 忘加 `no music` / `no subtitles` → 模型自带 BGM 和烧录字幕污染混音。
- `{...}` 台词里保留引号或塞情绪词（情绪写括号外 tone）。
- 提示词出现**知名音乐人/艺术家姓名** → 模型拦截生成失败。
- 生成与版权歌曲高度相似的旋律/歌词。
- 用户上传的音乐被替换/二次生成/改风格。
- 全片音色中途切换；把姿态参考误当音色参考。
- 非语言声音标签自创或翻译（必须用英文枚举 `(laughs)` 等）。
- 对口型视频变速 → 口型错位。
- 音效盖过主音乐/人声；BGM 不做 ducking 直接压住对白。
- BGM 音量跳变、硬切（须 crossfade）。
- 自行给 storyboard 没有的镜头加台词，或改写既有台词。
- 只写"温暖的音乐"这种空描述（缺乏乐器/BPM/人声约束）。
- 两种合成模式混用（既依赖视频原生音又生成独立 BGM）。
- BGM 含歌词/人声却用在需要纯器乐的舞蹈 MV/旅拍/意境片。
- 音画对齐误差 >1 帧（33ms）仍放行。

**质检清单（交付前过一遍）：**
- [ ] 每条 BGM 有风格+乐器+BPM+情绪弧线+人声约束？多段是否各带 audio_id 与范围？
- [ ] 每个有台词角色是否绑定 key_element_audio 音色锚点，全片一致？
- [ ] 视频提示词是否含 `no music`/`no subtitles`（或反向 Video track ON 模式明确）？
- [ ] 台词是否逐字、`{...}` 包裹、非主语言已标注语言、无多余引号？
- [ ] 旁白是否独立轨、未写进视频提示词、时间轴与入出点对齐？
- [ ] 关键动作音/口型对齐误差 ≤1 帧？对口型视频未变速？
- [ ] 音量层级（BGM 低人声 8–12dB、ducking、crossfade）是否落参数？
- [ ] 是否避开知名艺术家姓名与版权旋律？

## 表演与节奏（微表情 / 动作设计 / 剪辑节奏）

> 本节解决三个互相咬合的问题：**人物在镜头里做什么（动作设计）**、**做的时候脸上身上漏出什么（微表情/潜台词）**、**这些瞬间以什么速度被切在一起（剪辑节奏）**。三者必须协同：动作是骨架，微表情是血肉，剪辑节奏是呼吸。任何一项缺失，画面要么"杂乱合影"要么"念稿子"。

---

### 一、底层心智：表演不是"演情绪"，是"留下情绪的证据"

- **拒绝直接表达情绪，改写可拍摄的生理信号 / 物理动作。** 不写"他很愤怒""她很伤心"，写喉结滚动、拳头攥紧又松开、眉头反应、眼眶湿润未落泪、肩膀呼吸起伏。模型只能渲染可见物，看不见动机。
- **把动作"定格在戏剧性瞬间"，拒绝生硬摆拍（reject stiff posed look）。** 用潜台词（subtext）+ 氛围词锚定状态：
  - oppressive suffocation（压抑窒息）、no mercy（冷酷无情）、predatory stillness（捕食者般的静止）、piercing gaze（锐利目光）、cold and detached atmosphere（冷漠疏离）、Destined aura（宿命感）。
- **无生命物也"表演"。** 物体写其状态/气场而非外观：宿命感的光、被风吹落的纸、突然熄灭的灯、空椅子、摔碎的杯子——这些是情绪的转喻载体。
- **静止也是表演，且必须显式写出。** 主体不动时不能留空，写明 stands perfectly still / staring forward / 僵立 / 目光钉死，否则模型会自行加入随机微动。
- **真人感的核心是"不完美"。** 自然微笑而非表演式微笑（not over-performing）、不锁定与镜头对视、副歌手势略有参差、稍乱发丝、业余魅力——刻意的完美反而假。

---

### 二、动作设计：工程化四要素

写每一个动作都按"部位 → 方向 → 程度 → 时序"落地，禁止抽象动词和"瞬间到位"。

#### 1. 锚定身体部位
- 落到具体部位：手 / 腿 / 头 / 肩 / 肘 / 腕 / 胯 / 膝 / 踝 / 重心 / 脊柱 / 颈部 / 眼睑。
- 反例"握剑" → 正例"右手从腰间缓缓抬起，指尖微微颤动，才握住剑柄"。

#### 2. 叠加"程度" = 幅度 + 速度 + 强度
- 必带程度副词，使表演无歧义（quickly / violently / large amplitude / high frequency）：
  - slowly raises one hand（缓慢举起一只手）
  - snaps head left（头迅速向左转）
  - pushes hard off the ground（用力蹬地）

#### 3. 完整的动作弧线（起势 → 运动 → 收势）
- 任何动作必须有 **起势（蓄力/预备）→ 运动（过渡）→ 收势** 三段，禁止"瞬间到位"式静态动词。
- 写出流畅弧线：如"右臂以肩为轴缓缓展开，掌心向上，指尖最后舒展"。
- 柔性角色（毛毡/羊毛/萌宠）：walks smoothly / gently reaches out / turns around softly / slowly leans forward；禁 jerky / stiff / stuttering / swings arms wildly。

#### 4. 多节拍按时序排列（主 → 次）
- 单提示词内多动作按"主要动作 → 次要动作"且**按故事时间顺序**排列。
- 多主体写法：`主体1 + 动作1 + 动作2；主体2 + 动作1`——模型对多节拍、多主体反应强烈。
- 用承接词显式排序：**First / Then / Finally**、`as subject reaches…`、`then cutting to…`、镜头1/镜头2/镜头3。

#### 动作设计铁律（强约束）
- **一镜只承载 1 个主行为**（加油 / 递东西 / 开门 / 点烟）；禁止并行复合剧烈动作（不可"边加油边打电话掏枪"）。每个短镜只承载 1 个信息点。
- **受击/反应动作必从受力姿态写起**，不是中立站姿（被击打 → 倒地，起手帧即受力姿态）。
- **力学后果连续**：每个动作回应上一个、造成下一个的身体/空间结果；严禁"上一秒被压制下一秒无理由重置姿态"。
- **Secondary Motion（随动）必写**：裙摆 / 飘带 / 长发 + 延迟程度（轻/中/重）+ 摆动方向（如"裙摆转身后延迟 0.3s 摆动""发丝随侧步甩出弧形"）。
- **物理真实闭环**：动作符合人体动力学，无卡顿、无穿模、无跳帧；杜绝游戏 CG 感。

### 三、微表情库（可直接抄写的术语索引）

| 部位 | 可拍摄信号（中 / EN） |
|---|---|
| 眼（轮匝肌） | 眼轮匝肌收缩、上睑提升、下睑紧张、眼角带笑（eyes crinkling）、笑到眯眼月牙眼、瞳孔微扩（pupils dilate）、视线先躲闪后缓慢回望、睫毛微颤（lashes flutter）、眼尾上扬、眼眶微红不落泪（welling, not falling）、眼神拉丝、gaze locked ahead / eyes downcast |
| 眉 | 眉头聚拢（brows knit）、眉眼弯弯、眉头反应 |
| 唇 / 颌 | 轻咬下唇（bites lower lip）、嘴角单侧微勾（约 3mm，corner of mouth lifts slightly）、嘟嘴（pout）、唇微张后闭合、嘴角下压、压唇、启唇、下颌放松 / jaw tightening、嗓音像砂纸磨过 |
| 颈 / 头 | 喉结滚动（throat bobs）、轻侧头（slight head tilt）、歪头约 5–10°、低头后抬眸、回眸 |
| 手 / 肩 | 指尖虚挡镜头、单手撩拨刘海、手部停顿/犹豫、手触衣领、攥衣领、肩膀呼吸起伏、深呼吸后肩膀微落（release）、shoulders heaving |
| 整体 | 重心前倾靠近镜头、慵懒侧卧、脸颊轻鼓（假生气）、wink、from focused to shocked awe（表情弧线） |

**情绪状态 → 微表情组合速查**

| 情绪 | 组合配方 |
|---|---|
| 慵懒 | 眼神迷离 + 肢体柔软 + 鼻音 + 动作迟缓 |
| 快乐 | 笑容明媚 + 动作轻快 + 清脆笑声 + 眉眼弯弯 |
| 撒娇 | 嘟嘴 + 歪头 5–10° + 小动作丰富（扯袖/踮脚） |
| 假生气 | 脸颊轻鼓 + 假装不理 + 视线别开后偷瞄 + 轻锤画面边缘 |
| 克制的悲伤 | 眼眶湿润未落泪 + 手指攥紧未捶桌 + 深呼吸后肩膀微落 |
| 警觉 | 喉结滚动 + jaw tightening + 表情 from calm to alert |

> **表情要写"弧线"而非定值**：from focused to shocked awe、from calm to alert——情绪是过程，不是状态标签。

### 四、剪辑节奏：四大节奏制式

剪辑节奏的本质是**叙事信号**：慢 = 时间凝结 / 情绪沉淀，快 = 人物或空间在运动 / 信息密集。选制式前先判断片子属于哪一类。

#### 制式 A — 呼吸结构（文艺片 / 情绪驱动 / 克制表演）
- **吸气（铺垫）**：较长镜头、固定机位、建空间 → **屏息（高点）**：延长留白不加速，音乐权重高于画面 → **呼气（释放）**：空镜/物件特写配"变空"音效，比铺垫更安静。
- 单镜头 ≥ 6s，避免 MV 式快切；3–4 个镜头 = 一个情绪单元，单元总时长 30–50s。
- 情绪爆发四策略（绝不拍崩溃大哭）：声画分离 / 情绪前置（爆发前一秒）/ 情绪后置（爆发之后的余波物件）/ 转喻（熄灭的灯、关上的门）。

#### 制式 B — 商业能量节奏（TVC / 广告 / 电商）
- 靠**更多剪辑 + 硬切**获取能量；短镜头为主，每剪辑必有清晰视觉变化。
- **每 3s 一个反馈点，每 7s 一个高潮**；每 15s 含 5–12 镜；画面动效不间断。
- 强制时间码（仅限可执行时间码的模型，如部分 TVC 流程）：
  - 0–3s 品牌钩子 + 第一反馈点 → 3–6s 气质/材质核心 → 6–8s 第一情绪高潮 → 8–12s 价值/理念升级 → 12–15s Hero Moment / 记忆点 / 下段衔接。
- 慢动作镜保持原始慢速，**禁二次加速/插帧**。

#### 制式 C — 动作/武戏密度节奏（半拍法则）
- 节奏靠**加速、停顿、爆发的对比**，不是匀速；动作之间的"半拍"停顿是张力来源。
- 节拍密度决定段长：
  - **爆发板**（连续打击/混战，因果紧密无停顿）：目标 6–8s，优先取下限 6s 强化紧凑；追加 `snapping cuts, explosive action rhythm, no slow motion, rapid kinetic energy`。
  - **过渡板**（拉距/蓄力/喘息/大幅推拉）：目标 10–15s；追加 `deliberate pacing, building tension, smooth camera movement`。
- 每个 1.5s 片段内部仍保留完整微节奏：**蓄力 → 出招 → 碰撞 → 反应 → 收势**。
- 高潮放慢镜（慢镜只用于全片情绪顶点，≤2 次，禁用于道具/读取镜）；抖音快节奏前 3s 立冲突，快切打斗每镜 1–2s。

#### 制式 D — 长镜内部节奏（一镜到底 / 零剪辑 / 跟随叙事）
- 剪辑频率**服从叙事节奏**，镜头内部以"节拍推进"而非切碎；长镜首选，节奏由内部剪辑承载。
- 一个长镜用满模型预算（≤15s），故事支持时塞 ≥6 个内部节拍承载更密表演与情绪流转。
- 零剪辑生活切片：5–12s 一镜到底，节奏由"视线往复"（瞥向场景 → 瞥向镜头 → 再回场景）支撑，自然松弛不赶。
- VO / 口播主导：**一句完整台词为一个最小剪辑单元，绝不在句中硬切**；纯顺序拼接，节奏跟随旁白呼吸。

### 五、镜头时长经验值（速查表）

> 跨制式综合后的内切镜参考值，按景别和功能取值；加运镜各 +1s。

| 景别 / 功能 | 含台词 | 无台词 / 纯视觉 |
|---|---|---|
| 大特写 / 手脚特写 | — | 1.5–2.5s |
| 面部特写 | 2–4s | 1.5–3s |
| 近景胸像 | 2.5–4s | 2–3s |
| 中景 / 中全景 | 3–5s | 3–4s |
| 全景 / 大全景（建立镜） | — | 3–5s |
| 普通叙事镜（萌宠/微缩等） | 4–6s | — |
| 高潮特写 | 6–8s | 6–8s |
| 余韵收尾镜 | — | 8–10s（最多 1–2 个/段） |

**分层节奏（城市记忆/纪实类）**：短镜 2–3s（物件插入/情绪反应切，制造跳动）/ 中镜 6–10s（叙事主干约 60%）/ 长镜 11–15s（建立/沉淀/余韵，每段最多 1–2 个）。

### 六、宏观节奏曲线与段落功能

- **绝对节奏法则（旅拍/MV 型）**：开篇快切（10–15 镜）→ 铺垫舒缓（5–8 镜）→ 高潮密集（15–25 镜）→ 结尾余韵（5–8 镜）；**严禁任一段少于 5 镜**；全片宏观曲线 = 开头快 - 中间缓 - 高潮密 - 结尾舒。
- **POV / 沉浸式**：全片前快后慢（前半紧凑 → 后半放缓），情绪递进 起始 → 转折点 → 高潮 → 结束。
- **情绪曲线回收**：每 15s 至少回收一个情绪点 / 反差萌；长视频叙事须向前推进，**禁重复上段动作/台词节拍**。
- **结尾铁律**：不以短切收尾；情绪片末镜建议黄昏/定格类 ≥5s（定格笑容/夕阳剪影），形成可截图传播的"名场面"。
- **短版剪枝非等比压缩**：按优先级保留高价值段落（如 30s 保欢笑+舞台+黄昏，15s 仅欢笑+黄昏），而非整体均匀压扁。

---

### 七、音画与节奏对齐

- **卡点**：切镜点优先落强拍 / 小节开头 / 8-count 开头 / drop / break / fill / hook / 动作 pose 点；视觉强事件落 BGM 强拍（每小节第 1、3 拍）±0.1s。
- **旁白对齐**：每句开口在镜头开始后 0.3–0.5s 起声，句尾在强拍前 0.5s 收；爆闪/模块到位前后各 0.5s 禁旁白起收（留视觉呼吸）；旁白每句须能在画面找到对应视觉意象。
- **衔接/转场**：相邻片段 0.1–0.2s 音频交叉淡化避免硬切；多片段做响度标准化（loudness normalization）保音量均衡；L-Cut / J-Cut 错位提升流畅；音效跨镜叙事（如玻璃碎裂声触发下一镜反应/转场）。
- **错位微调铁律**：为对齐只做极小幅度微调，**不得大幅变速音乐或视频，不得为对齐破坏动作完整性**。

---

### 八、连续性与镜头衔接（跨镜稳态）

- **承接一致**：Shot N 开场的角色站位 / 视线方向 / 手势必须与 Shot N-1 结尾一致，再自然演化出动态连续。
- **物理稳态**：同一场景不同镜头间，服装整洁度、道具位置、光线入射角必须一致；跨镜服装/发型/道具状态保持一致。
- **段末标状态**：每段末写明双方/主体状态，供下一段承接（武戏尤其强制）。
- **跨镜手段**：动作匹配剪辑（match-cut）/ 音乐或声音衔接 / 视线引导。
- **复刻类强约束**：复刻原片时人物动作轨迹/姿态/面部朝向/节奏须与原片完全一致，不添加原片没有的动作；保留原始切点，逐镜对齐原时间轴，总时长误差 ≤0.1s。

---

### 九、计时铁律（模型能力适配）

> **这是最容易踩的坑**：不同模型对"时间"的理解能力差异极大，写法必须分流。

| 模型类型 | 计时写法 | 禁止 |
|---|---|---|
| 对绝对秒数**不敏感**（Seedance/Kling 类多数场景） | 速度形容词（slow/quick/lingering）+ 顺序词（First/Then/Finally）+ 镜头1/2/3 | 写"在 2 秒时""5–8s""0–3s/3–6s"逐秒计划 |
| 支持**时间码**（部分 TVC / 长镜内部节奏） | 明确时间标记 + 剪辑标记（0–4s/4–8s/8–12s）对齐节拍 | — |

- **核心原则**：能用"按顺序发生的事"描述就别用秒级时间表；不确定时一律退回顺序描述。
- Seedance 运动提示词固定顺序：**摄像机 → 主体 → 空间 → 音频**；主体层 = 动作 + 表情。
- 单 shot 时长须为整数（如萌宠类每 shot 3–5s）；时长不够宁可重跑，**禁拉伸**（破坏音画同步）。

---

### 十、情绪/氛围 → 节奏与表演 决策映射

| 情绪 / 氛围 | 表演（动作幅度） | 微表情重点 | 剪辑节奏 | 变速 |
|---|---|---|---|---|
| 紧张 / 压迫 | 克制、predatory stillness | jaw tightening、gaze locked | 快速/不稳节奏，硬切+闪白 | 默认不变速 |
| 温暖 / 怀旧 | 自然柔和动作、保留停顿 | eyes crinkling、轻侧头 | 缓慢/留停，长镜为主 | 禁慢动作煽情 |
| 悲伤（克制） | 微表情渐变，禁爆发 | 眼眶湿润未落泪、肩落 | 呼吸结构，单镜≥6s，转喻收尾 | 慢镜只用微小瞬间 |
| 兴奋 / 能量 | 外化为可拍动作（张臂/转圈） | 笑容明媚、眉眼弯弯 | 高密度快切，每 2–3s 切景别 | 可卡点 |
| 平静 / 意境 | 极度克制，仅自然轻动效 | 几乎无表情，目光移开 | 随音乐段落推进，不卡无关点 | 原速 2–3 倍内 |
| 喜剧 / 反差 | 把"梗"演出来而非靠字幕 | 夸张但可信的反差萌 | 前 3s 立冲突，每 7s 一梗点 | 高潮可放慢镜 |
| 高奢 / 仪式 | 步态仪式感、克制（runway） | piercing gaze、statuesque | 强时间码，每 3s 反馈每 7s 高潮 | 不变速 |

**通用决策规则**：
1. **先判戏属性**（文戏/武戏、单人/双人/多人）再定调度与节奏，焦点主体每镜必须明确指认。
2. **情绪越重，节奏越要慢/留白**（话越少事越大，deadpan 干冷克制）；信息越密，节奏越快。
3. **冲突/转折镜（承/转）加快，叙事镜（起/合）拉长停留。**
4. **运镜与表演配合**：推镜时主体 motionless 让情绪靠光与机位推进；拉镜时主体渐被环境 dwarfed；跟拍逃跑用 handheld sway + full speed 奔跑。

### 十一、常见错误与禁止项

- ❌ **写抽象情绪**（"他很愤怒"）而不落生理信号 → 模型无从渲染。
- ❌ **生硬摆拍 / 瞬间到位**：缺起势收势的静态动词（直接"握剑""转身到位"）。
- ❌ **一镜塞多个主行为 / 并行剧烈动作**（边加油边掏枪）→ 动作糊、信息散。
- ❌ **静止不写明**：主体该静止时留空，模型自加随机微动破坏潜台词。
- ❌ **逐秒计时喂给不敏感模型**（"在 2 秒时…""0–3s/3–6s"）→ 规划与成片错位。
- ❌ **为对齐 BGM 破坏动作完整性 / 大幅变速** → 音画失同步、动作糊化（同段不叠加超过一次降速）。
- ❌ **MV 式无意义快切**用于情绪片；**情绪高潮/关键动作中途断开**镜头。
- ❌ **慢动作滥用**：用于动作场面或道具读取镜（慢镜把情绪对象化，只配全片情绪顶点）。
- ❌ **结尾用短切收尾** / 短版等比压扁所有段落。
- ❌ **跨镜不承接**：Shot N 起始站位/视线与 Shot N-1 结尾冲突；服装/道具/光向跳变。
- ❌ **重复上段动作或台词节拍**，叙事原地踏步。
- ❌ **夸张表演 / 表演式完美**（over-performing、锁定对视、强烈性感化、夸张泪水）破坏真人可信感。
- ❌ **镜头运动与角色运动方向冲突**（跟拍/环绕方向相反）→ 观感眩晕、动作读不清。

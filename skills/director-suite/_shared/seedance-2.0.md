# Seedance 2.0 模型适配层（导演套件 · 皮③）

> 作用：把"皮③ 输出契约"产出的镜头卡，翻译成 Seedance 2.0 真正吃得最好的提示词写法。其它模型（Kling/即梦/Veo/Sora）可另建适配层，本套件默认 Seedance 2.0。

## 1. 语法速查（Seedance 2.0 专用标记）

| 元素 | 写法 | 例 |
|---|---|---|
| 对白 | `{语言:台词原文}` | `{普通话:这一次，没有退路。}` |
| 音效 | `<音效描述>` | `<金属管坠地，低频撞击>` |
| 背景音乐 | `(配乐描述)` | `(单钢琴，极简，留白)` |
| 屏幕标题/字卡 | `【标题文字】` | `【三年后】` |
| 参考图占位 | `<<<image_1>>>, <<<image_2>>> …` | 逐一绑定角色/场景/道具参考图 |
| 固定负向 | `no subtitles`；无独立配乐轨时加 `no music` | 防自动烧字幕、防乱配乐 |

## 0. 生成单元 = 镜头组（v2.0 核心 · 双时长观落地）

> **一个「镜头组」(10–15s) = Seedance 一次生成 = 一条 prompt。组内的「镜头」是这条 prompt 内部的镜内分切（用过渡词+切镜方式串联），不是各自单独生成的片段。**

- 这从结构上消除了"剪辑时长(单镜1.5–5s) vs 生成时长(Seedance≥4s)"的矛盾：单镜短没关系，它只是这条 10–15s 生成里的一个内部切点。
- **禁止**把组内每个 2–3s 的镜各自送一次生成（碎、贵、不连贯、且低于 4s 下限）。
- 组时长须落在 [4,15]s；推荐 10–15s 吃满生成窗口。

## 2. 五条铁律（Seedance 2.0 偏好）

1. **禁壁钟式时间切分**：prompt 里不要写 `0–3s / 3–6s` 钟表轴；用**叙事节拍顺序**（"开始于…→当…→随后…→最后…"）。镜头卡用「时长」规划，emit 给 Seedance 时转成节拍语序。
2. **运动堆栈顺序固定**：① 摄影机运动（机位/运镜/切换节奏）→ ② 主体动作（肢体/表情/台词节拍）→ ③ 空间变化（场景/环境移动）→ ④ 光感强化（光型/色温变化）→ ⑤ 音效/对白。**摄影机运动永远在首位。**
3. **一条 prompt 承载整组的镜内分切**：把组内 4–7 个镜用过渡词与「切镜方式」串成一段连续运动（"开始于全景缓推…硬切到中近景…当他抬眼，推近面部锁定…"），这就是 §0 的生成单元。
4. **首尾帧 / 参考一致性**：跨组强连续时，把上一组尾帧作为下一组 `reference_video`/首帧；角色/场景/色卡用参考图占位符绑定，保证跨组不漂。
5. **时长**：一次生成 = 一个镜头组 4–15s（推荐 10–15s）。`Σ组内镜时长 ≈ 组时长`。长对白时长按默会估值（标 `≈`/区间），不假装精确到帧；一句长台词撑过 15s 就按语义停顿拆到下一组。

## 3. 镜头组 → Seedance prompt 转换模板（一组一条）

```
【可选字卡】
开始于<镜头1 起幅景别+机位+运镜>，<主体+动作+表情>。
<切镜方式>到<镜头2 景别>，<主体动作/台词节拍>。
当<叙事节拍转折>，摄影机<镜头3 运镜>，<新景别>对准<新主体/角度>。
…（把组内 4–7 个镜按切镜方式串完）
<空间/环境变化>。<光型+色温+光比 的光感强化>。
{普通话:对应台词} <环境/事件音效> (配乐或 no music)
<<<image_1>>>=主角  <<<image_2>>>=场景
8K photorealistic, cinematic film grain, <镜头型号/焦段>; no subtitles, no plastic skin, no CGI gloss, no extra fingers.
```

## 4. 与"固定输出格式"的关系（重要）

- 给**人看的镜头卡**：保留 v2.0 契约格式（镜头组头含场景级锁定 + 各镜含 时长/主情绪/节奏/景别/相机/运镜/构图/光影分层/画面内容三段式/音效/切镜方式）——便于规划、对账、复用。
- 给**Seedance 的成片提示词**：**每个镜头组**末尾附一段按本适配层转换好的"可直接粘贴"提示词（中文为主 + 关键英文 + Seedance 标记），它把该组所有镜内分切串成一条。
- 二者并存：镜头卡是"蓝图"，每组一条 Seedance prompt 是"施工单"。

## 5. 常见错误（喂 Seedance 时）

- 把钟表时间轴塞进 prompt → 模型乱切/卡顿（用节拍语序）。
- 把组内每个短镜各自单独生成 → 碎、贵、不连贯、低于 4s 下限（应一组一条 prompt）。
- 把光感写在最前面 → 摄影机运动被弱化。失序即失控。
- 台词只写在"对白"、没进 `{语言:台词}` → 口型不同步。
- 忘了 `no subtitles` → 画面被自动烧字幕。

## 1. 问题陈述 Problem

director-suite 的"接地宽度"有一道**已知缺口与一道隐性缺口**，二者都落在 Bone 层的 `_shared/style-refs.md`（题材气质 / 名家参考库）与 README 的成员花名册上。

**现状（引 director-suite 具体文件）。**

- **断连 4 源未纳管（已知缺口·README 自陈）。** `README.md` L88 白纸黑字写"导演专业知识接地抽取自 **44/48** 个影视 skill（**4 个因网络中断未纳入，同类已覆盖**）"。这 4 源按方向简报为：**HappyHorse 东亚文艺 / 人文纪录 / 一图成片（执行导演）/ 主题变身特效**。README 用一句"同类已覆盖"把它们勾销，但**从未逐源核对"同类是否真覆盖、覆盖到哪一行"**——这是一句**未经验证的承诺**，与 D3「可移植性是口头承诺」、D2「学习闭环是死的」同型。
- **`style-refs.md` §六「分题材气质速查表」是当前唯一的题材覆盖账本。** 它已收 14 行气质条目（东亚文艺片/慢电影、纪实观察、黑色剧情、高奢 TVC、GTA 开放世界、体育转播伪纪实、日系青春 MV、国风纯意境、一镜到底 POV、微缩世界、羊毛毡、动作预演分镜、群像主视觉、武戏）。**关键事实：方向简报点名的"5 个缺类"里，有 3 个其实已在此表里有一行**——`一镜到底 POV/室内`（L128）、`动作预演分镜`（L131）、`体育转播伪纪实`（L125）。**它们"有一行气质锚词，但没有专属成员 / 没有专属管线 / 没有 D9 基线"**——是"半覆盖"，不是"零覆盖"，也不是"已完成"。
- **真正零覆盖的，只有 2 类：POV 互动（互动叙事/分支）与 拟人风格化（把抽象主体拟人化的风格变身）。** 前者在 `storyboard/SKILL.md` 的"剧本→线性分镜"管线里**没有任何分支/选择/状态机入口**（管线 6 步全是线性时序）；后者在 `style-refs.md` §六只有"羊毛毡/微缩世界"等**质感变身**行，没有"**主题变身特效（把 A 拟人成 B / 把抽象拟人成角色）**"这种**主体置换型变身**条目。
- **断连源的"独门能力"没有落点。** 一图成片有"**视觉基因解构**"（README/源生态证据，D2/D5 已引），主题变身特效有"**一图→特效变身序列**"，人文纪录有"**真实人物/事件的纪录片伦理与采访镜头语言**"，HappyHorse 东亚文艺是"**慢电影气质的体系化招式**"——其中东亚文艺与 `style-refs.md` L106/L120 行**高度重叠（真覆盖）**，而"视觉基因解构 / 变身序列 / 纪录片伦理"这三样**在套件里搜不到对应承载**。

**痛点（为何是问题）。**

1. **"同类已覆盖"是未证伪的安慰剂。** README 一句话把 4 源勾销，但没有"逐源能力 × 套件落点"的对照核验。**若其中某源有独门能力（如视觉基因解构）确实没落点，用户撞上该需求时套件直接哑火**，而账本却显示"已覆盖"——这是 D 类（覆盖与品味）最危险的形态：**纸面覆盖率虚高，真实覆盖有洞**。
2. **"半覆盖"被误当"已完成"会重复造轮子或漏做。** 一镜到底 / 动作 previz / 转播伪纪实已有气质行，若 D10 不分清"哪些只需补深、哪些要立专属成员"，会出现**两种错误**：(a) 把已有行当成"新增"重写一遍（浪费 + 口径分裂）；(b) 以为"有一行就够了"，不给它配 D9 基线，于是这些题材**永远没有可回归的验收锚**。
3. **POV 互动是套件架构级盲区，不是补一行能解决的。** 线性管线产线性时序卡；互动叙事需要"分支节点 / 状态 / 选择回边"，这与 `storyboard/output-contract.md` v2.0 的"场景→镜头组→镜头"线性三层**结构不兼容**。漏判它的"补位成本"会让 D10 估算失真。
4. **一次铺满 = 死覆盖。** 若 D10 把所有缺类一次性全立成员，会重蹈 `style-refs.md` 283 条名家库"靠人工增补、不自我进化"的覆辙（D2 §1 已点名）——**覆盖必须随真实需求滚动，且每补一类都要带可回归的验收基线，否则又是一摊没人验证、没人维护的死条目**。

> 一句话：**覆盖账本（README"44/48 同类已覆盖" + style-refs §六 14 行）从未被逐源逐类核验，纸面覆盖率虚高、半覆盖被当已完成、2 类真空、断连源独门能力无落点**。这正是缺口类 D（覆盖与品味）。

## 3. 目标与非目标 Goals / Non-Goals

**目标。**

- G1：建立**断连源逐源核对账** `docs/optimization/coverage-ledger.md`——对 4 个断连源 + 方向简报点名的缺类，逐项给"该源独门能力 → 套件落点（真覆盖 / 半覆盖 / 零覆盖）→ 处置（确认 / 补条目 / 补成员）"，把 README L88"同类已覆盖"从口头承诺升级为**可核验账本**。
- G2：**按真实需求滚动补位，分级处置**——区分三档：**(a) 真覆盖** = 仅在 ledger 确认 + 必要微补；**(b) 半覆盖** = 补深 `style-refs.md` 气质条目（不立成员）；**(c) 零覆盖** = 补气质条目（拟人风格化）或立轻量成员（POV 互动）。**每档都明确"为什么是这档"**。
- G3：**每补一类配 D9 基线一条**——新增 / 补深的每个气质条目或成员，必须在其 examples / 基线区附**一条可回归的最小验收基线**（一段脱敏 few-shot + 该题材的关键气质锚命中清单），使覆盖**可被 D9（评测 / 回归门方向）逐条重跑**，杜绝"死条目"。
- G4：把断连源**独门能力**（视觉基因解构 / 变身序列 / 纪录片伦理 / 互动分支）真正落到承载文件，使"撞上该需求套件不哑火"。
- G5：**先核验、后补位**——M0 先跑 ledger 核对，确认哪些真缺、缺多少，再决定补条目还是补成员，避免一次铺满造死覆盖。

**非目标（边界铁律）。**

- N1：**不一次铺满。** 不把所有缺类一次性全立成员。本版只交付：ledger（全量核对）+ 拟人风格化气质条目 + POV 互动轻量成员 + 视觉基因解构节 + 纪录片/转播/previz 三个半覆盖条目的补深及其 D9 基线。萌宠等内容题材、Sora 式新模型不在本版。
- N2：**不破引擎隐身（铁律）。** 所有新增气质条目、变身序列、互动分支状态、视觉基因解构的**中间分析产物（"我从这张图反推出 X 色相""当前在分支节点 B2""这是变身第 3 帧过渡态"）全属过程产物，绝不漏进成片镜头卡 / Seedance 提示词**。POV 互动的分支结构在落卡时**摊平为各分支独立的线性镜头卡**，成片里不出现"选择 A→跳 G5"这类状态机标注。继承 `tacit-core.md` L67 引擎隐身检、`storyboard/output-contract.md` §7。
- N3：**不破可移植性。** 新增气质条目仍是 `style-refs.md` 内的**纯文字语汇**（与现有 14 行同构），POV 成员两态（Skill + mega-prompt）可用；不绑任何平台 API。视觉基因解构依赖宿主读图能力时，**通过宿主能力门控降级**（无读图能力→退化为"用户口述参考图气质"），不写死平台。
- N4：**不破题材原创检。** 补条目只补"气质锚词 / 镜头语言 / 视觉锚点"（招式），**不得**把断连源里的具体题材 / 品牌 / 台词 / 角色搬进 `style-refs.md`（守 `tacit-core.md` L66 题材原创检）。视觉基因解构 / 拉片同律：只复刻气质手感，不搬题材。
- N5：**不重写已真覆盖项。** 东亚文艺 / 羊毛毡 / 微缩世界已被现有行承载者，**只在 ledger 标"确认覆盖"**，不重复造行（避免口径分裂）。
- N6：**不做互动叙事的运行时引擎。** POV 互动成员只产"分支骨架 + 各分支线性镜头卡"的**设计产物**，不实现真实的播放器 / 选择交互运行时（那是宿主 App 的事）。
- N7：**不做评测打分系统本身。** D10 只为每个补位项**产出 D9 可消费的基线**（few-shot + 气质锚命中清单），评测引擎 / 回归门是 D9（评测审计方向）的事，D10 是其数据供给方。

## 4. 需求 Requirements

### 4.1 功能需求 FR

**D10-FR-01 · 断连源逐源核对账（coverage-ledger，先核验）。**
新建 `docs/optimization/coverage-ledger.md`：对 4 个断连源（HappyHorse 东亚文艺 / 人文纪录 / 一图成片 / 主题变身特效）+ 方向简报点名的缺类（POV 互动 / 一镜到底 / 动作 previz / 拟人风格化 / 转播伪纪实），逐项填一行 `{源/缺类, 独门能力一句话, 套件落点(精确到文件§行 或 "无"), 覆盖度∈{真覆盖/半覆盖/零覆盖}, 处置∈{确认/补条目/补成员}, 对应 D9 基线 id}`。
- **验收标准**：(a) ledger 覆盖**全部** 4 断连源 + 5 缺类共 9 行（缺行 = 0）；(b) 每行"覆盖度"判定都附**精确落点**（真/半覆盖必给 `style-refs.md §六 L1xx` 或具体文件§，零覆盖写"无"并说明为何无）；(c) README L88"4 个因网络中断未纳入，同类已覆盖"改为"逐源核对见 `coverage-ledger.md`"，**口头承诺被账本取代**（grep README，"同类已覆盖"措辞 = 0 或仅作指针）。

**D10-FR-02 · 半覆盖条目补深 + 专属产物变体（不立成员）。**
对 ledger 判定为"半覆盖"的题材——**人文纪录**（补纪录片伦理 + 采访机位 + 真实事件反向锚定）、**动作 previz**（补 stick-figure 简化卡变体：只留景别 + 英文技术标注 PUSH IN/WIDE/POV + 轨迹虚线，省略光色 / 微表情）、**转播伪纪实**（补比分条 / 隔行扫描 / 转播长焦 cutaway 偷拍机位）——在 `style-refs.md` §六对应行**补深为完整气质条目**（风格锚 / 主导景别运镜 / 视觉锚点 / 光色 / **该题材专属反向锚定**），并在 `style-refs.md` 新增小节或 storyboard 给"previz 简化卡变体"写法。
- **验收标准**：(a) 3 个半覆盖题材的 §六行从"单行速查"升级为含**专属反向锚定**的完整条目（人文纪录含"不摆拍可识别真人 / 不伪造真实事件 / 采访同意"；转播含"禁真实联赛 LOGO / 真实球员名"；previz 含"只技术标注不写情绪文学"）；(b) previz 变体能产出一张**只含景别 + 技术标注 + 轨迹**的简化卡（无光色 / 微表情字段），且**仍通过引擎隐身检**；(c) 每个补深题材配 ≥1 条 D9 基线（FR-05）。

**D10-FR-03 · 零覆盖之「拟人风格化 / 主题变身」气质条目 + 变身序列写法。**
在 `style-refs.md` §六新增一行「拟人风格化 / 主题变身」并补**变身序列写法**：定义"**主体置换型变身**"（把 A 主体拟人 / 风格化成 B，区别于已有羊毛毡 / 微缩的**质感变身**），给出变身序列的**关键帧锚**（原态 → 中间过渡态 ×N → 目标态）+ 一致性约束（变身全程锁住某一不变量：轮廓 / 标志色 / 关键道具，复用 `continuity-quality.md` 物件叙事锚）。变身序列的"第几帧过渡态"是**过程产物**，落卡时摊为各帧独立镜头卡。
- **验收标准**：(a) §六新增「拟人风格化 / 主题变身」行（风格锚 / 景别运镜 / 视觉锚点 / 光色齐全）；(b) 给出 ≥1 个变身序列范式（原态→≥2 中间态→目标态），每态有"锁住的不变量"声明；(c) 变身序列产出的镜头卡里**无"过渡态 frame_3 / 变身进度 60%"等过程标注**（引擎隐身检通过）；(d) 配 ≥1 条 D9 基线。

**D10-FR-04 · 零覆盖之 POV 互动轻量成员（分支骨架 + 摊平落卡）。**
立轻量成员 `pov-interactive/`（或在 storyboard 加"分支扩展"，二选一在 M0 据 ledger 定）：定义**分支骨架 schema**（节点 = 镜头组 / 选择点，边 = 选择 → 目标节点，含回边 / 汇合点），第一人称 POV 视角锁定（复用 §六 L128 一镜到底 POV 锚），并提供**摊平算法**——把分支图**摊为每条路径一份独立的标准 v2.0 线性镜头卡**，使下游 Seedance 链零改即可消费。**互动状态 / 分支跳转绝不进成片**。
- **验收标准**：(a) 分支骨架 schema 通过校验（节点 / 边 / 选择点 / 汇合点字段齐全，见 §5③）；(b) 取一个 ≥2 选择点、≥3 终局的最小互动剧本，摊平后产出**每条路径一份**合法 v2.0 镜头卡（路径数 = 实际可达终局数，无悬空分支）；(c) 摊平后的成片镜头卡 + Seedance 提示词 grep `选择|分支|branch|node_id|跳转|goto|状态` 命中 = 0（互动结构零泄漏）；(d) 配 ≥1 条 D9 基线（最小互动剧本作黄金基线）。

**D10-FR-05 · 每补一类配 D9 基线一条（覆盖即可回归）。**
对 FR-02/03/04 每个补深 / 新增的题材或成员，在其 examples / 基线区产出**一条 D9 可消费的最小验收基线**：`{基线 id, 题材, 一段脱敏 few-shot 输入, 该题材关键气质锚命中清单(必含锚词 ≥3), 引擎隐身禁词清单, 期望产物形态}`。基线与 D5（一致性审计）/ D9（评测回归）接口对齐——D9 重跑该基线时逐条断言"气质锚命中 + 隐身禁词 = 0"。
- **验收标准**：(a) 每个补位项至少 1 条 D9 基线，全部补位项基线齐全（缺基线的补位项 = 0）；(b) 每条基线的"关键气质锚命中清单"≥3 个可 grep 的锚词（如转播伪纪实：`broadcast look` / `score bug` / `interlacing`）；(c) 基线"引擎隐身禁词清单"对该题材的过程产物（变身进度 / 分支状态 / 视觉基因解构标注）逐一列禁；(d) ledger 每行"对应 D9 基线 id"列全部填实（指向真实存在的基线，悬空 = 0）。

**D10-FR-06 · 视觉基因解构节（单图反推气质锚，宿主能力门控）。**
在 `style-refs.md` 新增小节「视觉基因解构（从单图反推气质锚）」：定义从**一张用户给的参考图**反推可复用气质要素（主导色相 / 光质 / 构图秩序 / 材质 / 名家锚）的协议，先跑**宿主读图能力探针**（能读图→自动反推；不能→退化为"用户口述参考图气质 + 套件归类到 §六最近气质行"）。反推产物是**气质锚词**（喂进 Step 3 风格锁定），**不是题材**（守 N4），且反推过程标注绝不进成片。
- **验收标准**：(a) 该节给出反推的 5 类要素（色相 / 光质 / 构图 / 材质 / 名家锚）+ 探针降级两档；(b) 反推产物落到 `style-refs.md` 已有气质锚词体系（能映射到 §五名家库 / §六气质行），**零新题材搬运**（正则扫描参考图专有名词命中 = 0）；(c) 与 D2 拉片正交声明清晰（D2 拆视频时序骨架，本节拆单图气质），无职责重叠。

**核心算法（POV 互动摊平 · 强调"分支图 → 多条线性卡 + 剥状态"）：**

```
def flatten_pov(branch_skeleton, script):
    probe_pov_lock(branch_skeleton)                     # 锁第一人称POV(复用§六L128)
    paths = enumerate_paths(branch_skeleton)            # 枚举所有 起点→终局 可达路径
    assert no_dangling(branch_skeleton)                 # FR-04: 无悬空分支/不可达节点
    boards = []
    for p in paths:                                     # 每条路径 → 一份独立线性卡
        groups = [node.group for node in p]
        board  = render_linear_v2(groups, script)       # 走标准 v2.0 三层(场景→组→镜)
        board  = re_run_emotion_mapping(board)           # 情绪先行：每路径独立校 mapping 强制项
        strip_interactive_meta(board)                    # NFR-01: 删 node_id/choices/edges/状态
        assert passes(board, "storyboard/output-contract.md §7")  # 复用既有9条自检
        boards.append(board)
    assert len(boards) == reachable_endings(branch_skeleton)      # FR-04②: 路径数=可达终局数
    return boards                                        # 输出 = 每路径一份标准线性卡 + 每组一段Seedance
```

- **气质条目结构核验（脚本）**：写一支核验脚本（python，本机用 `python` 非 `python3`）扫 `style-refs.md` §六：断言新增 / 补深行四列齐全（风格锚 / 景别运镜 / 视觉锚点 / 光色）、列结构与现有 14 行同构、真覆盖三行字节级未改（与冻结基线 diff）。→ 证 FR-02/03、NFR-03、DoD-2/3/8。
- **POV 摊平回归（脚本 + diff）**：固定一个最小互动剧本（≥2 选择点 ≥3 终局）作黄金基线 `fewshot-POV互动-demo.md`，跑摊平算法，断言：路径数 = 可达终局数、无悬空分支、每路径卡过 storyboard §7 九条自检。改 pov-interactive 后重跑，路径枚举 / 摊平结构不得无故漂移。→ 证 FR-04、DoD-4。
- **引擎隐身 grep（一票否决门）**：对所有补位项产出的成片提示词跑 NFR-01 禁词表（变身进度 / 分支 node_id / 视觉基因 / 反推 / 伦理核验 + 引擎术语），命中必须 = 0。→ 证 NFR-01、DoD-7。
- **D9 基线可消费核验（接口 diff）**：把每条 D10 基线交给 D5/D9 接口格式校验，断言每条含 `气质锚命中清单(≥3) + 隐身禁词清单 + 期望产物形态`，且 D9 重跑能逐条断言。→ 证 FR-05、DoD-5。
- **真机出片抽检（与用户协作，付费按钮由用户点）**：从补位项各抽 1 题材（建议：拟人变身 1 例 + POV 互动 1 条路径），按补深条目 / 摊平卡出 1 组 Seedance，**人眼比对"气质对不对"（变身是否锁住不变量 / POV 是否第一人称沉浸）+ grep 成片无过程产物**。这是"覆盖真有用"的终极证据——条目若空泛，出片气质必跑偏。→ 证 FR-02/03/04、DoD-7。
- **断连源原创扫描（脚本）**：对补位产物正则扫断连源 / 参考图专有名词（具体题材 / 品牌 / 球员名 / 名人脸），命中 = 0。→ 证 NFR-05、DoD-11。

**测试用例 / 基线。**

- BL-D10-POV-01：最小互动剧本（第一人称，2 选择点、3 可达终局）→ 摊平期望 = 3 份独立线性卡，成片零分支泄漏。
- BL-D10-TRANS-01（拟人变身）：一个"抽象主体拟人成角色"序列（原态→2 过渡→目标），锁不变量 = 标志色 → 期望变身卡锁色一致、无 frame/进度标注。
- BL-D10-DOC-01（人文纪录）：一段含可识别真人 / 真实事件的素材 → 期望条目反向锚定剥离真人身份 / 不伪造事件。
- BL-D10-BCAST-01（转播伪纪实）：含真实联赛 LOGO + 球员名 → 期望转播条目剥离 LOGO / 球员名，保留比分条 / 隔行扫描气质。
- BL-D10-VGD-01（视觉基因解构）：一张参考图（含可识别品牌）→ 期望反推产物只含色相 / 光质 / 构图 / 名家锚，品牌专有名词 = 0。

**为何这样能证明"真的有效"。**

- "覆盖账本完整 / 条目结构同构 / 摊平路径数 = 终局数 / 隐身禁词 = 0"全是**结构性质**，脚本 + grep + diff 给确定性证明，不靠"覆盖更全"这类空话——每条都是存在性 / 命中数 / 路径计数的硬断言。
- "条目真有用"靠**真机出片 + 气质人评 + 成片隐身 grep**：条目若空泛（如变身锚词不锁不变量），出片必"变身失真 / POV 跳出第一人称"，人眼一眼可辨；而过程产物是否漏进成片由 grep 客观判。
- "覆盖账本不撒谎"靠**逐源精确落点 + d9_baseline_id 非空**：ledger 每行都要指向真实文件§行或真实基线，把 README"同类已覆盖"从一句口号变成可逐行核验、可被 D9 重跑的账。

**落地可靠性理由（4/5）。**

- 正向：①本方向主体是**文档 / 知识库工程**——补气质条目与 §六现有 14 行同构、照抄结构即可；ledger 是纯核对账；视觉基因解构 / 变身序列有源 skill 明确证据（一图成片 / 主题变身特效），非空想。②验收大半是脚本 / grep / diff，确定性高；真覆盖项只确认不改，回归面小。③POV 互动虽是架构级新增，但**摊平后完全复用 v2.0 契约 + tacit-core 引擎**，下游零改，风险被"摊平"策略收敛。
- 扣 1 分：(a) POV 互动分支骨架是套件首个非线性结构，"摊平算法"在复杂回边 / 汇合点下的边界（不可达节点 / 循环分支）需仔细处理，存在写不严的风险（最小剧本基线缓释）；(b) 视觉基因解构依赖宿主读图能力，真实强度未知，多落降级档则精度打折（探针门控缓释）；(c) 断连源"独门能力"的精确手感需按真实源 skill 校准，存在"补得不够准"的风险（每补一类配 D9 基线 + 真机抽检兜底）。

## 1. 问题陈述 Problem

**现状（引 director-suite 具体文件）：**

整个套件的入口是**单模态的——只吃文字**：

- `storyboard/SKILL.md:13` 白纸黑字："把用户的【剧本/片段/桥段】转成可直接喂给视频生成模型的分镜镜头卡提示词"。6 步管线（`SKILL.md:25–31`）的 **Step 0 寓居读本**输入就是**文字片段**（`tacit-core.md:24` "通读片段……以人物身体感受场景"）——没有任何"读一张参考图、把它的美学解构出来"的入口。
- `production-bible/SKILL.md` 同样从**剧本**起步产四张互锁表。`tacit-core.md:33–41` 的情感优先六维管线，第 0 步寓居、第 1 步定主情绪，全部以"文字剧本"为读本对象。
- `_shared/` 八件共享知识里，**唯一**沾"图"的是 `continuity-quality.md`：它只把图当作**连续性参考素材 / 喂脸素材**用（`:24` 三视图、`:25` "多状态参考用 ImageToImage"、`:26` 双图喂脸 `<<<image_1>>>`/`<<<image_2>>>`），即"用已生成的图去锁后续身份"，而**不是**"分析一张外部美学图、把它的视觉语言解构成可指导分镜的结构化要素"。
- `style-refs.md` 的 283 名家参考是**静态文字语汇库**（`:9` "借谁的眼睛说"）+ 空间四层法（`:137–145`）——靠的是导演记忆里的招式，**不是从用户当下给的某张具体美学图里测量出来的视觉手感**；其中 `:132` 「群像主视觉」一行已写"空间四层(前/中/中后/深)+色卡锁定+golden hour 斜射金光+冷蓝阴影补色"，证明**这些视觉要素是套件已认知、可结构化的对象**——但没有任何成员把它从"读图"方向反向产出。

**痛点（为何是问题）：**

1. **最高频的真实创作诉求缺口**：用户常常**先有一张"想要做成这种感觉"的美学图**（一张电影截图、一张概念图、一张氛围参考、甲方给的 mood board），而非一段写好的剧本。当前套件无法接住——只能逼用户把"看到的画面感受"**口述成文字剧本**，而**色彩配比 / 光线环境 / 质感模拟 / 主体结构关系**这些恰恰是**最难用语言转述、最易在转述中丢失**的视觉信息。这正是缺口类 **B（单向单模单模型）** 的典型症状：入口"单模"（只吃文字）、流程"单向"（只前向），对"图"这种模态只当连续性素材、不当**可解构的设计源**。
2. **情绪曲线缺一个视觉锚**：`tacit-core.md` 第 1 步要"定主情绪"，但纯文字剧本里的情绪是抽象的；一张美学图携带的**色温/光比/明暗分布**本身就是情绪的物理载体（`tacit-core.md:39` "色彩=情绪的温度"、`:40` "光影=情绪的明暗"）。把图的视觉基因接进来，能让"起→蓄→转→爆→落"情绪曲线（`storyboard/SKILL.md:27`）多一个**可测量的视觉起点**，而非纯凭文字想象。
3. **生态已证明此能力是标配、唯独本套件缺**：方向简报点名"一图成片 `multimodal_analyze_tool` 段有视觉基因解构"。源生态把"从一份已有视觉成品反推可复用设计要素"做成了**可执行中间产物**；本套件却把它停留在"读图只为锁脸"，没有"读图为解构美学、驱动分镜"这一环。
4. **解构产物若直接当生成指令会污染成片**：天真做法是把解构出的"Texture/Lighting 英文标签"直接拼进 Seedance 提示词——这会**绕过情绪优先**（违反 `storyboard/SKILL.md:17` 铁律一）、且**把解构过程产物漏进成片**（违反 `tacit-core.md:67` 引擎隐身 + `output-contract.md:172` §7.8）。所以"图→分镜"不是直连，必须经过**情绪优先六维管线**这道闸——这正是本方向设计的核心约束。

## 3. 目标与非目标 Goals / Non-Goals

**Goals：**

- G1：新增成员 `image-genome/`，提供"**上传 1 张美学图 → 视觉基因解构（四维）→ 解构产物喂情绪优先六维管线 → 驱动分镜**"的可执行流程。**入口从"只吃文字"扩成"文字 ∪ 图 ∪ 文字+图"**。
- G2：定义固定的**四维视觉基因 schema**——`Subject_Structure`（主体结构/空间四层关系）、`Color_Palette_Ratio`（色板 6:3:1 主辅点缀配比 + 色温/光比）、`Lighting_Environment`（光线环境/光位/明暗分布）、`Texture_Simulation`（质感模拟/胶片颗粒/材质语汇）。每维带**可量化字段**，与套件已有 `dimensions.md`/`pro-params.md`/`style-refs.md` 词汇对齐、可逆。
- G3：**解构产物只作"指导分镜"、绝不当生成指令**——四维基因经 `tacit-core.md` 情绪优先六维管线"翻译"成情绪锚与视听决策，由分镜契约消化；不得把 `Texture_Simulation` 的英文标签直接拼进 Seedance 提示词（守 `storyboard/SKILL.md:17` 情绪先行 + `:19` 引擎隐身）。
- G4：**解构驱动情绪曲线**——把图的色温/光比/明暗分布映射到"情绪强度 0–5"的一个**视觉起点估值**，喂给 Step 2 情绪曲线（`storyboard/SKILL.md:27` 起→蓄→转→爆→落）作初锚，再由文字剧情校正；让情绪曲线有"可测量的视觉锚"而非纯文字想象。
- G5：**先 de-risk 宿主多模态读图能力**：跑全流程前用能力探针确认宿主能否读图像像素/色值/构图；不能则优雅降级到"用户口述图 + 缩略色值"模式，绝不静默假装解构了图。

**Non-Goals（边界铁律）：**

- N1：**不破引擎隐身**。视觉基因解构是**分析过程产物**（类同自检/审计）：四维标签、HSL 色值、"这是伦勃朗光"等分析标注，**绝不漏进成片镜头卡 / Seedance 提示词**。引擎隐身铁律（`tacit-core.md:67`、`output-contract.md:172` §7.8）在此扩展为"**解构层不漏进成片层**"。解构结论只在内部转成情绪锚与视听参数后落卡。
- N2：**解构 ≠ 生成指令**（本方向第一红线）。绝不把解构标签直连成片提示词当 image-prompt 用，必须经情绪优先六维管线。
- N3：**不破可移植性**。`image-genome/` 作为 Agent Skill / mega-prompt 两态都要能跑（README.md `两种用法`）；多模态读图能力**通过宿主能力门控**，不写死任何特定平台 API（不绑 Flova / 不绑某云）。宿主无读图能力时降级模式仍能产出有用基因卡。
- N4：**不搬运题材 / 不抄美学图内容**。解构只提取**美学手感/视觉语法**，不得把参考图的具体主体/IP/品牌/题材搬进输出（守 `tacit-core.md:66` 题材原创检 + `continuity-quality.md:170–178` 合规版权类）。
- N5：**不新增视频模型适配层、不改下游契约**。下游仍走现有 `storyboard/output-contract.md` v2.0 + `seedance-2.0.md`；D8 只产"解构基因 + 情绪初锚"，零改下游契约。
- N6：**不做图像版权法律判定**（仅做工程级"无品牌/Logo/可读真实文字/IP 形象搬运"的反向锚定）。

## 4. 需求 Requirements

### 4.1 功能需求 FR

**D8-FR-01 · 宿主多模态读图能力探针与降级（先 de-risk）**
- 描述：`image-genome/SKILL.md` 第一步必须先跑"读图能力探针"，判定宿主能否（a）读取图像像素并取主色 HEX/HSL、（b）感知构图区域/前后景层次、（c）判读光位与明暗分布。据结果选三档模式之一：**A 全自动解构**（宿主可读图像）/ **B 半自动**（宿主可读用户提供的"主色块缩略 + 用户口述构图"）/ **C 口述兜底**（用户文字描述图，退化为带"视觉锚优先"写法的前向 storyboard）。
- 可量化验收：给同一张基线美学图，三档模式都能产出**结构合法**（通过 D8-FR-02 schema 校验）的四维基因卡；探针在 A 不可用时**显式落到 B/C 且告知用户当前档位**，绝不静默假装解构了图（对齐 `continuity-quality.md:188` "缺参考必须停下，不得虚构"）。

**D8-FR-02 · 四维视觉基因解构（Subject/Color/Lighting/Texture）**
- 描述：对输入图产出一张**四维视觉基因卡**，每维字段如下、且每维都给**可量化或可枚举值**（对齐套件词表）：
  - `Subject_Structure`：空间四层关系（前景/中景/中后景/深景，复用 `style-refs.md:141`）+ 主体位置/朝向/视线/遮挡 + 构图法（对称/三角/纵深，复用 `style-refs.md:144`）。
  - `Color_Palette_Ratio`：主色/辅色/点缀色 HEX + **6:3:1 配比**（主导色 ≈60% / 辅 ≈30% / 点缀 ≈10%）+ 色温 K + 光比 + 饱和倾向 + 暗部走向（对齐 `output-contract.md:78` 色彩影调锁定字段）。
  - `Lighting_Environment`：光位（顺/侧/逆/顶）+ 主光方向 + 光质（硬/柔）+ 明暗分布（明调/暗调/中间调）+ 大致色温（对齐 `pro-params.md` 色温光比、`output-contract.md:128` 光影分层）。
  - `Texture_Simulation`：质感语汇（胶片颗粒/数字干净/油画感/材质标签）+ 颗粒强度 + 镜头质感（对齐 `output-contract.md:126` 颗粒字段、`continuity-quality.md:246` `35mm film grain`）。
- 可量化验收：①四维全部存在（缺一即不合格，schema 校验）；②`Color_Palette_Ratio` 三色 HEX 齐全且配比之和 = 100%（容差 ±5%，对齐电商全案"白底 RGB≥245"式量化口径）；③每维字段值均能命中套件已有词表（空间四层/构图法/光位/颗粒），未命中数 = 0；④基因卡内**不含**任何成片字段（无台词/无切镜方式/无 Seedance 标记）——这些属成片层，泄漏即不合格。

**D8-FR-03 · 解构 → 情绪优先六维管线桥（解构当读本，不当指令）**
- 描述：四维基因卡**不直连成片**，而是作为"视觉读本"喂进 `tacit-core.md:24–41` 情绪优先六维管线：(a) 第 0 步寓居——把图当场景"住进去"读体感；(b) 第 1 步定主情绪——由 `Color_Palette_Ratio`（色温/光比）+ `Lighting_Environment`（明暗分布）反推一个**情绪锚候选**，再与用户文字剧情**校验合一**（图与文字冲突时以剧情/情绪为准，留痕）；(c) 六维设计时，四维基因作为**视听决策的视觉参照**（如图的母色 → 色彩影调锁定初值），但每个落卡参数仍须过 `mapping-tables.md` 强制项。
- 可量化验收：①基因卡的每一维都有**显式去向**——映射到六维管线的哪一维（产出一张"基因→六维"去向表，四维全部有去向，无悬空）；②由图反推的"情绪锚候选"落在 0–5 强度区间且写明依据（色温/光比/明暗）；③当图与文字剧情情绪冲突时，输出**以情绪/剧情为准**并留一行调整痕迹（守 `tacit-core.md` 情绪先行）。

**D8-FR-04 · 解构驱动情绪曲线（视觉起点 → 起蓄转爆落）**
- 描述：把 FR-03 得到的"图情绪锚候选"接入 Step 2 情绪曲线（`storyboard/SKILL.md:27` 起→蓄→转→爆→落）作**首镜情绪强度初锚**；若一张图明确属于某个曲线阶段（如高对比暗调 → 多落在"转/爆"），据此给曲线一个视觉起点，再由文字剧情节拍校正全曲线。
- 可量化验收：①输出含一条情绪曲线，其**首锚强度**可回溯到图的 `Color_Palette_Ratio`/`Lighting_Environment`（写明"图初锚=k 级，依据=色温X/光比Y/明暗Z"）；②曲线后续阶段由文字剧情驱动，**不被图锁死**（验证：换同一张图配两段不同情绪的剧情，曲线不同 → 证明图只给起点不锁全程）；③最终落卡的景别/运镜仍 100% 守 `output-contract.md` §2.1/§2.2 强制项（图不豁免强制映射）。

**D8-FR-05 · 解构层 → 成片层硬隔离（引擎隐身扩展闸）**
- 描述：在产成片镜头卡 / Seedance 提示词前，**剥离全部解构过程产物**——四维英文标签、HEX/HSL 色值、"伦勃朗光/三角构图"等分析标注、能力探针档位、`Subject_Structure` 等字段名，一律不得出现在成片层；解构结论只以**已翻译的创作语言 + 镜头参数**（色温K/光比/景别/运镜）呈现。
- 可量化验收：对最终镜头卡 + Seedance 提示词 grep `Subject_Structure|Color_Palette|Lighting_Environment|Texture_Simulation|HSL|#[0-9A-Fa-f]{6}|视觉基因|解构|伦勃朗光标注`，命中 **= 0**；grep 引擎术语（Polanyi/默会/支柱/方法论/寓居/格式塔），命中 **= 0**（复用 `output-contract.md` §7.6/§7.8 口径）。

### 4.2 非功能需求 NFR

- **D8-NFR-01 · 引擎隐身 + 解构层不漏进成片（铁律）**：解构卡里允许出现 HSL/四维标签/光型术语——这是本产物的**本体**；但成片层绝不可引用解构卡原文、绝不可把四维标签/色值/分析术语混入成片提示词。引擎术语（Polanyi/默会/支柱编号/方法论/寓居/格式塔）仍零出现。验收口径同 FR-05 + `output-contract.md` §7.8。
- **D8-NFR-02 · 可移植性**：`image-genome/` 必须同时以（a）Agent Skill、（b）`_megaprompts/image-genome.megaprompt.md` 单文件两态可用（对齐 README.md `两种用法`）；多模态读图依赖通过 FR-01 探针门控，不写死平台；成员目录内无 `.py/.js/.exe` 运行时强依赖；提示词不出现 `127.0.0.1:8777` 等宿主 App 痕迹。
- **D8-NFR-03 · 性能 / 成本**：解构 1 张图，自动模式宿主调用次数有上限（建议 ≤2 次：一次读色值/构图、一次读光位/质感），避免反复回读爆 token；降级 B/C 模式零额外模型调用；真机出图（如要对解构做视觉验证）为**可选**末步、由用户亲点（计费门，遵 CLAUDE.md「付费按钮用户亲点」）。
- **D8-NFR-04 · 派生一致性（基因 == 图）**：四维基因字段必须可回溯到输入图，禁止"为基因好看"编造图里没有的要素。验收：抽样核对主色 HEX 与图实际取色误差（自动模式 HSL 色相 Δ ≤15°，复用电商全案阈值）。
- **D8-NFR-05 · 口径统一**：D8 文档统一采用"情感优先六维管线"口径（`tacit-core.md` 第二节），不混用"5维/8维/视觉四维"措辞造成与六维管线的混淆——**视觉基因四维 = 输入侧解构维度，情绪优先六维 = 内部推理维度，二者不同名不混用**，本 PRD 一并收敛遗留口径分歧。

def image_first_storyboard(ref_image, script_text):

    curve    = emotion_curve(anchor, script_text)      # FR-04 图给起点，文字驱动全曲线

    board    = storyboard_six_dims(curve, genome_as_reference=genome)  # 六维设计，基因仅作参照
    enforce_mapping_tables(board)                       # 图不豁免强制映射(景别-情绪/运镜)

    strip_genome_fields(board)                          # 删四维标签/HEX/HSL/分析术语/探针档位
    assert grep_no_genome_leak(board)                   # FR-05 grep 命中=0
    assert passes(board, "storyboard/output-contract.md §7")  # 零改下游契约即过自检
    return board                                        # 输出 = 标准 v2.0 镜头卡 + 每组一段 Seedance

## 6. 验收标准 Acceptance Criteria (DoD)

1. **成员可触发可跑**：`image-genome/SKILL.md` frontmatter 被索引；对"我有一张图，想做成这种感觉的分镜"的请求能触发并跑完 6 步，产物为标准 v2.0 镜头卡 + 每组一段 Seedance（非空、非占位）。
2. **三档探针真降级**（FR-01）：宿主读图不可用时，**显式输出当前为 B/C 档**并继续产基因卡；构造一次"伪装宿主无读图能力"用例，验证它**不静默假解构**（无凭空捏造的 HEX/光位）。
3. **四维结构合法**（FR-02）：随机抽 1 张基线图，产四维基因卡——四维齐全；`Color_Palette_Ratio` 三色 HEX 齐全且配比和 = 100%（±5%）；每维字段命中套件词表，未命中 = 0；卡内**无**台词/切镜方式/Seedance 标记 成片字段。
4. **派生一致性**（NFR-04）：自动模式取的主色 HEX 与图实际取色 HSL 色相 Δ ≤15°（电商全案阈值）。
5. **解构当读本、有去向**（FR-03）：四维**全部映射**到情绪优先六维的某一维（去向表无悬空）；图反推的情绪锚候选 ∈ [0,5] 且写明依据；构造"图×文字情绪冲突"用例，验证输出**以情绪/剧情为准**并留痕。
6. **驱动情绪曲线、不锁全程**（FR-04）：输出含情绪曲线，首锚可回溯到图的色温/光比/明暗；**换同一张图配两段不同情绪剧情，曲线不同**（图只给起点不锁全程）；落卡景别/运镜 100% 守 §2.1/§2.2 强制项。
7. **引擎隐身 + 解构层零泄漏（铁律）**（FR-05/NFR-01）：最终镜头卡 + Seedance 提示词 grep `Subject_Structure|Color_Palette|Lighting_Environment|Texture_Simulation|HSL|#[0-9A-Fa-f]{6}|视觉基因|解构`，命中 **= 0**；grep 引擎术语（Polanyi/默会/支柱/方法论/寓居/格式塔），命中 **= 0**。
8. **下游契约零改**（N5）：图像优先产物**不改一行** `storyboard/output-contract.md` 即通过其 §7 全部 9 条自检。
9. **无 IP / 题材搬运**（N4）：基因卡与成片均经反向锚定扫描，**不含**参考图的具体 IP / 品牌 / 可读文字 / 题材搬运；负例（含品牌 Logo 的图）验证被剥离。
10. **可移植双态**（NFR-02）：mega-prompt 单文件版整段复制到对话框，喂"一张图的文字描述（C 档）+ 一段剧情"，能产出合法基因卡与成片镜头卡（不依赖 Skill 安装）。

## 7. 验证方案 Verification Plan

**验证手段：**

1. **审计脚本（结构闸，自动可回归）**：`image-genome/verify_genome.py`（或等价 PowerShell/node 检查清单），做五件事：(a) schema 校验四维基因卡（DoD-3）；(b) `Color_Palette_Ratio` 配比和 = 100%（±5%）+ HSL 色相 Δ ≤15°（DoD-4，自动模式）；(c) "基因→六维"去向表无悬空（DoD-5）；(d) 成片卡 + Seedance 提示词跑 FR-05/NFR-01 禁词 grep（DoD-7）；(e) 反向锚定 IP/品牌扫描（DoD-9）。这是**冷启动可重跑的回归门**。
2. **回归 diff（基线）**：取 1 张**原创自拍/无版权**的美学基线图 I0（避免版权与题材搬运污染验证），人工标注其四维 ground truth（主辅点缀 HEX、空间四层、光位、质感）。把 I0 的解构基因冻结为黄金基线 `examples/fewshot-图像优先-demo.md`；后续改 `visual-genome.md` 后重解构 I0，diff 四维结构，**主色 HSL/空间四层/光位不得无故漂移**。
3. **"图只给起点不锁全程"专项用例（FR-04 核心证据）**：同一张 I0 分别配 (剧情甲=温情重逢 / 剧情乙=诀别对峙) 两段文字，跑出两条情绪曲线 + 两套镜头卡——断言**首镜视觉初锚相同、全曲线与落卡不同**，证明"图驱动起点、文字驱动全程"真成立（这是本方向价值的硬证据，非"提升质量"空话）。
4. **真机出片 A/B（对图核验，可选，付费由用户亲点）**：取 I0 + 一段剧情，跑 D8 全链出 1 组 Seedance 成片，人评 A/B：A=纯文字口述图走前向 storyboard、B=D8 图像优先解构链，量"成片画面的色温/光比/明暗气质是否更贴近原参考图 I0"的命中率（≥3 名评审），B 应显著高于 A。
5. **引擎隐身专项 grep（铁律闸）**：对成片层跑 FR-05 禁词表 + `output-contract.md` §7.6/§7.8 引擎术语表，命中必须为 0；**反例**：故意把"Texture_Simulation: 35mm grain"原标签拼进 Seedance 提示词 → 审计脚本必须报不合格（验证隔离闸是真闸）。

**测试用例 / 基线：**
- I0：1 张原创无版权美学图（含明确主辅点缀三色、可辨空间四层、明确光位、明显质感），人工标注四维作 ground truth。
- 用例 T1（FR-04）：I0 × 剧情甲/乙 → 首锚同、曲线异。
- 负例 NB0（FR-01）：伪装"宿主无读图能力" → 验证降级 B/C 且不静默假解构。
- 负例 NB1（N4/DoD-9）：含可见品牌 Logo + 一句可读真实文字的图 → 验证基因抽取**剥离**品牌/文字（合规反向锚定生效）。
- 反例 NB2（FR-05）：把四维标签直拼成片提示词 → 审计脚本必须 FAIL。

**为何这样能证明"真的有效"：**
- DoD-3/4 是**数值化对账**（配比和 100%±5%、HSL Δ≤15°），不是"提升质量"空话——直接量"基因忠实于图"。
- T1「同图换剧情曲线必变、首锚不变」是**可量化、可重跑**地证明"图只给起点、文字驱动全程"——把本方向最易被误解为"图直连生成"的价值点，落成硬断言。
- DoD-7 + NB2 用 **grep 硬扫 + 反例**证明"解构层没漏进成片层"，把最容易出错的引擎隐身铁律变成可执行闸，而非劝告。
- DoD-8「下游契约零改即过 §7」证明 D8 真正**复用**而非旁路现有质量门——它没偷偷绕开 storyboard 的 9 条自检。

**落地可靠性理由（自评 4/5）：**
- 上调因素：①解构产物**完全复用**成熟的 `tacit-core` 引擎与 v2.0 契约，新增面集中在"输入侧解构"，下游零改、回归面小；②源生态（一图成片视觉基因 + 电商量化审计 + Flova multimodal_analyze）已证流程可行，非空想；③成员纯 Markdown、零依赖、可移植；④四维解构字段全部能映射到套件已有词表（空间四层/色彩影调/光影分层/颗粒），无新造词风险。
- 扣 1 分因素：**宿主多模态读图能力的真实强度未知**——能否稳定取准主色 HEX/判光位/辨空间层次，决定 A 档是否名副其实；若宿主弱，多落 B/C 档、HSL Δ 阈值需放宽。这是 P2、可靠性 4/5（而非 5/5）的根因，也正是 G5「先 de-risk」存在的理由。

## 8. 依赖与顺序 Dependencies

**依赖的宿主能力：**
- **多模态读图能力（强依赖，须先 de-risk）**：读像素取色值 / 判构图层次 / 判光位明暗。D8-FR-01 探针就是为此依赖做的门控与降级，**先 de-risk 是 D8 的第 0 号前置**。
- 不依赖任何特定平台 API（NFR-02）；若宿主恰好暴露 Flova 式 `multimodal_analyze_tool`，A 档质量更高。
- 可选依赖宿主图像模型通道（真机对图核验用，与 keyframe 同档 GPT-Image-2 / Nano Banana Pro）；文本基因卡产出不依赖宿主出图。

**依赖的其它 DNN / 现状件：**
- 复用（不改）：`tacit-core.md`（情绪优先六维引擎）、`storyboard/output-contract.md` v2.0、`mapping-tables.md`、`dimensions.md`、`pro-params.md`、`style-refs.md`（空间四层/构图法）、`continuity-quality.md`、`seedance-2.0.md`。
- 与 **D2 reverse-board（拉片复刻）正交互补**：D2 = 时序视频反向解构，D8 = 单图静态视觉反向解构；二者共享"反向解构→换内容重组→喂 v2.0 契约"范式，可共用部分反向锚定逻辑（弱依赖、非阻塞）。
- 与 **D1 执行编排契约弱耦合**：若 D1 已落地执行 DAG，D8 的"读图解构"可注册为 DAG 的前置节点（对应 Flova `multimodal_analyze_tool` 位）；D1 未就绪时 D8 独立可跑（非阻塞）。

**顺序：**
1. 先 de-risk 宿主多模态读图（FR-01）→ 2. 落 `_shared/visual-genome.md`（探针三档 + 四维范式 + 反推表 + 去向表 + 合规锚定）→ 3. 落 `image-genome/` 成员与 6 步管线 + `output-contract.md` 基因卡 schema → 4. 基线 I0 + 黄金 few-shot + 审计脚本验证（含 T1 同图换剧情）→ 5. 出 mega-prompt 双态 → 6. （可选）真机对图 A/B。

## 9. 风险与缓解 Risks & Mitigations

| 风险 | 影响 | 缓解 |
|---|---|---|
| **宿主读图能力弱/不稳**（核心风险） | A 档名存实亡，取色/判光位失准 | FR-01 三档探针 + 显式告知档位；B/C 降级仍产可用基因卡；先 de-risk 再投入；NFR-04 HSL Δ 阈值随档位放宽 |
| **解构标签漏进成片**（引擎隐身破口） | 破铁律，成片出现 `Subject_Structure`/`#RRGGBB`/"伦勃朗光标注" | FR-05 硬隔离 + `strip_genome_fields` + DoD-7 grep + 反例 NB2；基因卡字段名与 HEX 全列入禁词表 |
| **解构标签被当生成指令直连成片**（第一红线） | 绕过情绪先行、画面僵硬照搬参考图 | N2/FR-03 强制经情绪优先六维管线；算法 `genome_as_reference`（仅参照非指令）；落卡仍过 mapping-tables 强制项 |
| **图把情绪曲线锁死**（图喧宾夺主） | 不同剧情被同一张图绑成同一曲线 | FR-04 验收②"换剧情曲线必变"+ T1 专项用例；反推表只给**首镜初锚**，全程由文字驱动 |
| **IP / 品牌 / 题材搬运**（版权 + 原创破口） | 侵权、与 tacit-core 题材原创检冲突 | N4 + 负例 NB1 + visual-genome 合规反向锚定（复用 continuity-quality:170–178）；基因只取手感不取内容 |
| **图×文字情绪冲突无裁决** | 产出情绪稀释/多锚废稿 | FR-03"以情绪/剧情为准 + 留痕"；守 tacit-core 单一主锚铁律 |
| **四维与情绪优先六维口径混淆** | 文档混乱、误把四维当六维 | NFR-05 明确"视觉四维=输入侧解构，情绪六维=内部推理"，不同名不混用，本 PRD 一并收敛 |
| **反复回读图爆 token/成本** | 解构昂贵 | NFR-03 自动模式 ≤2 次读图调用；真机对图核验为可选末步、用户亲点 |

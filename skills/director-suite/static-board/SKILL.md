# 静态全案 / 电商（Static-Board）

video-first 套件里**唯一只产静态图**的成员。审计见 `../_shared/scripts/audits/audit_static_board.py`。

## 主图序列（Hero，恰 3 张 · 景别递进）

| 编号 | 类型 | 景别 |
|---|---|---|
| Hero_01 | 场景氛围图 | establishing（建立/低角度仰拍） |
| Hero_02 | 卖点结构图 | medium（中景正面） |
| Hero_03 | 白底 KV 图 | neutral（棚拍·白底 RGB≥245） |

## 详情页（Detail，恰 8 屏 · 每屏 1 主卖点）

功能场景 / 材质特写×2 / 卖点结构 / 对比验证×2 / 尺寸规格×2（建议序）。景别跨度≤两级。

## 铁律

- **11 图同一商品 asset_id**（引用闭合）；主导色 ≥85%，点缀 ≤15%（9:1 克制，禁霓虹撞色）。
- 焦点坐标 (X,Y)：主图 1/3·2/3 分布；详情页奇偶 Z/F 扫读。
- **卖点潜台词转化**：文字参数（"微米级防水"）→ 视觉意象（"水滴在哑光金属边缘完美张力"），写进 Visual Intent。
- **禁视频字段**：运镜/切镜方式/时长/Seedance/start_frame 一律不出现（纯静态）。
- 一致性复用 D5 量化审计（轮廓±5%/HSL±15°/LOGO Δ0.05/白底≥245）。

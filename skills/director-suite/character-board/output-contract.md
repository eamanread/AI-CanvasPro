## 角色设定板输出字段契约 v1.0

> 本契约与 `../storyboard/output-contract.md` 同源同纪律：**参数优先于形容词**（可量化项一律数值+单位）、**一致性锁定为第一性**（本板的核心产出就是"锁死身份"）、**反向锚定必填**。本板专为"角色锚点（character anchor）"服务：输出的多视图与头像供后续分镜以 `<<<image_1>>>` 形式复用。所有未标"可选"的字段均为强约束，缺项视为不合格。

---

### 0. 总则与底层约束

- **身份锁定优先**：本板第一目的不是"好看"，而是"看清并钉死这个人长什么样"。任何为了画面好看而牺牲多视图一致性的选择都视为废稿。
- **A-pose 中性铁律**：所有全身视图默认 A-pose / 自然中性站姿，**零戏剧化动作、零情绪表演夸张**。情绪只沉淀为脸部"默认神态"与造型倾向，不靠甩动作外化。设定板是身份参考，不是姿态参考。
- **写实优先**：默认 8K 真人写实，禁 CG/塑料皮肤/卡通插画（除非"气质核心/风格"显式声明风格化）。
- **参数优先于形容词**：身高（cm）、头身比（X 头身）、焦段（mm）、光圈（fX.X）、色温（K）、瞳色/发色（具体色名或 HEX）等一律给值。
- **一人一板·单一主气质**：每板只一个角色、一个主气质；多角色拆多板（或显式 1×2 拼版，左右各一人一气质，互不串味）。

---

### 1. 版式布局（Layout）

**填写规范**：先声明整板布局，再排视图。默认"设定手册/开发文档"感——统一版式、干净高级、留白合理、细线标注专业，**不要做成海报，不要做成杂乱拼贴**。

| 子项 | 允许值 / 格式 | 说明 |
|---|---|---|
| 画幅 | `16:9 横版`（默认，多视图拼版）/ `1:1`（单头像）/ `3:4`（单全身）/ 用户指定 | 多视图设定板默认 16:9 横版 |
| 拼版方式 | `单角色多视图横排` / `1×2 双角色对照`（一人一气质） / `头像区 + 全身多视图区 上下分区` | 多角色必须分区隔离，气质不串 |
| 视图集合 | 默认 5 视图：`头像特写 + 正面 + 侧面90° + 背面 + 四分之三(3/4)`；可增 `表情特写排 / 服装局部 / 配饰道具细节` | 视图数由用户或锚定需求决定 |
| 视图排布 | 全身多视图**同一基线、同一比例尺、同一朝向逻辑**水平合排 | 比例尺不一致 = 一致性破坏 |
| 背景 | 纯色影棚背景（默认 `纯白 / 中性灰 #C8C8C8`），clean studio | 背景纯净，不抢主体、不投复杂阴影 |

**常见错误**：把设定板画成有剧情有场景的概念图；多视图比例不一（一个高一个矮）；多角色挤在一区互相串气质；背景花哨抢戏。

### 2. 角色档案（Profile）+ 3. 气质核心（Essence）

**角色档案**（强约束，逐项填）：`角色名/代号 + 性别 + 年龄段 + 身高(cm) + 头身比(X头身) + 体态一句话`。如 `林九｜男｜32｜183cm｜8头身｜久经训练的精瘦体态，惯性微含肩`。

**气质核心**（本板的"母色"锚，跨所有视图一致）：一句话主气质 + 母色翻译。如 `克制的危险——冷蓝硬光基底 + 一缕琥珀暖；材质偏硬挺、做旧；默认神态：眼神下压、下颌微收`。
- 只允许**一个**主气质；复杂用"主 + 一缕暗流"。
- 母色要落到可执行：冷暖（色温倾向）/ 材质硬软 / 明暗倾向 / 松紧。
- **禁止**：把气质写成内心独白或动机解释（"他其实很孤独"）；多气质并列。

---

### 4. 视图清单（Views）——每视图独立成段，缺一不可

> 固定顺序：①头像特写 → ②正面全身 → ③侧面90° → ④背面 → ⑤四分之三(3/4)。每个视图写清：取景线 + 朝向 + 该视图必须看清的锚定要点 + 该视图的相机焦段。

| 视图 | 取景 / 朝向 | 必须看清 | 建议焦段 |
|---|---|---|---|
| 头像特写 Bust/Headshot | 胸上至头顶，正对或微 3/4，A-pose | 脸型/五官/肤质毛孔/瞳色/发际线/妆容/默认神态 | 85–100mm（自然脸部透视，浅景深虚化纯背景） |
| 正面 Front | 全身正立，正对镜头 | 整体廓形/服装正面层次/Logo/扣合/鞋正面/比例 | 50mm（最小畸变，交代比例） |
| 侧面 Side 90° | 全身正侧，朝向画左或画右统一 | 体态曲线/含背挺胸/服装侧缝/鞋侧/发型侧轮廓 | 50mm |
| 背面 Back | 全身背对镜头 | 后脑发型/背部服装结构/背包/披风/鞋后跟 | 50mm |
| 四分之三 3/4 | 全身 45° 转身（front-3/4） | 立体感、肩与髋的转折、服装在转折处的落感 | 50mm |

**填写规范**：每视图一句"取景+朝向"+ 一句"本视图锁定要点"。**所有全身视图共享同一套锚定项**（见 §5），仅角度不同；模型必须理解"这是同一个人转了不同角度"，不是不同的人。

**常见错误**：各视图换了服装/换了发型；侧面与正面比例对不上；3/4 视图脸变成另一个人；用动作姿势替代中性站姿。

---

### 5. 锚定项逐项锁定（Locks）——一致性的物理钉子（强约束核心）

> 这是本板的灵魂。每一项都必须给出"跨所有视图/跨所有镜头都不变"的确定描述；模糊或"同上"不写具体值视为不合格。

| # | 锚定项 | 必含子项 / 格式 | 示例 |
|---|---|---|---|
| 1 | **面貌 Face** | 脸型 + 五官特征 + 肤色/肤质 + 瞳色 + **特征记号**（疤/痣/雀斑/纹身，标位置） | 方下颌国字脸；浓眉单眼皮；冷白皮、毛孔级真实；瞳色深棕；左眉骨一道 2cm 旧疤 |
| 2 | **发型 Hair** | 发色（色名/HEX）+ 长度 + 分缝/造型 + 发质 | 哑光黑 #1A1A1A；两侧推短上方中长油头背梳；硬挺微油光 |
| 3 | **妆容 Makeup** | 妆感强弱 + 关键部位 + 是否素颜 | 男性几近素颜；仅唇色偏干、眼下淡青；无修容 |
| 4 | **服装 Costume** | 廓形 + 层次(由内到外) + 颜色 + 材质 + 磨损/做旧 + Logo/图案位置 | 廓形挺括 H 型；内白棉 T + 外炭灰羊毛大衣（双排扣）；做旧袖口；左胸无 Logo |
| 5 | **鞋履 Footwear** | 款式 + 颜色 + 材质 + 磨损 | 黑色军靴；做旧牛皮、鞋头微磨白；6 孔系带 |
| 6 | **配饰道具 Accessory** | 每件：名称 + 位置 + 材质（含随身关键道具） | 钢制旧腕表（左腕）；银素戒（右无名指）；随身折刀（闭合，腰侧） |
| 7 | **体型比例 Build** | 身高 + 头身比 + 肩宽/腰臀倾向 + 体态默认 | 183cm / 8 头身 / 肩宽腰窄倒三角 / 惯性微含肩 |

**跨视图一致性规则（强制）**：
- 7 项锚定在 §4 五个视图中**逐一保持一致**，只允许角度差异，不允许内容差异。
- 关键道具若在某视图被身体遮挡，需在标注说明框注明"（背面被大衣遮挡）"，不得无故消失或变形。
- 风格化（如声明插画/二次元）时锚定项依然逐项锁定，仅渲染语言切换。

**常见错误**：服装层次只写"穿大衣"不写内层与颜色材质；漏特征记号导致换脸；配饰在背面视图凭空消失；体型写"匀称"等空话。

### 6. 设定板光照与背景（Lighting & Plate）

**核心规则**：设定板的光是**展示用均匀光**，目的是"看清"而非"营造戏剧"——与分镜的戏剧布光不同。但光的**冷暖**仍由"气质母色"统辖，做出基底色性。

固定模板（分层，主光必填）：
```
设定板光照：
  主光：色温 5500K / 亮度 75% / 作用：均匀塑形看清结构（柔光箱正前偏上45°）/ 区域：人物整体
  辅光：色温 5500K / 亮度 50% / 作用：填暗、控反差约 2:1（保留立体不死黑）/ 区域：阴影侧
  轮廓光：色温 6000K / 亮度 45% / 作用：勾边分离纯背景 / 区域：发缘肩缘
  气质偏色：整体轻微冷蓝倾向（呼应"克制的危险"母色），不破坏肤色还原
背景：纯白/中性灰 clean studio，无投影杂物，景深 f8 全清（头像视图可 f2 虚化背景）
```
**允许值**：设定板光比建议 2:1 ~ 3:1（保看清，不做强阴阳脸，除非气质强烈要求）；色温随气质冷暖微调；背景纯色。
**常见错误**：给设定板打 16:1 戏剧硬光导致结构看不清；背景做成场景；多视图光位不统一致使同一人在不同视图明暗矛盾。

### 7. 标注说明框（Annotations）

**填写规范**：专业设定手册感——小标题 + 细线引线 + 简短说明框（视图名 / 关键锚定要点 / 材质或道具备注）。文字应作为**画面内的标注排版**，而非旁白。
- 允许标注：视图名（FRONT / SIDE / BACK / 3-4 / BUST）、材质标签（如 "wool / brushed steel / distressed leather"）、关键尺寸或比例线、道具引线名。
- **禁止**：满屏装饰文字 / 水印 / 与角色无关的花字；把标注写成剧情台词。

---

### 8. 质量和禁止（正向 + 反向，皆必填）

**正向规格**：`8K，真人写实，皮肤毛孔级细节，自然影棚光，物理正确材质（布料垂坠/金属反光/皮革做旧），多视图严格同一人。`

**反向锚定（negative，逐类覆盖）**：
- 渲染失真：`禁 CG 感、禁 3D 渲染、禁塑料皮肤、禁过度磨皮`
- 风格越界：`禁卡通、禁插画、禁动漫、禁油画感`（除非气质核心声明风格化）
- 解剖/结构：`禁多指/畸形手、禁脸崩、禁不对称眼、禁错误头身比`
- **一致性（本板重中之重）**：`禁多视图换脸、禁跨视图换装、禁发型/发色漂移、禁配饰凭空增减、禁比例尺不一`
- 设定板专属：`禁戏剧化动作姿态、禁夸张情绪表情、禁复杂场景背景、禁背景投影抢戏、禁水印花字`
- 画质：`禁过曝死白、禁欠曝死黑、禁噪点过载、禁低分辨率`

**固定模板**：
```
质量和禁止：
  正向：8K，真人写实，毛孔级肤质，自然影棚光，物理正确材质，五视图严格同一人同比例同服装。
  反向（禁止）：CG感，3D渲染，塑料皮肤，过度磨皮，卡通/插画/动漫，多指畸形手，脸崩，错误头身比，
  多视图换脸，跨视图换装，发型发色漂移，配饰增减，比例尺不一，戏剧化动作，夸张表情，复杂场景背景，
  背景投影抢戏，水印花字，过曝死白，欠曝死黑，低分辨率。
```

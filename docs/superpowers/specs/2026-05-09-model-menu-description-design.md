# 模型菜单副标题中文说明设计

## 目标

把各类 AI 模型下拉菜单第二行从内部模型 ID 改成面向用户的一句简短中文说明。

## 范围

- 图片注册模型菜单
- 文本注册模型菜单
- 图片工具面板模型菜单
- 其他已经是中文能力描述的菜单保持不变

## 规则

1. 第一行继续显示模型名
2. 第二行不再显示 `modelId`、路由 ID、provider 内部标识
3. 已知模型显示固定短说明
4. 未知模型按节点类型显示通用说明
   - 图片：`通用图像生成`
   - 文本：`通用文本生成`
   - 视频：`通用视频生成`
   - 音频：`通用音频生成`

## 实现方式

- 新增共享的模型副标题解析模块
- 图片/文本注册模型菜单与图片工具菜单统一调用该模块
- 保持现有模型选择、保存、选中态逻辑不变

## 验证

- 先补测试，确认旧逻辑会暴露内部 ID
- 改完后验证：
  - `Nano-Banana-2`、`Gpt-Image-2` 等显示中文说明
  - 未知模型显示通用中文说明
  - 菜单第一行和选择逻辑不受影响

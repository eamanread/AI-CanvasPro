## 一、回忆录的目标（为什么做这部片子）

这部回忆录写给玲——她口中的"中国当代阿信"，也写给她的女儿孙瑜、外孙墩墩，更写给所有从"白手扎根"走过来的普通中国家庭。

我们不为她立丰碑，而是把她一生"什么都干过、什么苦都吃过"的**真实质感**留下来：父亲擦得锃亮的自行车瓦圈、一级级往上换的房子、压车那条一天一夜的夜路、出嫁那身红色大绒旗袍、她自比的阿信——用这些反复出现的**母题意象**作章节的眼睛，让**正直、要强、托举**三股精神血脉在影像里看得见。

影像化四原则：
1. **以物代情，不喊口号**——让一颗玉米籽、一碗病号面、皮筋勒得方方正正的票、5毛钱、最后剩的80块，自己开口说话。
2. **时间可被观众理解**——每个母题章内部按事实自然时序推进，用时代标记（粮票、砸锭、肯德基刚进中国、4050工程）锚定年代。
3. **保留矛盾与并存的记述**——婚房"区委楼"与实住"黑石坝"、"集资还债3600"与丈夫"没贷过款"并置，不强行抹平，这正是口述史的真。
4. **苦中见光**——邻里的一锅粥、哥姐的爱、刘玉申专程带来的一瓶醋，都是黑暗里的暖色。

看完，要让观众记住：这是一个把"正直"当传家品、把"托举"当宿命、把吃苦活成尊严的女人。

**旁白比例铁律**：全片旁白(VO)字数 ≤ 总字数 20%，对白与画面承担其余 80% 以上。多数场零旁白，让真实的人物语言当主角。

# 第一幕 · 锃亮的自行车（上）——父亲的瓦圈与玉米籽

### 场景 1.1 · 《天津到张家口的捣车工》
- 时间地点：1950年代末·张家口铁路调车场
- 时代标记：天津铁路学校、分配张家口、捣车、蒸汽机车
- 画面：黎明的调车场，蒸汽机车喷着白汽。全景——一个清瘦挺拔的年轻男人（爹）拿着信号灯，在钢轨间捣车、摘挂车钩，动作利落干净。近景他胸前别着"天津铁路学校"的旧校徽。镜头摇到场边土坡：年轻的妈抱着包袱站着，身后是陌生的小城轮廓，风把她大城市样式的衣角吹起。色调偏冷灰，是白手扎根的底色。
- 旁白VO：（无）
- 对白：
  妈：「天津那么大个家……怎么就到这小地方来了。」
  爹：「学校分的，铁路上要人。咱俩有手有脚，到哪儿不是过日子。」
  妈：「没爹没娘帮衬，几张嘴呢。」
  爹：「不怕。能受苦的人，饿不死。」
- 情绪落点：父母身上"对生活不屈、特别要强、特别能受苦"的那股劲，是玲一生性格的根。

### 场景 1.2 · 《满车厢粮食与一颗玉米籽》

- 画面：A·父亲工作的闷罐车厢，门一拉开——满满一车厢黄澄澄的玉米。爹站在粮食堆前，只把脚边漏出的玉米粒一颗颗捡起、轻轻放回车厢。特写他空空的、干净的手。B·切回小屋，几个孩子围着空锅；邻居家窗口飘来香气，大饭盒里焖的玉米豆，炉子上搁着糖精咕嘟。孩子们扒着窗台咽口水。
- 旁白VO：（无）

# 第七幕 · 中国当代阿信——下岗与各种小生意

### 场景 7.1 · 《先下岗后破产的时间线》
- 时间地点：1995–2003·厂门口告示 / 家中
- 时代标记：95年做副业、96年下岗节点、97、98破产、炸鸡串、03年解散、买断工龄661
- 画面：厂门口的告示栏，一张张文件换着贴。家中灯下，两口子对着一张写了又划的纸算账、商量去留。镜头用字幕卡分层标注年份，让"先下岗、后破产"的过程被观众看懂。
- 旁白VO：（仅一句，理清时间线）「下岗不是一天的事。它一段一段地来——先抽走人，再抽走厂。」
- 对白：
  建国：「95年我就开始做副业了，修机器、卖羊肉串。」
  玲：「96年厂里说要下岗——不回去上班，就给你边缘下岗，撵到待业、就业公司。我一寻思，下岗能行吗？又回去上了好几年。」

  玲：「等我炸鸡串那阵，就彻底回家了。到03年，企业一解散，买断工龄，一年工龄661，给了两万来块，把杨家坟那房全买下来。」
- 情绪落点：把"先下岗后破产"这条复杂时间线交代清楚，一个铁饭碗如何分两步被时代收走。

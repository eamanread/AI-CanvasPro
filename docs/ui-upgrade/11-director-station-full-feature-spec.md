## 0. 一句话洞察

竞品 ≈ **轻量虚拟制片台（Virtual Production Stage）**。关键发现：图1"全景球·球形半径 **60**"= 幻映原生全景球 60m 半径，"场景缩放 300%"= 幻映视口缩放——**竞品功能几乎 1:1 映射幻映已有状态模型**，绝大多数是"用更丰富的右栏检查器暴露已有能力"，唯一真正全新的子系统是**角色姿势骨骼绑定**。

| **天空颜色** | #060608 色块 | 全景球外/无全景的背景色 | ❌（现 environmentMode 日/夜） |
| **全景球·水平旋转** | 0° 滑杆 | dome.rotation.y（我 backdrop 已用 -90°） | ❌ 缺暴露 |
| **全景球·球形半径** | **60** 滑杆 | 原生全景球 60m 半径 ← 直接命中 | ❌ 缺暴露 |

## 6. 角色检查器 — 姿势 tab（图3/4）⭐⭐ 全新核心子系统

### 6.1 姿势预设（20 个一键姿势）

```
站立✓  T型   行走   跑步
坐姿   蹲下   单膝跪 双膝跪
叉腰   倚靠   鞠躬   思考
格斗   踢球   投掷   推进
招手   伸手   抱臂   看手机
```

### 6.2 姿势调节（骨骼细调滑杆，分部位+左右对称）

| 部位 | 自由度（滑杆） | 截图样例 |
|---|---|---|
| 身体(整体) | 前倾 / 转身 / 侧倾 | 0/0/0 |
| 躯干 | 前倾 / 扭转 / 侧倾 | 2/0/0 |
| 头部 | 点头 / 转头 / 歪头 | -10/0/0 |
| 手臂—肩（左/右） | 前举 / 外展 / 扭转 | -5/7/0 |
| 肘部（左/右） | 弯曲 | 15 |
| 腿部—髋（左/右） | 前抬 / 外展 / 扭转 | 0/0/0 |
| (膝/踝等继续) | … | … |

**幻映现状**：人偶静态站姿。**但** `applyPanoramaCharacterNaturalArmPose` 已对 `upperarm_l/r`、`lowerarm_l/r` 做骨骼旋转（已确认骨骼名）——姿势系统**技术可行**，需补全骨骼集（spine/neck/head/thigh/calf…）+ 20 预设的骨骼角度表 + 姿势状态持久化。

**专家洞察③**：姿势 = 把"摆人形"升级为"摆表演"。预设覆盖叙事常用动作；细调滑杆给精修。这是导演台真正出"分镜参考价值"的关键（角色有动作语言）。

## 7. 机位检查器 — 属性 tab（图5，"摄像机"[属性|摄像机截图]）⭐ 机位是一等公民

| 功能 | 截图值 | 幻映映射 | 现状 |
|---|---|---|---|
| **镜头预览缩略图** | "FOV 50°"+展开 | 从机位渲染缩略图 | ❌ |
| 名称 | 机位3 | camera.name | ✅(V0) |
| **切换机位** | 下拉 机位3 | activatePanoramaSceneCamera | ⚠️ 有 action |
| **位置 XYZ** | 9.66/1.37/2.76 | camera.position | ⚠️ 有数据缺编辑 |
| **注视目标** | 下拉"手动坐标" | 可选 手动/角色（目标跟踪） | ❌ |
| **注视坐标 XYZ** | 0/1.2/0 | 从 quaternion 反解 look-at | ❌ |
| **视野角度 FOV** | 50.0 滑杆 | camera.focalLength↔FOV 换算 | ⚠️ 有 focalLength |

**专家洞察④**：机位是**真·虚拟机位**（位置+注视目标+FOV+截图），不是简单书签。"注视目标"可选**角色**=机位锁定看着某角色（target tracking，运镜利器）。幻映机位数据（position+quaternion+focalLength）**完全够**，差注视目标抽象 + 面板 + FOV/focalLength 换算暴露。

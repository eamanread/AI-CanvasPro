# 功能说明：导演视角 vs 机位视角 + 摄像机检查器

> 幻映 3D 导演台 顶栏「导演视角 ｜ 机位视角」两态的产品定义、交互规范、与摄像机检查器功能。2026-06-13，依据竞品 liblib 实拍 + 用户口述定义。

## 1. 两个视角的本质区别（用户定义）
| | **导演视角** | **机位视角** |
|---|---|---|
| 定位 | 自由观察/搭建场景的"上帝视角" | 固定在**某个机位**的取景视角里干活 |
| 视角控制 | **可自由移动**（轨道旋转/平移/缩放） | **锁定**在选中机位的画面，**不可自由轨道**（拖拽不改变视角） |
| 选中机位时 | 仅在树/检查器里看机位参数，视角不跳 | **点击机位 → 视角自动切到该机位**所见 |
| 用途 | 摆人偶、布场景、调全景、整体导演 | 以"透过镜头"的方式精修这一机位的取景（位置/注视/FOV），所见即将截的图 |

### 关键交互规范
- **导演视角**：拖拽 = 轨道旋转场景；ViewCube/重置视角生效；选人偶/机位走选中逻辑，视角不被机位绑架。
- **机位视角**：
  1. 进入即把视角设为"当前激活机位"所见；
  2. **点击任一机位（左树）→ 视角自动切换到该机位**（= activatePanoramaSceneCamera + 视角套用），右侧自动显示该机位的摄像机检查器；
  3. **拖拽不应自由轨道**（视角锁定在机位）——竞品实测：机位视角下拖视口画面**无反应**；调整取景靠右侧数值（位置/注视/FOV）或移动机位本身；
  4. 改机位位置/注视/FOV → 视角**实时**跟着变（所见即所得）。

> ✅ 已实现（2026-06-13）：机位视角下**视角锁定** —— 透明锁定层 `.hy-dc-camlock`（chrome 子元素，inset:0，z60）仅在 `.is-cameraview` 时 `pointer-events:auto`，吞掉中央视口的拖拽 → 3D 画布收不到 → **不能自由轨道**（面板/树/检查器 z 更高，照常交互）。导演视角时该层 `pointer-events:none`，自由轨道照旧。配套：进机位视角隐藏 ViewCube；左树点机位 → `applyViewMode(camera)` 自动切到该机位视角（§1.2）；改机位 位置/注视/FOV → maybeApplyCameraView 实时套用。

## 2. 摄像机检查器功能说明（机位视角/选中机位时右侧面板）
两 tab：**属性 ｜ 摄像机截图**。

### 2.1 属性 tab
| 控件 | 功能 | 数据落点 |
|---|---|---|
| 相机预览缩略图 | 显示该机位所见小窗 + FOV° | （幻映降级为静态占位，待离屏渲染） |
| 名称 | 重命名机位 | renamePanoramaSceneCamera（原生 name） |
| 切换机位 | 下拉切换激活机位 | activatePanoramaSceneCamera + 套用视角 |
| 位置 X/Y/Z | 机位世界坐标（三轴横排） | directorExt.cameras[id].position |
| 注视目标 | 手动坐标 / 某角色 | directorExt.cameras[id].lookAtTarget |
| 注视坐标 X/Y/Z | 手动注视点（三轴横排，仅手动时可编辑） | directorExt.cameras[id].lookAtPoint |
| 视野角度 FOV | 焦距/视场（滑块） | directorExt.cameras[id].focalLength（FOV↔焦距换算 clamp [16,135]mm） |

### 2.2 摄像机截图 tab
- 截图画廊：该机位历次截图缩略图（空 = "暂无摄像机截图"）。
- 截图：抓当前机位画面入画廊（directorExt.cameras[id].captures，FIFO 上限 24）。
- 全部清空 / 发送到画布（dataURL→建 source-image 节点）。

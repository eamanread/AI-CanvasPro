## 三、总还原度结论

- **可达核心（卡面/标题/桩/工具条皮肤/输入卡换皮）：综合约 85%**——这些覆盖了截图里 90% 的视觉面积。
- **整体还原度：约 75%**。三类硬缺口拉低分数且无法用 CSS 补齐：①空态"尝试"建议列表（新功能）②风格/标记/聚焦等 liblib 专属功能件（不伪造）③连线流光（JS 渐变）。
- **交互还原度：约 85%**——选中显形、hover 渐进披露、停靠输入、提交流幻映已同构，本轮主要是视觉对齐。

## 1. 产品概览与技术架构

- 定位：「LibTV - 专业视频创作工具」，节点画布式 AI 视频创作（文/图/视频/音频/分镜全链路）
- 技术栈：React + React Flow（xyflow）+ Tailwind v4 + Mantine（部分模态用 ant-design）
- 节点为 DOM 元素（非 canvas 绘制），连线为 SVG path
- 性能工程：React Flow `onlyRenderVisibleElements`（47 节点项目视口内仅渲染 6–48 个）；连线同样视口虚拟化；视口外节点以 `node-skeleton` 灰色骨架占位
- 路由：`/canvas?spaceId=&projectId=`；tab 标题 `{画布名} - {项目名} - LibTV - 专业视频创作工具`（顺序为推断，两级均为"未命名"无法区分）
- 单活跃会话制：同 projectId 在第二处打开 → 原 tab 弹「会话已过期」强制模态（详见 §11）

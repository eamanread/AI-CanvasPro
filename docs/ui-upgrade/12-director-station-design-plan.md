## 0. 设计语言基准（Warp，所有 UI 必须遵守）

### 0.1 颜色（中性灰，[S6] 已落地）
| 角色 | 值 | 用途 |
|---|---|---|
| canvas | `#141414` | 视口/最底 |
| surface | `#1b1b1b` | 面板底（左树/右检查器） |
| surface-raised | `#262626` | 浮层/菜单/输入场域 |
| hairline | `#2e2e2e` / `#333` | 边界（**替代阴影**） |
| ink-1/2/3 | `#f5f5f5` / `#c4c4c4` / `#a8a8a8` | 主/次/弱文字 |
| accent（中性） | `#f5f5f5` | 选中/primary 填充（**禁彩色 accent**） |
| 语义色 | danger/success/warning | 仅状态，保留 |

### 0.2 形 & 影 & 字
- **圆角**：按钮 3px / 输入·卡片 4px / 大面板 6px；**胶囊只给图标容器与状态丸**
- **禁投影**：层级 = 表面对比 + 发丝线（浮层 = `#262626` + `1px #333`，无 shadow）
- **字体**：Inter 400/500（UI）/ DM Mono（**数值/坐标/角度**）/ Instrument Serif italic（偶发编辑性点缀，如空态副标题）
- **激活态**：`rgba(255,255,255,.08–.14)` 底色填充，**不上色**

### 0.3 交互通则
- 工具栏图标按钮 → 悬停 tooltip + 点击在**上方**弹浮层菜单
- 快捷键暴露在菜单项右侧（如 移动 `V`）
- 右检查器 = 上下文 + tab（属性/姿势、属性/截图）
- 数值字段：DM Mono、change（blur/回车）提交、聚焦不被轮询打断

## 3. 分模块产品设计（功能点 / 交互 / UI）

### 3.1 取景比例选择器（P0，🔴 最高性价比）

**功能点**：安全框按比例锁定取景框，决定截图/出图画幅。Auto=跟随视口；其余固定 21:9/16:9/4:3/1:1/3:4/9:16。

**交互**：
- 点底部「安全框」按钮 → 上方弹比例网格浮层（图B 布局）
- 选中项高亮（Warp 激活态：`rgba(255,255,255,.12)` 底 + ink-1 字）
- 选定后视口叠加该比例的安全框遮罩（画幅外压暗 60%）
- 截图按所选比例裁切

**UI**（Warp）：
- 浮层：`#262626` 底 + `1px #333` + 6px 圆角，无影
- 网格：7 项，每项 56×40 卡（4px 圆角），图标=画幅缩略框 + 下方 DM Mono 标签
- Auto 项带图标 + "Auto" 字；选中态白底填充
- 状态：`sceneNode.capture.aspectRatio`（新增字段或复用 capture.mode）

### 3.2 变换模式菜单 + 快捷键（P0）

**功能点**：移动/旋转/缩放三模式切换，gizmo 随之换；快捷键 V/R/S。

**交互**：
- 点「变换」按钮 → 上方弹三项菜单（图E）：移动 `V` / 旋转 `R` / 缩放 `S`
- 或直接按 V/R/S 切换（全局快捷键，仅导演台聚焦时）
- 当前模式按钮高亮

**UI**（Warp）：
- 菜单项：左图标 + 中文名（Inter）+ 右快捷键（DM Mono，弱色 ink-3，外包 `#1b1b1b` 1px hairline 小键帽）
- 行高 36px，hover `rgba(255,255,255,.07)`，激活白底
- 复用 `ui.transformTool`（move/rotate/scale 已有）

### 3.3 角色属性补全：三轴旋转/缩放（P0）

**功能点**：旋转 X/Y/Z（度）、缩放 X/Y/Z（逐轴）+ 统一缩放滑杆联动。

**交互**：
- 三轴一行（X/Y/Z 并排），DM Mono 数值，change 提交
- 统一缩放滑杆拖动 → 三轴等值；逐轴编辑 → 解除统一
- ⚠️ 始终发完整 pose（已知 action 部分 pose 会重置，已修）

**UI**（Warp）：
- 字段组：组标题（ink-3 小字）+ 三轴行；轴标 X/Y/Z 弱色，输入 `#262626` 底 4px 圆角
- 滑杆：轨 `#333`、已填段中性白、握柄白圆点（pill 豁免）

### 3.4 全局场景检查器（P1，无选中时）

**功能点**：场景缩放/平移/旋转；全景背景（缩略图+文件名+天空色）；全景球（水平旋转+半径）；角色标签/网格吸附开关。

**交互**：
- 空选中时右栏标题"3D场景"
- 全景球**水平旋转**滑杆 → 实时转全景对齐机位；**半径**滑杆 → 调包裹感（映射原生 60m 球 / backdrop 半径）
- 天空色取色器 → 球外/无全景背景色
- 开关：角色标签、网格吸附（Warp 开关：轨 `#333`、开=中性白）

**UI**：分区卡（场景变换 / 全景背景 / 全景球 / 全局开关），区间发丝线分隔；缩略图 4px 圆角 + 文件名 DM Mono 截断。

### 3.5 全景背景源三入口（P1）

**功能点**：本地上传 / 历史记录 / AI生成（图F）。

**交互**：
- 点「全景背景源」按钮 → 上方弹三项：本地上传（带 ? 帮助）/ 历史记录 / AI生成
- 本地上传 → 文件选择（复用 uploadPanoramaSceneImage，已修 import bug）
- 历史记录 → 弹近期全景网格选择
- AI生成 → 唤起全景生成（接 panorama-360 节点 / AI 全景管线）

**UI**：菜单同 3.2 制度；AI生成项可带 Instrument Serif italic 副标"从一句话生成场景"。

### 3.6 机位检查器（P1）

**功能点**：镜头预览缩略图（FOV标注+展开）、名称、切换机位、位置 XYZ、注视目标（手动坐标/角色）、注视坐标 XYZ、FOV 滑杆。

**交互**：
- 选中机位 → 右栏"摄像机"[属性|摄像机截图]
- 注视目标下拉选"角色X" → 机位锁定看着该角色（target tracking）
- FOV 滑杆（映射 focalLength↔FOV 换算）
- 镜头预览 = 从该机位渲染小图，点展开看大图

**UI**：预览图顶部叠 FOV 标（DM Mono）；下拉 Warp 制度；坐标三轴 DM Mono。

### 3.7 角色姿势系统（P2，⭐ 全新核心）

**功能点**：
- 姿势预设 20 个（图3）：站立/T型/行走/跑步/坐姿/蹲下/单膝跪/双膝跪/叉腰/倚靠/鞠躬/思考/格斗/踢球/投掷/推进/招手/伸手/抱臂/看手机
- 姿势细调（图4）：身体[前倾/转身/侧倾]、躯干[前倾/扭转/侧倾]、头部[点头/转头/歪头]、手臂-肩(左/右)[前举/外展/扭转]、肘部(左/右)[弯曲]、腿部-髋(左/右)[前抬/外展/扭转]…

**交互**：
- 角色检查器「姿势」tab
- 点预设 → 套该姿势骨骼角度（覆盖细调）
- 拖细调滑杆 → 实时改骨骼（保留预设基底叠加）
- 姿势存 `mannequin.pose`（新增字段，骨骼角度字典）

**UI**：
- 预设：4 列网格按钮，每项小图标 + 名（Inter），激活白底
- 细调：分部位折叠组，每自由度一行滑杆 + DM Mono 数值；左/右用小丸标"左""右"

**技术**：基于已验证的 `applyPanoramaCharacterNaturalArmPose`（upperarm/lowerarm_l/r 骨骼旋转），补全骨骼集（spine/neck/head/thigh/calf/foot）+ 预设角度表。

### 3.8 ViewCube 导航球（P2）

**功能点**：右上方位立方体 + 三轴彩点；点面切正交视角；重置视角。

**交互**：点立方体面/轴点 → 相机切到该正交方向；点"重置视角"回默认。

**UI**：CSS 3D 或小 three 立方体；面 `#262626` + 发丝边；轴点用语义色（仅此处允许，作方位辨识）；"重置视角"小字按钮在下方。

### 3.9 机位截图 + 添加到画布（P2）

**功能点**：每机位存截帧序列；截图按取景比例裁切；「添加到画布」把帧落为画布图像节点 → 喂分镜。

**交互**：摄像机检查器「摄像机截图」tab 列出该机位历史帧；点底部「添加到画布」当前帧入画布。

### 3.10 角色库 + 上传（P3）

**功能点**：内置角色库（多体型/性别）+ 上传自定义模型；放置布局（单个/网格）。

**交互**：点「添加角色」→ 弹库网格（图C）+ 上传入口（图D）。

## 4. 迭代产品计划（版本里程碑）

> 排序依据：①用户可见价值 ②"暴露已有能力 vs 全新子系统"（已有的先做，风险低）。已完成 = P0 全景两条路 + 双视角 + 场景树 + 角色属性基础。

| 版本 | 主题 | 范围 | 价值 | 工期 |
|---|---|---|---|---|
| **V1 取景与变换**（即做） | 出图能力补齐 | 取景比例选择器(3.1) + 变换菜单/快捷键(3.2) + 角色三轴旋转缩放(3.3) | 直接决定出图画幅，最高性价比 | 1.5d |
| **V2 场景与背景** | 环境控制 | 全局场景检查器(3.4) + 全景背景源三入口(3.5，含历史/AI生成) | 全景球半径/旋转/天空色暴露，AI生成场景 | 2d |
| **V3 机位系统** | 虚拟机位 | 机位检查器(3.6) + 机位截图/添加到画布(3.9) | 机位成真·虚拟机位，闭环分镜 | 2.5d |
| **V4 角色表演**（核心） | 姿势系统 | 姿势 20 预设 + 骨骼细调(3.7) | 唯一全新子系统，角色有动作语言=分镜真价值 | 3–4d |
| **V5 导航与资产** | 打磨 | ViewCube(3.8) + 角色库/上传(3.10) + 整体 Warp 一致性校验 | 专业感收尾 | 2d |

**总览**：V1–V3 几乎全是"用 Warp 富检查器暴露幻映已有状态"（低风险高性价比）；V4 姿势是唯一需新建子系统（骨骼接口已验证可行）；V5 收尾。每版独立可交付、可回退（新模块 + autoload + theme-upgrade.css，不碰混淆核心）。

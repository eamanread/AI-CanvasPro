# 摄像机检查器（机位视角）差异文档 — 幻映 vs 竞品 liblib

> 来源：竞品 liblib 导演台「机位视角→选中机位→右侧摄像机面板」实拍 vs 幻映现状（`modules/panoramaDirectorChrome.autoload.js` renderInspector camera 分支 + `components/panoramaScene/DirectorChrome.js` deriveCameraInspector）。2026-06-13。

## 1. 顶层结构差异
| 维度 | 竞品 | 幻映现状 | 差异/动作 |
|---|---|---|---|
| **Tab 结构** | 顶部 `属性 ｜ 摄像机截图` 两个 tab | 单一面板，截图做成**内联画廊** | ❌ 不一致 → **改成两 tab**（属性 / 摄像机截图） |
| **相机预览** | 顶部**实时缩略图**（小窗渲染机位画面 + "FOV 50°" + 放大按钮） | 静态占位（相机图标 + FOV/焦距文字） | ⚠️ 降级（离屏渲染成本高）→ 暂保留占位，标注 |

## 2. 属性 tab 内容 & 顺序差异
| 顺序 | 竞品 | 幻映现状 | 差异 |
|---|---|---|---|
| 1 | 相机预览缩略图（顶部） | 名称 → 切换机位 → 预览（夹在中间） | ❌ 预览位置/顺序不同 |
| 2 | 名称（输入框） | 名称（输入框，可改） | ✅ 一致 |
| 3 | 切换机位（下拉） | 切换机位（下拉，>1 机位才显示） | ✅ 一致 |
| 4 | **位置 X｜Y｜Z（三轴横排）** | **位置 X/Y/Z（竖排三行）** | ❌ **布局不一致**（竞品横排、我竖排）→ 改三轴横排 |
| 5 | 注视目标（下拉 手动坐标/角色） | 注视目标（下拉） | ✅ 一致 |
| 6 | **注视坐标 X｜Y｜Z（三轴横排）** | **注视坐标 X/Y/Z（竖排三行）** | ❌ **布局不一致** → 改三轴横排 |
| 7 | 视野角度 FOV（滑块 + 数值） | FOV（滑块） | ✅ 基本一致 |
| 8 | （截图在另一 tab） | 摄像机截图画廊（内联，在位置上方） | ❌ 位置错 → 移到「摄像机截图」tab |

## 3. 核心差异小结（要改的 3 点）
1. **位置 / 注视坐标 改三轴横排**（`hy-dc-insp-xyz` 三列，复用角色属性 tab 的样式）——当前是竖排三行，与竞品、与本产品角色面板都不一致。
2. **摄像机截图 改成 tab**：摄像机检查器顶部加 `属性 ｜ 摄像机截图` 两 tab（与角色面板 `属性 ｜ 姿势` 同构），截图画廊放第二 tab。
3. **属性 tab 顺序对齐**：预览缩略图置顶 → 名称 → 切换机位 → 位置 → 注视目标 → 注视坐标 → FOV。

## 4. 字段语义（一致项，仅说明）
- 名称：写 `renamePanoramaSceneCamera`（机位有原生 name）。
- 切换机位：`activatePanoramaSceneCamera` 切激活机位 + 机位视角自动套用该机位视角。
- 位置/注视坐标/FOV：写 `node.directorExt.cameras[id].{position,lookAtTarget,lookAtPoint,focalLength}`（sceneNode 机位坐标只读，覆盖走 directorExt）；机位视角下实时套用（maybeApplyCameraView）。
- 注视目标：手动坐标 或 选某角色（角色 id）；选角色时注视坐标随角色头部。

> 降级保留：相机预览缩略图（竞品实时小窗）幻映暂为静态占位——离屏渲染（第二 renderer / FBO render-to-texture）成本与兼容风险高，待真机验证 FBO 路径稳定后再升级。

# 竞品 3D导演台 实操实录 + 差距清单（liblib.tv，2026-06-13 现场操作）

> 来源：用 Chrome 扩展实时操作竞品 `liblib.tv/canvas` 的「3D导演台」逐功能点遍，截图+DOM 核对。这是**地面真相**，作为像素+功能对齐的唯一目标。huanying 现状对照见每节「我方」。

## 0. 顶层布局
- **顶栏**：左「3D导演台」标题 ｜ 中「导演视角 ｜ 机位视角」分段切换 ｜ 右 `?` `×`。
- **左面板「场景」**：搜索框 +树。树行带类型图标（机位=摄像机图标 / 角色=人形图标）；**悬停显示 👁 可见性 + 🔒 锁定** 两个图标。
- **右检查器**：三态（3D场景 / 角色 / 摄像机），见下。
- **右上 ViewCube**：方位导航球（X 红/Y 绿/Z 蓝端点，负向灰点，随相机转）+ 下方「重置视角」按钮。
- **底部工具栏**：8 图标（选择/角色/变换/机位/安全框/截图/背景源/全屏），变换·安全框·背景源·角色为弹出菜单。
- **视口**：人偶顶上浮名字标签（角色标签开关控制）；选中出三轴 gizmo（红X/绿Y/蓝Z 箭头 + 旋转圈）；背景幕带 + 网格地面。

## 2. 右检查器 · 角色态（选中人偶）
Tabs：**属性 ｜ 姿势**
- **属性**：名称(输入框) / 位置 XYZ / 旋转 XYZ / 缩放 XYZ(逐轴) / 统一缩放(滑块) / 颜色(色块+hex #4F8EF7)　→ **✅ 我已重做对齐**（差异：竞品缩放真逐轴，huanying 原生仅统一缩放→我做成三轴联动）。
- **姿势**：20 预设网格（站立/T型/行走/跑步/坐姿/蹲下/单膝跪/双膝跪/叉腰/倚靠/鞠躬/思考/格斗/踢球/投掷/推进/招手/伸手/抱臂/看手机）+ 姿势调节滑块（身体:前倾/转身/侧倾, 躯干:前倾/扭转/侧倾, 头部:点头/转头/歪头, 手臂-肩 左/右…）　→ **✅ 我设计一致**（差异：**活体未接线**——拖滑块/选预设没真改模型骨骼）。

## 5. ViewCube
方位导航球：X 红(右)/Y 绿(上)/Z 蓝(朝外)端点小球，负向灰点，**随相机朝向转动**；点端点对位；下方「重置视角」。我方：已建静态版（轴色一致），**缺随相机转 + 点击对位需真机验**。

## 6. 关键行为
- **点视口人偶=选中**（出 gizmo + 角色检查器）。**这正是 huanying 全屏下失效的 #3**。
- 树点机位=选中（出摄像机检查器 + 相机预览）。
- 拖 gizmo 移动/旋转/缩放人偶；姿势滑块实时改骨骼。
